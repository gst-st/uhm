# Полная сборка корпусов в Markdown

УГМ (обе локализации):

```sh
python3 scripts/build-markdown.py
```

Результаты: `output/markdown/uhm-en.md`, `uhm-ru.md` и
`build-markdown-manifest.json`. Нужны Python 3 и Bun. Скрипт работает из любой
папки, если указать полный путь. `--output-dir PATH` задаёт папку результата.
Прежний `bun scripts/consolidate.ts [filename]` вызывает тот же сборщик и
копирует английскую редакцию в указанный файл (по умолчанию `docs-consolidated.md`).

Включаются **все** `.md`/`.mdx` из `website/docs`, затем русские переводы для
русской редакции. Порядок берётся из меню; документы вне меню следуют в порядке
исходных путей. Отсутствующий перевод явно отмечается и заменяется оригиналом.
Тела документов, формулы, код, статусы и исходные ссылки сохраняются побайтно;
YAML-метаданные помещаются в отдельные блоки. Полнота и SHA-256 записываются в
манифест. Изменение исходников во время сборки вызывает ошибку.

Это текстовый корпус для исследования. MDX-компоненты сохраняются как исходный
текст; бинарные изображения не встраиваются. Исходные ссылки сопоставляются с
путями в оглавлении; их веб-маршруты не переписываются. Для отрисовки интерактивных
компонентов и иллюстраций остаётся сайт.

## Все пять корпусов одной командой

```sh
python3 scripts/build-corpora-markdown.py
```

Дополнительно нужен Pandoc. Используются сборщики УГМ, Diakrisis, math-foundations,
MSFS и SYNARC, по умолчанию доступные через ссылки `internal/`. Каждому сборщику
передаётся отдельная временная папка: исходники и Git-состояние не изменяются.
Пути независимых checkout можно передать аргументами `--uhm-root`,
`--diakrisis-root`, `--foundations-root`, `--msfs-root`, `--synarc-root`.
Если в основном checkout SYNARC сборщика ещё нет, автоматически используется
единственный Git-worktree, где он есть; выбранный путь выводится явно и
записывается в манифест. При нескольких кандидатах нужно указать `--synarc-root`.

В `output/markdown/corpora/` появляются:

- полные MD каждого корпуса, отдельная Аутогения, доступные EN/RU редакции;
- точные LaTeX/BibTeX-исходники MSFS и SYNARC в `*-source.md`;
- `all-corpora.md`: все пять корпусов одним файлом, с русскими редакциями там,
  где они доступны; Аутогения уже входит в math-foundations и не дублируется;
- `README.md` с размерами и `corpora-manifest.json` с ревизиями и SHA-256.

Объединённый файл проверяется обратным извлечением каждого полного корпуса.
Файлы становятся доступны только после успешной сборки всех корпусов.
При передаче аудиторам можно выбрать отдельные корпуса вместо большого общего
файла. Полученные тексты и манифесты генерируются локально и не включаются в Git.
