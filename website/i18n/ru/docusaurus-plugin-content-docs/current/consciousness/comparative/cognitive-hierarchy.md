# Когнитивная Иерархия: От Ощущений к Языку

Различение, реакция на вознаграждение, перенос категории, планирование и символическая коммуникация ставят разные экспериментальные вопросы. Их объединение в стадии добавляет утверждение о порядке и зависимости способностей. Для каждого утверждения нужен опыт, где ответ нельзя объяснить недоступностью стимула, мотивацией или отсутствием подходящего действия.

<a id="операциональные-критерии"></a>

## Свидетельства для конкретной задачи

Различение проверяют на новых пробах, перенос категорий — на новых примерах, планирование — при изменении результата с прежними начальными подсказками. Для проверки коммуникации меняют информацию, доступную получателю, и регистрируют изменение сообщения отправителя. Для каждого опыта указывают более простую стратегию следования подсказке или запоминания и условие, в котором её прогноз отличается.

<a id="таксономическое-соответствие"></a>

## От задачи к утверждению о субъекте

Обучение приближению к награде не определяет, переживает ли организм удовольствие. Контроллер с заданным сигналом вознаграждения может выучить то же соответствие. Оценка способности относится к конкретным стимулу, считыванию и проверке переноса. Возраст, вид, архитектура и выбранная размерность матрицы сами её не задают.
