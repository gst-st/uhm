# Когнитом Анохина: Нейронная Гиперсеть и Проблема Субъекта

К. В. Анохин предлагает описывать мозг как гиперсеть нейронных групп с когнитивными свойствами. Его постановка вопроса — какая организация может выступать субъектом последовательных переживаний. Анатомическая связь, выученный ансамбль, отчёт в отдельной пробе и оценка самомодели — разные данные. Связь между ними требует явной процедуры измерения. [Постановка Анохина](https://doi.org/10.31857/S0044467721010032)

## Как отличить субъекта от измеренного ответа

Уравнение неподвижной точки не имеет единственной феноменальной интерпретации. Тождественный канал оставляет на месте любое состояние, а канал сброса фиксирует любую выбранную цель. Неподвижная точка имеется и без выученного репертуара или наблюдателя, способного дать отчёт. Для связи с субъектом нужно различать вмешательства в предполагаемую организацию, вход, решение и канал отчёта.

## Проверка нейронной группировки

Задают способ выделения группы в записи, предсказываемое поведение и способ сопоставления группы между пробами. Модель с взаимодействиями высших порядков сравнивают с моделью, сохраняющей ту же индивидуальную активность и парную статистику. Различить их может отложенное изменение контекста или стимула. Если при всех доступных вмешательствах предсказываются одинаковые полные записи, по этим наблюдениям нельзя выбрать реализацию.

## Что должно сохранять отображение моделей

Для отображения нейронной гиперсети в $\Gamma$ нужны категория допустимых вмешательств, целевая модель и проверка композиции. Можно предсказать результат двух последовательных вмешательств по параметрам, зафиксированным на одиночных воздействиях. Расхождение способно выявить неполноту кодировщика. Совпадение поддерживает указанные прогнозы; для отождествления переживаемого качества нужно дополнительное наблюдение.
