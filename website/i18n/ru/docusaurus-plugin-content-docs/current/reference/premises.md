# Предпосылки УГМ

## Исходные данные лаборатории {#как-читать}

Лаборатория задаёт типы приготовлений и процессов, их последовательное и параллельное соединение и записи замкнутых экспериментов. В указанном классе тестов два приготовления операционально эквивалентны ровно тогда, когда при каждом допустимом вмешательстве наблюдается одна и та же запись. Вероятностное распределение в качестве записи требует дополнительной структуры. Классическая лаборатория с честной монетой и одним фиксированным прибором различает $n$ символов для любого конечного $n$. Правила композиции сами по себе не выбирают комплексные амплитуды или семиэлементный алфавит. [Операциональные результаты](./network-results) · [Математическое ядро](./mathematical-kernel).

| A1 | Выбранный сайт открытых множеств пространства плотностей со стрелками включения и покрытиями объединением. Пучок на нём описывает согласованные локальные данные. |

| A5 | Тензорные часы, показания и ограничение на носитель совместного состояния в конструкции Пейджа–Вуттерса. Одна метка оси не выделяет тензорного фактора. |
| Октонионы | Вещественная положительная трёхформа или размеченная согласованно ориентированная таблица умножения. Для симметрии прибора с отмеченными осями нужны дополнительные условия. |

## Когда следует нижняя граница размерности {#посылка-сигма6}

Кодовая предпосылка (Σ₆) требует совершенной диагностики одиночной ошибки двоичным кодом, в котором больше двух слов. Шар Хэмминга радиуса один содержит $N+1$ элементов. Для совершенного покрытия $M(N+1)=2^N$, где $M>2$. При $N=1,3$ имеется не более двух слов, а следующая возможная длина $N=7$ достигается кодом Хэмминга. Другая граница получается из верного комплексного представления **заданной** алгебры $\mathbb C\oplus M_3(\mathbb C)\oplus M_3(\mathbb C)$, для которой нужны как минимум $1+3+3=7$ измерений. Кодовая задача и алгебра входят в предпосылки разных теорем. [Границы размерности](./mathematical-kernel).

## Чем задаются скорость и цель {#свободные-параметры}

<a id="максфи-и-вариационные-принципы"></a>

<a id="безусловные"></a>

Для динамики нужны гамильтониан, диссипативные скорости, цель замены, сила обратной связи, фильтр, единица физического времени и считывание. При одинаковой инцидентности допустимы разные скорости и цели. У канала замены целью может быть любая фиксированная матрица плотности. Правило максимальной интеграции (MaxΦ) могло бы выбирать её лишь в отдельно заданном допустимом множестве по определённому критерию. Физические скорости калибруют по одним траекториям, предсказания проверяют на других. [Уравнения](./specification) · [Постановка проверок](./falsifiability).

## Нормативные обязательства {#нормативные-основания}

Этическая модель принимает заботу о предотвращении вреда, самостоятельности, согласии и равном учёте интересов как нормативные предпосылки [N]. Соответствие показателя благополучию человека — эмпирическая гипотеза. Доказанное сохранение выбранной численной оценки относится лишь к самой оценке. Неизмеренный показатель не ограничивает этического статуса человека. [Нормы и интерпретация](../consciousness/ethics-meaning/value-consciousness).
