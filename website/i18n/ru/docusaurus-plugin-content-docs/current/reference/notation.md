# Математические обозначения

## Процессы и записи измерений

| Обозначение | Значение |
|---|---|
| $p:a\to b$ | Процесс с указанными типами входа и выхода. У приготовления тривиальный тип входа. |
| $T[p]$ | Замкнутый опыт, включающий процесс в допустимый контекст проверки. |
| $p\sim q$ | Во всех допустимых замкнутых тестах записи двух процессов совпадают. Новое вмешательство может уточнить отношение. |
| $C(y)$ | Состояния и параметры калибровки, совместимые с наблюдением $y$. |
| $U_{ji}$ | Перенос из узла $i$ в узел $j$. При локальных заменах репера $U_{ji}\mapsto g_j U_{ji}g_i^{-1}$. |
| $d(i,j)$ | Минимальная стоимость допустимой передачи, когда минимум установлен полным перебором или доказательством. Стоимости в двух направлениях могут различаться. |

## Конечномерная квантовая модель

| Обозначение | Определение |
|---|---|
| $\mathcal H$, $D_N$ | Гильбертово пространство размерности $N$ и положительные матрицы со следом один на нём. В выбранном семантическом регистре $N=7$. |
| $\Gamma$, $\gamma_{ij}$ | Состояние и его элементы в заданном базисе; $\gamma_{ji}=\overline{\gamma_{ij}}$. |
| $K$, $K^*$ | Линейный канал и сопряжённое по следу действие на наблюдаемых. У сохраняющего след канала сопряжённое действие сохраняет единицу. |
| $E_y$ | Эффект исхода. Для измерения $E_y\succeq0$, $\sum_y E_y=I$ и $p(y)=\operatorname{Tr}(E_y\Gamma)$. |
| $H$, $L_j$ | Эрмитов гамильтониан и заданные операторы скачков квантовой марковской модели. |
| $\sigma$, $\kappa$ | Целевое состояние и скорость для выбранного закона замены. Единицы времени согласуют с калибровкой скорости. |
| $P$, $S$ | Чистота $P=\operatorname{Tr}\Gamma^2$ и энтропия $S=-\operatorname{Tr}(\Gamma\log\Gamma)$ при указанном основании логарифма. |

При заданном тензорном произведении $\mathcal H_A\otimes\mathcal H_B$ маргиналь равна $\rho_A=\operatorname{Tr}_B\Gamma_{AB}$. Координатное сжатие $\Pi\Gamma\Pi$ на одном регистре имеет другой смысл и может иметь след меньше единицы. [Спецификация модели](./specification).

## Считывания семиосевой модели {#индексы-измерений-протокол-измерения}

$A,S,D,L,E,O,U$ обозначают артикуляцию, структуру, динамику, логику, интериорность, основание и единство. В циклической таблице октонионов на страницах физики используется нумерация $(A,S,D,L,E,U,O)=(1,2,3,4,5,6,7)$. При другом порядке матрицы одной перестановкой меняют строки, столбцы и наблюдаемые.

Положим $d=\sum_i\gamma_{ii}^2$ и $q=\sum_{i\ne j}|\gamma_{ij}|^2$. Для выбранных оценок $P=d+q$, $\Phi=q/d$ и $R=1/(7P)$. Для $D_{\rm diff}=\exp S(\rho_E)$ требуется отдельно заданное состояние $\rho_E$. Символы $I_A,\ldots,I_U$ обозначают предлагаемые экспериментальные индексы, например взаимную информацию или ранг якобиана при выбранном пороге. Их соответствие населённостям и когерентностям требует калибровки. [Протокол измерений](../applied/research/measurement-protocol).

## Геометрия, инцидентность и поля {#топология-гротендика}

$F(\rho,\sigma)=(\operatorname{Tr}\sqrt{\sqrt\rho\sigma\sqrt\rho})^2$ обозначает квадрат верности. Угол Бюреса равен $\arccos\sqrt F$, а хордальное расстояние Бюреса — $\sqrt{2-2\sqrt F}$. В сайте открытых множеств используются включения и покрытия объединением. Чтобы указать расстояние в численной оценке, приводят его формулу.

$f_{ijk}=\langle e_i e_j,e_k\rangle$ — структурные константы октонионов, $G_2=\mathrm{Aut}(\mathbb O)$. $H_F$ обозначает заданное конечное фермионное пространство спектральной модели, $D_F$ — внутренний оператор Дирака. Матрицы масс могут входить в его исходные данные. Калибровочное действие, локальные поля и физический масштаб энергии нужно указать отдельно.
