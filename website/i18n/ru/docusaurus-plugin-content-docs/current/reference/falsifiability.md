# Проверяемость и предсказания

## Какое утверждение может опровергнуть наблюдение {#refutation-criterion}

Для экспериментального утверждения нужны приготовление, допустимые вмешательства, регистрируемые исходы и предсказанное распределение или интервал. Пусть для скрытого состояния $x$ и калиброванного закона наблюдения $O$ множество $C(y)$ содержит все состояния, совместимые с записью $y$ и погрешностью калибровки. Предсказываемая величина $F$ определена по $y$ ровно тогда, когда $F$ постоянна на $C(y)$. Если измеренная разность с учётом шума выходит за весь допустимый диапазон, она противоречит совместной модели. При перекрытии интервалов конкурирующих предсказаний сравнение остаётся неразрешённым. [Идентифицируемость](../applied/research/reconstruction-identifiability#fiber-theorem).

## Вмешательство с различимыми исходами {#summary-table-of-predictions}

В сети с двумя когерентными путями сигналы, пришедшие одновременно, могут погасить друг друга при одной настройке прибора. Калиброванная смена знака в одном плече превращает их сумму в разность. Если хотя бы в одном плече амплитуда ненулевая, два показания не могут одновременно обратиться в нуль. Здесь предполагаются линейный отклик, управление относительной фазой в измеряемом представлении и чувствительность прибора к данной моде. Само по себе отсутствие сигнала не определяет длину пути. В отдельном опыте можно сравнить времена первого отклика двух калиброванных проб на одной цепи. [Сетевые результаты и примеры](./network-results).

## Модель с семью скоростями {#f-rank7-ранг-7-анизотропия-декогеренции}

<a id="f-gap-1-внутри-триплетный-gap-ниже-межтриплетного"></a>
<a id="f-gap-2-блоковая-прозрачность-по-фано-триплетам"></a>
<a id="f-ξ-корреляционная-длина-фано"></a>

Для выбранного семейства скачков дефазировки на прямых Фано попарные скорости затухания связаны условием $r=A\gamma$ с семью неотрицательными скоростями $\gamma_p$. Строка для $i,j$ содержит $1/6$ в столбцах прямых, содержащих ровно один из индексов, и ноль в остальных. Матрица $21\times7$ имеет ранг семь. Измеренный вектор скоростей должен лежать в семимерном пространстве столбцов и в более узком конусе $A\mathbb R^7_{\ge0}$. Для проверки нужны временные ряды с контролем гамильтоновой динамики и обратной связи и оценка коррелированных погрешностей. Один снимок модулей когерентностей скоростей не определяет. Любая пара точек Фано лежит на прямой, поэтому для сравнения поведения на прямой и вне её нужно определить *тройки* или явно размеченное семейство пар. [Прибор Фано](../proofs/gap/fano-channel).

## Точное ограничение и условия его применения {#f-band-две-суммы-живого-состояния}

Для матрицы плотности обозначим $d=\sum_i\rho_{ii}^2$ и $q=\sum_{i\ne j}|\rho_{ij}|^2$. Условия выбранного фильтра $q\ge d$, $2/7<d+q\le3/7$ влекут $1/7\le d\le3/14$ и $1/7<q\le2/7$. Здесь $d\ge1/7$ следует из нормировки. Матрица, прошедшая фильтр и нарушившая границы, опровергла бы алгебраический вывод или выявила ошибку реализации. Применение фильтра к биологическим данным дополнительно требует независимо калиброванного кодирования и критерия исхода. [Пороги](./mathematical-kernel#thresholds).
