## Критерии Фальсификации

:::tip Леджер фронтиров
Очные предсказания против конкурирующих теорий на каждом живом фронтире — [Леджер фронтиров](/docs/reference/frontier-ledger).

### Экспериментальные Предсказания

Расширенная теория делает проверяемые предсказания:

#### 1. Изоспектральная дискриминация

Два состояния $\rho_1$, $\rho_2$ с $\mathrm{Spec}(\rho_1) = \mathrm{Spec}(\rho_2)$, но $\mathrm{Eigvec}(\rho_1) \neq \mathrm{Eigvec}(\rho_2)$ должны давать:
- Одинаковую интенсивность опыта (спектр определяет интенсивность)
- Различимое качество опыта (собственные векторы определяют [качество](/docs/proofs/categorical/categorical-formalism#2-категория-exp))

**Численные критерии:**
- Спектры «идентичны»: $\|\mathrm{Spec}(\rho_1) - \mathrm{Spec}(\rho_2)\|_2 < \varepsilon_{\text{spec}} = 0.01$
- Векторы «различимы»: $\min_i |\langle v_i^{(1)} | v_i^{(2)} \rangle| < 1 - \varepsilon_{\text{vec}}$, где $\varepsilon_{\text{vec}} = 0.1$
- Качество «различимо»: $d_{\text{FS}}([|q_1\rangle], [|q_2\rangle]) > \varepsilon_{\text{qual}} = 0.05$ рад

**Тест:** Создать изоспектральные нейронные состояния, измерить феноменальные отчёты.

#### 2. Контекстуальная модуляция

Изменение [контекста](/docs/reference/specification#полное-экспериенциальное-пространство) $\Gamma_{-E}$ при фиксированном $\rho_E$ должно изменять *качество* опыта без изменения *интенсивности*.

**Численные критерии:**
- $\rho_E$ «фиксировано»: $\|\rho_E^{(1)} - \rho_E^{(2)}\|_F < \varepsilon_{\rho} = 0.02$
- Контекст «изменён»: $\|\Gamma_{-E}^{(1)} - \Gamma_{-E}^{(2)}\|_F > \delta_{\Gamma} = 0.1$
- Интенсивность «постоянна»: $|\mathrm{Tr}((\rho_E^{(1)})^2) - \mathrm{Tr}((\rho_E^{(2)})^2)| < \varepsilon_P = 0.05$
- Качество «изменено»: феноменальный отчёт различим с $p < 0.01$ (статистический тест)

**Тест:** Модулировать контекст (внимание, настроение) при постоянном стимуле, измерить изменения в качестве восприятия.

#### 3. Адаптационная динамика

[Экспериенциальное содержание](/docs/proofs/categorical/categorical-formalism#2-категория-exp) (уровни [L1–L2](/docs/proofs/consciousness/interiority-hierarchy)) должно следовать закону адаптации:

$$
\mathcal{Q}(t) \sim \log\left(\frac{\lambda_{\max}(t)}{\langle\lambda_{\max}\rangle_\tau}\right)
$$

где:
- $\mathcal{Q}(t)$ — субъективная интенсивность опыта в момент $t$
- $\lambda_{\max}(t)$ — максимальное собственное значение $\Gamma(t)$
- $\langle\lambda_{\max}\rangle_\tau$ — среднее за период адаптации $\tau$

:::info Интерпретация
Это предсказание следует из того, что восприятие кодирует *изменения* относительно базовой линии (закон Вебера–Фехнера), а не абсолютные значения.
:::

**Численные критерии:**
- Корреляция $r(\mathcal{Q}_{\text{measured}}, \mathcal{Q}_{\text{predicted}}) > r_{\min} = 0.7$
- Наклон регрессии $\beta \in [0.8, 1.2]$ (близок к 1)
- RMSE $< \sigma_{\mathcal{Q}} / 2$ (ошибка меньше половины стандартного отклонения)
- Период адаптации $\tau \in [100, 1000]$ мс (типичный диапазон)

**Тест:** Измерить временную динамику адаптации, сравнить с предсказанием.

#### 4. Метрические отношения

Расстояния в феноменальном пространстве ([L1](/docs/proofs/consciousness/interiority-hierarchy#уровень-1-феноменальная-геометрия-phenomenal-geometry)) должны соответствовать [метрике Фубини–Штуди](/docs/reference/specification#метрика-фубини-штуди):

$$
d_{\mathrm{perceived}}(q_1, q_2) \sim d_{\mathrm{FS}}([|q_1\rangle], [|q_2\rangle])
$$

где $[|q\rangle] \in \mathbb{P}(\mathcal{H}_E)$ — класс эквивалентности в [проективном пространстве](/docs/reference/specification#проективное-пространство-качеств).

**Численные критерии:**
- Корреляция Спирмена $\rho_S(d_{\text{perceived}}, d_{\text{FS}}) > 0.6$
- Монотонность: нарушений $< 10\%$ от общего числа пар
- Метрическая согласованность: $|d(a,b) + d(b,c) - d(a,c)| < \varepsilon_{\triangle} = 0.15$ (неравенство треугольника)
- MDS-реконструкция: stress $< 0.1$ при отображении в $\mathbb{R}^k$

**Тест:** Построить феноменальную карту качеств (L1), сравнить с предсказанной геометрией.

## Критерий Опровержения

Теория фальсифицируется, если:

$$
\exists \rho_1, \rho_2 : \mathcal{I}(\rho_1) = \mathcal{I}(\rho_2), \text{ но } F(\rho_1) \neq F(\rho_2)
$$

где:
- $\mathcal{I}(\rho) := (\mathrm{Spec}(\rho), \mathrm{Eigvec}(\rho), \Gamma_{-E}, \mathrm{Hist})$ — полный инвариант
- $F: \mathbf{DensityMat} \to \mathbf{Exp}$ — [функтор опыта](/docs/proofs/categorical/categorical-formalism#3-функтор-f-на-объектах)

То есть, если два состояния с *идентичными* полными инвариантами (спектр + собственные векторы + контекст + история) дают *различимый* опыт.

:::info Калибровочная уточнённость [Т]
[Теорема $G_2$-ригидности](/docs/proofs/categorical/uniqueness-theorem) [Т] уточняет понятие «идентичности»: два состояния $\rho_1, \rho_2$ считаются **физически тождественными**, если $\rho_2 = U\rho_1 U^\dagger$ для некоторого $U$ из конечной октонионной реперной группы $\Gamma_{\!\text{oct}} \subset G_2$ — перемаркировки функциональных осей ([реперное решение D-0910](/docs/proofs/categorical/uniqueness-theorem#g2-ригидность)). Полный инвариант $\mathcal{I}(\rho)$ поэтому определён на $\mathcal{D}(\mathbb{C}^7)/\Gamma_{\!\text{oct}}$ (48 параметров); его $G_2$-орбитальная часть (34 параметра: спектр и углы относительно $\varphi_3$) инвариантна и до закрепления репера. Собственные векторы в таблице ниже берутся в закреплённом функциональном репере; при перемаркировке $v_i \to Uv_i$ скалярные произведения $|\langle v_i^{(1)} | v_i^{(2)} \rangle|$ не меняются.
:::

**Операциональные допуски:**

| Компонент инварианта | Критерий «идентичности» |
|---------------------|------------------------|
| Спектр | $\|\mathrm{Spec}(\rho_1) - \mathrm{Spec}(\rho_2)\|_2 < 0.01$ |
| Собственные векторы | $\forall i: \lvert\langle v_i^{(1)} \vert v_i^{(2)} \rangle\rvert > 0.99$ |
| Контекст | $\|\Gamma_{-E}^{(1)} - \Gamma_{-E}^{(2)}\|_F < 0.02$ |
| История | $d_{\text{edit}}(\mathrm{Hist}_1, \mathrm{Hist}_2) < 0.05 \cdot \lvert\mathrm{Hist}\rvert$ |

| Интериорность | Критерий «различимости» |
|------|------------------------|
| Феноменальный отчёт | Статистически различим ($p < 0.01$, тест Вилкоксона) |
| Поведенческий маркер | AUC > 0.7 в задаче дискриминации |

:::note Практический критерий
Для экспериментальной проверки достаточно сравнить спектр и собственные вектора (без истории): если $\mathrm{spec}(\rho_1) = \mathrm{spec}(\rho_2)$ и $|q_i^{(1)}\rangle = |q_i^{(2)}\rangle$, но $\mathcal{F}(\rho_1) \neq \mathcal{F}(\rho_2)$, теория фальсифицирована.
:::

:::warning Что этот критерий есть — и чем он не является
Спектр и собственные векторы определяют $\rho$, а $\Gamma_{-E}$ вместе с $\mathrm{Hist}$ дополняют состояние. Критерий выше, следовательно, утверждает, что опыт — *функция* полного состояния $(\Gamma, \mathrm{Hist})$: это утверждение о **супервентности**. Оно фальсифицируемо лишь совместно с фиксированным протоколом реконструкции $\pi_{\mathrm{bio}}$ (репер закреплён [реперным решением D-0910](/docs/proofs/categorical/uniqueness-theorem#g2-ригидность), выбор фиксации калибровки публикуется по R8) и само по себе не предсказывает, *какой именно* опыт несёт состояние. Содержательные фальсификаторы теории — численные: $P(\Gamma_{\mathrm{wake}}) > 2/7 > P(\Gamma_{\mathrm{NREM3}})$ и монотонная связь $\Phi$–PCI (P8.3) в [протоколе измерения](/docs/applied/research/measurement-protocol), критерий симуляции No-Zombie S1–S3 в [теоремах КК](/docs/applied/coherence-cybernetics/theorems#протокол-симуляции-no-zombie) и физические строки [леджера рубежей](/docs/reference/frontier-ledger). Где эти численные фальсификаторы стоят относительно аргумента подстановки Kleiner & Hoel — [теорема протокола измерения](/docs/applied/research/measurement-protocol#substitution-position): калибровка на сессиях, размеченных по отчётам, стоит на роге строгой зависимости, проверка с заранее замороженными параметрами — на роге независимости, а мягкая зависимость существует в лучшем случае внутри объявленной области [Г]. До 2026-09-25 эталонный оценщик $\pi_{\mathrm{bio}}$ содержал штраф за нежизнеспособность, восстанавливавший всякое подпороговое состояние равномерного семейства ровно при $P = 2/7$, так что $P(\Gamma_{\mathrm{NREM3}}) < 2/7$ нельзя было наблюдать; штраф снят (SUB-2).
:::

:::info Замечание об операционализации
Полный инвариант $\mathcal{I}(\rho) = (\mathrm{Spec}, \mathrm{Eigvec}, \Gamma_{-E}, \mathrm{Hist})$ — **теоретический идеал**. Операциональная реализация:
- **Spec(ρ):** измерим через квантовую томографию состояния
- **Eigvec(ρ):** измеримы через полную томографию (нейронные корреляты)
- **Γ_{-E}:** приближённо измерим через парциальный след — отбрасывание E-компоненты
- **Hist:** приближён через временны́е корреляторы $\langle O(\tau)O(0) \rangle$ (двухточечные функции, доступные через фМРТ/ЭЭГ)

Критерий фальсификации **строг в теоретическом смысле** и **приближён в экспериментальном**. Это стандартная ситуация для теорий с ненаблюдаемыми непосредственно объектами (ср. волновая функция в КМ).
:::

## Фальсифицируемые предсказания из Фано-интеграции

:::info Источник
Предсказания выведены из интеграции [Фано-геометрии](/docs/physics/gauge-symmetry/fano-selection-rules) с [Gap-динамикой](/docs/core/dynamics/gap-dynamics), [термодинамикой Gap](/docs/core/dynamics/gap-thermodynamics) и [RG-потоком](/docs/physics/gauge-symmetry/rg-flow). Каждому предсказанию присвоен статус строгости согласно [реестру](/docs/reference/status-registry).

### F-Gap-1: Внутри-триплетный Gap ниже межтриплетного {#f-gap-1-внутри-триплетный-gap-ниже-межтриплетного}

$$
\langle \mathrm{Gap}_{\mathrm{intra}} \rangle < \langle \mathrm{Gap}_{\mathrm{inter}} \rangle
$$

Средний [Gap](/docs/physics/dual-aspect/gap-semantics) внутри [Фано-триплетов](/docs/physics/gauge-symmetry/fano-selection-rules) ниже, чем между ними. Когерентности, принадлежащие одной Фано-линии, более прозрачны (ближе к $\mathrm{Gap}=0$), чем когерентности, соединяющие разные линии.

**Тестируемость:** ISF-компоненты (independent slow features) в фМРТ. Внутри-триплетные корреляции должны систематически превышать межтриплетные.

**Статус:** [Г] Гипотеза — следствие [Gap-семантики](/docs/physics/dual-aspect/gap-semantics) и [G₂-ковариантности](/docs/physics/gauge-symmetry/g2-structure).

### F-Gap-2: Блоковая прозрачность по Фано-триплетам {#f-gap-2-блоковая-прозрачность-по-фано-триплетам}

Когерентности внутри одной [Фано-линии](/docs/physics/gauge-symmetry/fano-selection-rules) сильнее коррелированы, образуя блоковую структуру в матрице когерентности $\Gamma$. Фано-диссипатор сохраняет триплетные когерентности ([Т], [G₂-структура](/docs/physics/gauge-symmetry/g2-structure)), что порождает выделенную блоковую прозрачность.

**Тестируемость:** Корреляционный анализ матрицы когерентности — 7 блоков $3 \times 3$ (по Фано-линиям) должны быть статистически отделены от внеблоковых элементов.

### F-w: Форма дрейфа тёмной энергии (закон дрейфа Λ) {#f-w-форма-дрейфа-тёмной-энергии}

**Предсказание ([T-254](/docs/physics/gravity/cosmological-constant#теорема-лямбда-дрейф) [Т] / [T-255](/docs/physics/gravity/cosmological-constant#теорема-трихотомия-ветвей) [Т-структурно]+[С]).** Уравнение состояния тёмной энергии — функционал состояния, а не ручка настройки: $1+w_{\text{eff}} = -\tfrac{2}{3}\,d\ln\mathcal{G}_O/d\ln a$ с положительным полом $\Lambda_\infty = \Lambda_{\text{phys}}(\rho^*) > 0$. Следствия, независимые от ветви: **нет Большого разрыва** (неограниченный фантом исключён), **нет вакуумного коллапса** ($\rho_{\text{DE}} \not\to 0^-$), $w \to -1$ асимптотически. Зависимые от ветви: DESI-квадрант $(w_0 > -1,\ w_a < 0)$ достижим **только** через настоящее пересечение $-1$ (осцилляторная ветвь); последнее пересечение идёт фантом → квинтэссенция в ориентации, фиксированной $V_3$-стрелой внутреннего времени [С]; со-дрейф $\dot G_N$ обязан нести **тот же знак**, что и $(1+w)$, с величиной $\chi(\omega_0/\Lambda)^2(\mathcal{G}_O/7)\tfrac32(1+w)\,H$.

**Критерии фальсификации:** (i) подтверждённое *постоянное* $w \neq -1$ (неизменное не-Λ уравнение состояния по эпохам с высокой значимостью); (ii) реконструированная $\rho_{\text{DE}}(z)$, растущая неограниченно или пересекающая ноль; (iii) DESI-квадрант CPL подтверждён, а непараметрическая реконструкция *исключает* всякое пересечение $-1$; (iv) последнее пересечение в направлении, противоположном $V_3$-стреле (фальсифицирует [С]-связку); (v) подтверждённый дрейф при измерении $\dot G_N/G_N$ *противоположного* знака (фальсифицирует со-дрейф).

**Эксперименты:** DESI DR2+, Euclid, Roman (реконструкция $w(z)$); лунная лазерная локация ($\dot G_N$).

**Текущий вердикт (2026):** СОГЛАСУЕТСЯ — предпочтение DESI DR2 (март 2025; $2.8$–$4.2\sigma$ за $w_0 > -1,\ w_a < 0$ в зависимости от выборки сверхновых) лежит ровно в том единственном квадранте, который УГМ достигает через пересечение, и лучшая CPL-траектория идёт фантом (прошлое) → квинтэссенция (сегодня) с пересечением $-1$ около $z \approx 0.5$ — ориентация, предсказанная УГМ. Нет ни Rip-подобного, ни постоянного-$w$ сигнала; знаковый тест со-дрейфа ждёт подтверждённого дрейфа.

:::warning Оговорка — само пересечение ещё не установлено
Пересечение фантом → квинтэссенция выведено из двухпараметрического CPL-фита $(w_0, w_a)$, а не из физической модели. Непараметрические / модель-независимые реконструкции $w(z)$ **пока не** подтверждают настоящее пересечение $-1$ надёжно — признак частично является артефактом параметризации, и литература (2025–2026) считает его реальность неустановленной. Это важно для [С]-связки: критерий фальсификации (iii) УГМ — «DESI-квадрант подтверждён, **тогда как** реконструкция *исключает* всякое пересечение» — **не** сработал (реконструкции не подтверждают и не исключают), так что предсказание в безопасности, но ключевой дискриминатор остаётся открытым. Количественный дискриминатор для наблюдения — выживёт ли осцилляторная (quintom-подобная) ветвь после уточнения реконструкций.
:::

### F-rank7: Ранг-7 анизотропия декогеренции {#f-rank7-ранг-7-анизотропия-декогеренции}

$$
r_{ij}=\tfrac{1}{6}\!\!\sum_{|\ell_p \cap \{i,j\}| = 1}\!\!\gamma_p
$$

Двадцать одна межканальная скорость декогеренции не свободна. Всякая пара $(i,j)$
лежит ровно на одной прямой Фано, и скорость между ними задана семью прямыми
скоростями $\gamma_p$ через один лишь узор инцидентности. Двадцать одно число,
определённое семью, оставляет **четырнадцать точных правил сумм** — предсказание
без единого подгоночного параметра, отчего оно и есть самая резкая структурная
проверка, какую теория предлагает.

**Проверяемость:** томография скоростей в базисе $\Gamma$ — сейчас вычислительно,
позже через возмущающие протоколы типа PCI. Проверка есть проекция: подогнать
измеренные $r_{ij}$ и спросить, отличим ли статистически от нуля остаток вне
семимерного подпространства инцидентности.

**Фальсифицируется:** значимым остатком вне этого подпространства. В отличие от
нейронных предсказаний, мостовой посылки здесь не нужно — это утверждение о
диссипаторе, проверяемое всюду, где диссипатор измерим.

**Статус:** [Т]+[С] — правила сумм доказаны (T-262, Предсказание 23);
отождествление измеренной матрицы скоростей с $r_{ij}$ и есть условная часть.

### F-Band: две суммы живого состояния {#f-band-две-суммы-живого-состояния}

$$
\text{жив}\;\Longrightarrow\; s_1 \in \left[\tfrac{1}{7},\,\tfrac{3}{14}\right]
\quad\text{и}\quad s_2 \in \left[\tfrac{1}{7},\,\tfrac{2}{7}\right]
$$

Всякие ворота суть формула от трёх сумм, из которых две — это $s_1 = \sum_i d_i^2$,
чистота диагонали, и $s_2 = \sum_{i \neq j}|\gamma_{ij}|^2$, полный вес связи.
Целостности нужно $s_2 \geq s_1$; рефлексии нужно $s_1 + s_2 \leq 3/7$; а
неравенство Коши — Буняковского требует $s_1 \geq 1/7$ от всякого состояния
вообще. Сцепив их, получаем стеснение **обеих** сумм в узкие полосы, причём
вторая ровно вдвое шире первой.

Это собственный внутренний фальсификатор теории, и прогнать его необычайно
дёшево: не нужно ни мостовой посылки, ни феноменального отображения, ни опыта
сверх вычисления двух сумм по $\Gamma$.

**Фальсифицируется:** всяким состоянием, удовлетворяющим четырём условиям, у
которого $s_1$ или $s_2$ выпадает из своей полосы, — это означало бы, что четыре
условия суть не то, что говорят три суммы. Либо, с другой стороны, системой,
которую независимое измерение зовёт сознательной, а её восстановленная $\Gamma$
стоит вне полос, — что фальсифицировало бы восстановление, а не алгебру.

**Проверяемость:** немедленная вычислительно; через восстановление $\Gamma$ из
фМРТ или ЭЭГ — как только этому восстановлению начнут доверять.

**Статус:** [Т] — ноль контрпримеров на двадцати тысячах состояний в каждой
полосе, причём обе полосы достижимы, а не пусты: плоская диагональ с
уравновешенным содержимым вполсилы попадает внутрь (T-321, T-323).

## Полнота Теории

Теория полна в следующем смысле:

1. **Самодостаточность:** Не требует внешних постулатов или ссылок
2. **Универсальность:** Применима к структурным аспектам самореферентных систем — от квантовых до когнитивных
3. **Внутренняя согласованность:** Не содержит противоречий
4. **Операциональность:** Может быть реализована вычислительно
5. **Объяснительная сила:** Разрешает традиционные философские проблемы
6. **Фальсифицируемость:** Делает проверяемые предсказания о структуре опыта
7. **Формальная строгость:** Доказаны ключевые теоремы ([минимальность 7D](/docs/proofs/minimality/theorem-minimality-7), [оператор φ](/docs/proofs/categorical/formalization-phi), [функтор F](/docs/proofs/categorical/categorical-formalism))
8. **Совместимость с КМ:** регенеративный член сохраняет [маргинальное тождество](/docs/proofs/physics/physics-correspondence#запрет-сигнализации) [Т] (CPTP-свойство $\varphi$, условия [NS1-NS3](/docs/core/dynamics/evolution#запрет-сигнализации)); запрет сигнализации для полной динамики выполняется лишь в неселективном прочтении [С] — при обновлении Людерса шлюз $g_V$ сигналит (прежний пункт называл запрет доказанным; отозвано)
9. **Ансамблевая независимость:** отображение эволюции есть функция $\Gamma$ (матрицы плотности), а не её разложения [О]; физическое прочтение «два приготовления одной $\Gamma$ эволюционируют одинаково» [отозвано](/docs/proofs/physics/physics-correspondence#85-ансамблевая-независимость)
10. **Вычислительная согласованность:** утверждение, что нелинейность $\mathcal{R}$ не даёт ускорения сверх BQP, [отозвано](/docs/proofs/physics/physics-correspondence#86-вычислительное-ограничение) — даёт ли, открытый вопрос [Г]

### Феноменальные Границы (что принимается как аксиома)

1. **Категориальный разрыв:** Теория не объясняет, *почему* математические структуры «ощущаются». Тождество бытия и опыта — [Аксиома Ω⁷](/docs/core/foundations/axiom-omega), не теорема.

2. **Калибровка квалиа:** Соответствие между конкретными собственными значениями/векторами и конкретными качествами опыта устанавливается эмпирически.

:::info Калибровка квалиа — эмпирический вопрос
Какой конкретный $[|q\rangle] \in \mathbb{P}(\mathcal{H}_E)$ соответствует «красному» — эмпирический вопрос, не теоретический дефект. Это аналогично тому, как масса электрона не выводится из Стандартной модели. Структура опыта (спектральное разложение) — [единственный функтор](/docs/consciousness/foundations/two-aspect-monism#теорема-единственность-фв), совместимый с аксиоматикой, но конкретная калибровка определяется экспериментально.
:::

3. **Абсолютные квалиа:** Вопрос о существовании контекстно-независимых квалиа остаётся открытым.

4. **Пороги [L2](/docs/proofs/consciousness/interiority-hierarchy#уровень-2-когнитивные-квалиа-cognitive-qualia):** $R_{\text{th}} = 1/3$ **[Т]** — выводится из [триадной декомпозиции](/docs/core/operators/lindblad-operators#триадная-декомпозиция) ($K = 3$ типа динамики из аксиом) + [байесовского доминирования](/docs/core/foundations/axiom-septicity#теорема-порог-рефлексии). $\Phi_{\text{th}} = 1$ **[Т]** — единственное самосогласованное значение при $P_{\text{crit}} = 2/7$ ([T-129](/docs/proofs/consciousness/operationalization#t-129)).

### Категориальные Границы

1. **$\mathbf{Exp}$ не топос:** [Доказано](/docs/proofs/categorical/categorical-formalism#6-топосная-структура), что категория $\mathbf{Exp}$ не является топосом — нет внутренней логики экспериенциального содержания.

2. **Функтор $F$ необратим:** Нельзя однозначно восстановить $\rho$ по экспериенциальному содержанию — разные состояния могут давать «одинаковый» опыт.

3. **Проблема времени:** Категория $\mathbf{DensityMat}$ статична; время требует внешнего параметра.

### Статус Границ

Эти границы — **не недостаток**, а признание:
- Теория описывает *структуру*, а не отвечает на «почему именно эта структура»
- Некоторые вопросы могут быть *за пределами* любого возможного объяснения
- Честное признание границ — признак зрелой теории

**Сравнение с физикой:**
Физика не объясняет, *почему* существуют законы природы — она описывает их структуру. Аналогично, УГМ описывает структуру опыта, признавая границы объяснения.
