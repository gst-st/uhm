# Глоссарий

## Эксперименты

| Термин | Значение |
|---|---|
| Приготовление | Допустимая операция, предоставляющая исходную систему для опыта. |
| Прибор | Операция с наблюдаемым исходом и указанным выходом, доступным для последующих вмешательств. |
| Запись | Результат замкнутого опыта, доступный детектору. Это может быть символ, время, вероятность события или вся последовательность в порядке наблюдения. |
| Операциональное состояние | Класс приготовлений, для которых записи совпадают во всех допустимых тестах. |
| Слой наблюдения | Множество предполагаемых состояний, совместимых с одними показаниями при данной калибровке. |
| Идентифицируемость | Величина определена по записям, если она принимает одно значение на всём слое наблюдения. |
| Укрупнение исходов | Считывание функции от результата прибора. При объединении исходов одного прибора их вероятности складываются. |
| Калибровочное преобразование | Локальная смена репера с соответствующими преобразованиями связей, материи и считывания. |
| Голономия | Перенос по замкнутому пути. Смена репера в начальной точке сопрягает оператор переноса. |
| Расстояние по отклику | Минимальная достижимая стоимость вмешательства из одного узла в другой при заданном протоколе. Обратимость с той же стоимостью требует отдельного условия. |

## Состояния, процессы и считывания {#таксономия-конфигураций-γ}

| Термин | Значение |
|---|---|
| Холон | Система, для которой модель задаёт входы, допустимые действия, состав и отклики. Смысл предложенных семантических ролей требует отдельного отождествления. |
| Матрица когерентности $\Gamma$ | Положительная матрица со следом один в выбранной квантовой реализации. Когерентности — её недиагональные элементы в указанном базисе. |
| Чистота $P$ | $\operatorname{Tr}\Gamma^2$. Для состояния в размерности $N$ лежит в $[1/N,1]$. |
| Канал | В квантовой модели процессов — линейное вполне положительное отображение, сохраняющее след. В общем операциональном описании процессы сравнивают во всех допустимых контекстах. |
| Дефазировка | Ослабление когерентностей в заданном базисе. Величина ослабления зависит от канала и прошедшего времени. |
| Замена | Канал $X\mapsto\operatorname{Tr}(X)\sigma$ с заданной целью $\sigma$. Частичная замена смешивает его с другим каналом. |
| Стационарное состояние и аттрактор | Стационарное состояние сохраняется при эволюции. У аттрактора дополнительно есть область начальных условий, из которых траектории к нему приближаются. |
| Часы | Регистр с различимыми показаниями и физической калибровкой. Для обусловливания по Пейджу–Вуттерсу задают часовой фактор, совместное состояние, считывание и связь. |
| Инцидентность и фазовый зазор Gap | Инцидентность Фано определяет, какие базисные тройки образуют прямые. Фазовый зазор — заданная функция фазы ненулевой когерентности в выбранном репере. Численная фаза не задаёт кривизны пространства-времени. |
| Фильтр и запас | Фильтр выделяет состояния по указанным неравенствам. Запас измеряет расстояние или отклонение от границы в заданных единицах. |
| Репер семи ролей | Координатные метки $A,S,D,L,E,O,U$. Для отождествления с частями физического прибора нужна калибровка. |
| Рефлексия, интеграция, дифференциация | $R$, $\Phi$, $D_{\rm diff}$ — считывания модели со своими областями определения и соглашениями. Их связь с отчётом остаётся эмпирической гипотезой. |
| L0–L4 | Метки предложенной иерархии интериорности. Условия расчёта метки, предел возможностей выбранного устройства и свидетельства переживания требуют разных оснований. |
| Интенсивность, качество, контекст, история | Предлагаемые компоненты описания переживания. Экспериментальный смысл задают отчёт, допустимые вмешательства и правило наблюдения. |

## Математические структуры {#категорные-термины}

**Категория** задаёт объекты, композицию стрелок и тождества. **Функтор** также отображает стрелки, сохраняя тождества и композицию. В **терминальный объект** из каждого объекта ведёт единственная стрелка. В категории конечных квантовых процессов тривиальный выход представляет отбрасывание системы. **Неподвижная точка** конкретного канала — другой тип объекта.

**Сайт** задаёт допустимые покрытия. **Пучок** определяет ограничения и единственную склейку согласованных локальных данных. В открытом сайте Бюреса покрытие задаётся объединением открытых множеств матриц плотности. **Кодировщик** отображает наблюдаемые системы в пространство состояний. Симметрии пространства значений сами по себе не фиксируют это отображение. [Математическое ядро](./mathematical-kernel).

## Физические конструкции и сравнения {#связанные-теории}

**Октонионы** образуют восьмимерную вещественную нормированную алгебру с делением. Семь мнимых базисных единиц задаются ориентированной таблицей Фано. Стабилизатор отмеченной мнимой единицы изоморфен $SU(3)$. **Фермионный бимодуль** несёт согласованные левое и правое действия алгебры. В физической спектральной модели нужны дополнительные данные о представлении материи, внутреннем операторе Дирака, калибровочном действии и связях Юкавы. [Октонионная структура](../physics/gauge-symmetry/g2-structure) · [Калибровочные представления](../physics/gauge-symmetry/standard-model).

**Текстура Фрича** задаёт расположение нулей в матрицах масс в одном базисе ароматов. Она допускает проверку по независимым измерениям масс и смешивания. **Инфракрасная фокусировка** описывает ослабление чувствительности бегущей связи к её начальному значению при указанной динамике. Измеренную массу не задаёт само определение ни одного из этих понятий. [Проверка по смешиванию](../physics/particle-physics/ckm-matrix#derivation-vus) · [Связи Юкавы](../physics/particle-physics/yukawa-hierarchy).

У утверждений об этих структурах есть математическая область применимости и статус обоснованности. Определения, выбранные исходные данные, условные следствия и физические интерпретации указаны в [предпосылках](./premises) и [реестре статусов](./status-registry).
