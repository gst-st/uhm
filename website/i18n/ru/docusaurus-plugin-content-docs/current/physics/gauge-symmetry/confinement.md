# Конфайнмент и статический потенциал

## Измерение вдоль замкнутого контура {#теорема-закон-площади}

Зададим калибровочное поле $SU(3)$, представление пары статических источников и калибровочный ансамбль. Для прямоугольной петли Вильсона пространственного размера $L$ и евклидова времени $T$ разложение через трансфер-матрицу при ненулевом перекрытии с основным состоянием даёт $\langle W(L,T)\rangle\sim A(L)e^{-T V(L)}$ при больших $T$ с выбранным вычитанием собственных энергий источников. Линейный рост $V(L)=\sigma L+o(L)$ даёт вклад площади в логарифм петли. Сам этот рост требуется доказать или измерить в контролируемой области расстояний. С динамическими фундаментальными кварками струна может разорваться.

Стабилизатор отмеченной единицы октонионов задаёт абстрактную группу $SU(3)$. Связность пространства-времени, её действие и ансамбль требуют дополнительных данных. В заданной сети обратимого переноса обходы замкнутых контуров уже различают голономии. Сами обходы не определяют распределения связностей. [Наблюдения на циклах](../../networks/cycle-observations).

## Размерный масштаб натяжения {#диагностика-расхождения-σ}

В пробной модели $\sqrt\sigma=C|\gamma|^2\mu_\mathrm{phys}$ масштаб $\mu_\mathrm{phys}$ имеет единицы энергии. При фиксированных $C,\mu_\mathrm{phys}$ изменение $|\gamma|$ с $0.047$ до $0.13$ умножает результат примерно на $7.65$. Если какой-либо из параметров выбран по измеренному натяжению, это измерение уже использовано для калибровки. Независимая проверка потребовала бы зафиксировать оба параметра отдельно и предсказать статический потенциал на больших расстояниях.

В теории с массивными кварками инвариантная фаза сильного CP-нарушения зависит от калибровочного $\theta$-члена и фазы определителя кварковой матрицы масс. Вещественные коэффициенты отдельного потенциала оставляют эти данные свободными. Для сокращения калибровочных аномалий нужно вычислить следы в киральном представлении всех полей материи.
