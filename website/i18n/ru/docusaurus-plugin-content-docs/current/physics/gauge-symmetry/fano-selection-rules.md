# Правило отбора в базисе Фано

## Носитель трёхлинейной формы {#теорема-фано-отбор-fijk}

В ортонормированном базисе мнимых октонионов положим $f_{ijk}=\langle e_i e_j,e_k\rangle$. Для различных базисных единиц ненулевые компоненты приходятся ровно на прямые Фано и равны $+1$ или $-1$ в зависимости от порядка индексов. Отметим $E=5$ и $U=6$. Единственный третий индекс — $A=1$, поскольку $(5,6,1)$ образует прямую. Следовательно, $f_{1EU}=1$, а для любого $k\ne1$ выполняется $f_{kEU}=0$. Для другой пары тот же расчёт укажет другую компоненту. [Таблица умножения](./g2-structure#октонионное-умножение-и-g2).

## От компоненты к взаимодействию {#каппа-по-подавленным}

В модели можно задать одну из вершин формулой $y_k=c\,f_{kEU}$. При фиксированных осях это определяет расположение нулей и оставляет $c$ свободным. Расчёт требует размеченного репера. При смене репера нужно согласованно преобразовать тензор, внешние состояния и измерение вершины.

Для вывода иерархии масс нужны соответствие индексов физическим полям, их калибровочные заряды, вакуум Хиггса и остальные допустимые члены взаимодействия. Дополнительная инвариантная связь может изменить матрицу масс при той же таблице Фано. Для петлевой оценки нужны также пропагаторы, нормировки вершин и область применимости теории возмущений.
