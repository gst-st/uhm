# Правило отбора в базисе Фано

## Носитель трёхлинейной формы {#теорема-фано-отбор-fijk}

В ортонормированном базисе мнимых октонионов положим $f_{ijk}=\langle e_i e_j,e_k\rangle$. Для различных базисных единиц ненулевые компоненты приходятся ровно на прямые Фано и равны $+1$ или $-1$ в зависимости от порядка индексов. Отметим $E=5$ и $U=6$. Единственный третий индекс — $A=1$, поскольку $(5,6,1)$ образует прямую. Следовательно, $f_{1EU}=1$, а для любого $k\ne1$ выполняется $f_{kEU}=0$. Для другой пары тот же расчёт укажет другую компоненту. [Таблица умножения](./g2-structure#октонионное-умножение-и-g2).

## От компоненты к взаимодействию {#каппа-по-подавленным}

В модели можно задать одну из вершин формулой $y_k=c\,f_{kEU}$. При фиксированных осях это определяет расположение нулей и оставляет $c$ свободным. Расчёт требует размеченного репера. При смене репера нужно согласованно преобразовать тензор, внешние состояния и измерение вершины.

Для вывода иерархии масс нужны соответствие индексов физическим полям, их калибровочные заряды, вакуум Хиггса и остальные допустимые члены взаимодействия. Дополнительная инвариантная связь может изменить матрицу масс при той же таблице Фано. Для петлевой оценки нужны также пропагаторы, нормировки вершин и область применимости теории возмущений. [Матрицы Юкавы](../particle-physics/yukawa-hierarchy).

## Конструктивный изоморфизм $\mathrm{PSL}(2,\mathbb{F}_7) \simeq \mathrm{GL}(3,\mathbb{F}_2) = \mathrm{Aut}(\mathrm{PG}(2,2))$ {#psl2-7-fano-bridge}

Группа автоморфизмов плоскости Фано $\mathrm{PG}(2,2)$ даёт точный безаксиомный алгебро-геометрический мост к модулярной флейворной симметрии намагниченного орбифолда тора $M = 7$ (`verify_deep_frontier_v8.py`, `ToEFrontierV8.lean`):

1. **Безаксиомный конструктивный изоморфизм групп (`gl3_f2_generators_psl2_7_relations`, `gl3_f2_order_168_generated_by_psl2_7`) [Т]:** Явные двоичные $3\times 3$-матрицы $A_S, A_T \in \mathrm{GL}(3,\mathbb{F}_2)$ удовлетворяют $\det = 1$ и всем четырём соотношениям Гурвица для $\mathrm{PSL}(2,7)$ ($A_S^2 = I$, $A_T^7 = I$, $(A_S A_T)^3 = I$, $(A_S A_T^4)^4 = I$), сохраняют все 7 коллинеарных прямых Фано и разбивают все $168$ элементов $\mathrm{GL}(3,\mathbb{F}_2)$ на $8$ непересекающихся классов Брюа по $21$-элементной борелевской подгруппе Фробениуса $B_{21}$ ($8 \times 21 = 168$).
2. **Точная эквивалентность характеров и квартика Клейна (`sym2_three_eq_fano_six_and_singer_trace`) [Т]:** При этой биекции симметричное юкавское пространство $\mathrm{Sym}^2(H_3^-)$ трёх нечётных поколений Ландау на $(T^2/\mathbb{Z}_2, M=7)$ изоморфно по характерам нетривиальному фановскому гармоническому пространству $\mathbb{C}[\mathrm{PG}(2,2)]/\mathbb{C}\cdot 1 \cong \mathbf{6}$ на всех 168 элементах группы ($\max\lvert\Delta\chi\rvert = 7{,}94\times 10^{-14}$), 7-цикл Зингера $A_T$ не оставляет неподвижных точек, инволюция $A_S$ фиксирует $3$ точки (одну прямую Фано), а квартика Клейна $K(z) = -z_1^3 z_2 + z_2^3 z_3 + z_3^3 z_1$ строго инвариантна (ошибка $1{,}1\text{–}3{,}2\times 10^{-15}$).
3. **Открытый динамический мост [П]:** Построение явного динамического отображения компактификации от 7D $G_2$-голона к намагниченному орбифолду $(T^2/\mathbb{Z}_2, M=7)$ остаётся открытым.
