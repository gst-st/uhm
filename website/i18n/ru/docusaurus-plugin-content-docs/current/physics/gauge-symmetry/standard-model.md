# Стандартная модель из G₂

:::info Для кого эта глава
Вывод калибровочной группы Стандартной Модели из $G_2 = \mathrm{Aut}(\mathbb{O})$. Читатель узнает о стратегии двойственного извлечения $\mathrm{SU}(3)_C$ и электрослабого сектора.
:::


## Обзор

:::info[Что означает заголовок]
$\mathrm{rank}(G_2) = 2 < \mathrm{rank}(\mathrm{SM}) = 4$, поэтому калибровочная группа SM **не является подгруппой** $G_2$. Страница получает её из $G_2$ **и** конструкций вне $G_2$; после отзыва 25.09.2026 (множества осей $\{A,S,D\}$, $\{L,E,U\}$ — не $\mathbf 3$ и не $\bar{\mathbf 3}$ группы $\mathrm{SU}(3)$, Теорема 1.1(a) ниже) статусы таковы:
- $\mathrm{SU}(3)_C$ из $G_2$ как стабилизатор O-направления — **[Т]** как математика ($\mathrm{Stab}_{G_2}(e_O)\cong\mathrm{SU}(3)$; приоритет Гюнайдына — Гюрсея, 1973); её прочтение как цвета — **[И]**
- Электрослабый сектор $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ из Фано-электрослабой конструкции (ФЭ): пара $(E,U)$ из $\kappa_0$ и проходящая через неё линия $\{A,E,U\}$ — **[Т]** комбинаторика; группа и её единственность — **[С при (ФЭ)]**, где (ФЭ) — допущение, что электрослабая группа действует на $\mathrm{span}\{L,E,U\}$ системного фактора Пейджа–Вуттерса; этот вход прежде поставляло отозванное разбиение «$\bar{\mathbf 3}=\{L,E,U\}$»
- Полное соответствие «SM из $G_2$ + (ФЭ)» — **[С]** (электрослабая динамика условна)
- **Исправленный путь (25.09.2026, [§2.5](#sm-из-клиффорда)):** на $\mathbb{C}\otimes\mathbb{O}$ — гильбертовом пространстве УГМ плюс параллельный спинор — октонионная система Клиффорда вынуждена и порождает $\mathfrak{spin}(9)$. Централизатор цвета в ней — $\mathfrak{u}(2)$, а вся группа — $(\mathrm{SU}(3)\times\mathrm{SU}(2)\times\mathrm{U}(1))/\mathbb{Z}_6$ с гиперзарядами $\tfrac16$ и $-\tfrac12$ на левых дублетах. Это **[Т]** как математика (T-326; приоритет Тодорова — Дюбуа-Виолетта 2018 и Краснова 2021) и **[С при (Кл)]** как результат УГМ. Хиральность дублетов — T-327. Поколения должны быть горизонтальны — T-328. Комплексифицированный спинор несёт вынужденную десятую образующую и одно полное поколение с $\nu_R$ без аномалий; в нём $\mathrm{SU}(2)$ из T-326 — диагональ $\mathrm{SU}(2)_L\times\mathrm{SU}(2)_R$, и $B-L$ возвращается — T-329 ([§2.6](#поколение-t329))
:::

Центральная задача — вывод калибровочной группы Стандартной Модели $\mathrm{SU}(3)_C \times \mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ из $G_2 = \mathrm{Aut}(\mathbb{O})$. Стратегия двойственна: $\mathrm{SU}(3)_C$ извлекается из стабилизатора O-направления в $G_2$, а электрослабый сектор $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ — из Фано-электрослабой конструкции (ФЭ) на паре $(E,U)$ и Хиггсовой линии $\{A,E,U\}$. (Прежняя фраза «Хиггсова линия канонически разлагает $\bar{3} \to \{E,U\} \oplus \{L\}$» отозвана [✗]: $\{L,E,U\}$ — не $\bar{\mathbf 3}$.)

:::tip[Статус: \[Т\] для SU(3)\_C]
$\mathrm{SU}(3)_C$ из $G_2$ — стандартный математический факт.
:::

:::tip[Статус: \[Т\] для комбинаторики электрослабого сектора; группа — \[С при (ФЭ)\]]
Формула $\kappa_0$ [Т] категориально выделяет **единственную** пару $(E,U)$ через $\mathrm{Hom}(O,E)$ и $\mathrm{Hom}(O,U)$, а единственная Фано-линия через $E$ и $U$ — $\{A,E,U\}$; то и другое [Т]. То, что эти данные определяют $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$, — [С при (ФЭ)]; шаг «Хиггсова линия канонически разлагает $\bar{3} \to \{E,U\} \oplus \{L\}$», на котором это держалось, отозван [✗]. Доказательство и его статус: [разд. 2.3a](#теорема-единственности-фэ).
:::

:::warning Разграничение [Т] и [С] в электрослабом секторе {#электрослабое-разграничение}
Следует чётко разделять два уровня результатов:

- **[Т] (доказано):** комбинаторная единственность пары $(E,U)$ из $\kappa_0$, единственность Хиггсовой линии $\{A,E,U\}$. Указанная здесь прежде «каноническая декомпозиция $\bar{3} \to 2_{EU} \oplus 1_L$» отозвана [✗]
- **[С] (условно):** полная динамическая калибровочная структура $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ с корректным бегом констант связи — зависит от динамического содержания (Gap-потенциал, RG-уравнения), выходящего за рамки чистой комбинаторики
- **Свободный параметр:** генератор гиперзаряда $Y$ содержит параметр $\alpha$ (относительный вес барионного числа и слабого изоспина внутри $\bar{3}$), значение которого не фиксируется Фано-структурой и требует дополнительного условия (например, из аномальной свободы или феноменологии)
:::

## 1. Анатомия $G_2$ и проблема ранга

### 1.1 Постановка

**Фундаментальное препятствие.** $\mathrm{rank}(G_2) = 2$, а $\mathrm{rank}(\mathrm{SU}(3) \times \mathrm{SU}(2) \times \mathrm{U}(1)) = 2 + 1 + 1 = 4$. Следовательно, SM-группа **не является подгруппой** $G_2$.

**Стратегия.** Преодолеть препятствие через два механизма:
- (A) $\mathrm{SU}(3)_C$ из стабилизатора O-направления в $G_2$ — **[Т]** (структурная симметрия, rank $2 \to$ rank 2)
- (B) $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ из Фано-электрослабой конструкции (ФЭ) на системном факторе Пейджа–Вуттерса — **[С при (ФЭ)]** (пара $(E,U)$ из $\kappa_0$ — [Т]; добавляет rank 2 в 42D PW-расширении). Прежнее «Хиггсова линия канонически разлагает $\bar{3} \to \{E,U\} \oplus \{L\}$ — [Т]» отозвано [✗]

### 1.2 Теорема 1.1 (Разложение $G_2$-генераторов под $\mathrm{SU}(3)$)

:::tip[Статус: Теорема \[Т\]]
Максимальное вложение $\mathrm{SU}(3) \subset G_2$ (стабилизатор вектора в $\mathrm{Im}(\mathbb{O}) \cong \mathbb{R}^7$) определяет разложение.
:::

**(a)** Представление **7** (фундаментальное). Над $\mathbb{R}$: $\mathbf 7\to\mathbf 1\oplus\mathbf 6$, где $\mathbf 6$ неприводимо и комплексного типа (комплексная структура — левое умножение на $e_O$, спаривающее $A\leftrightarrow D$, $S\leftrightarrow U$, $L\leftrightarrow E$). Над $\mathbb{C}$ **[Т]**:

$$7 \to 1_O \oplus \mathbf 3 \oplus \bar{\mathbf 3},\qquad \mathbf 3=\mathrm{span}_{\mathbb C}\{A-iD,\ S-iU,\ L-iE\},\quad \bar{\mathbf 3}=\overline{\mathbf 3}.$$

Прежние метки $3_{ASD}=\{A,S,D\}$ («пространственный триплет») и $\bar{3}_{LEU}=\{L,E,U\}$ («Gap-триплет») **отозваны [✗]** (25.09.2026): ни одна из 20 троек осей, отличных от $O$, не натягивает $\mathrm{SU}(3)$-инвариантного подпространства (`test_no_axis_triple_is_su3_invariant` в `website/scripts/check_core_numbers.py`). Приоритет расщепления и его прочтения как цвета — Гюнайдын и Гюрсей, 1973 ([G₂-структура, §2.6](/docs/physics/gauge-symmetry/g2-structure#прецеденты-g2)). Пространственной оси нет. Пространственные направления, вращения которых коммутируют с этой $\mathrm{SU}(3)$, существуют лишь вне $\mathrm{Im}\,\mathbb O$: это цветово-синглетная часть $\mathfrak h_2(\mathbb C_O)$ спин-фактора $\mathfrak h_2(\mathbb O)$ ([Пространство-время, теорема 48c](/docs/core/foundations/spacetime#теорема-48c), [Т] как математика, [С при (Q)] как пространство-время).

**(b)** Присоединённое представление **14** (алгебра $\mathfrak{g}_2$):

$$14 \to 8 \oplus 3 \oplus \bar{3}$$

где $8$ — присоединённое представление $\mathrm{SU}(3)$ (генераторы $\mathrm{SU}(3)$), $3$ и $\bar{3}$ — фундаментальные представления.

**(c)** — **отозвано [✗] как распределение пар осей.** Кратности верны: над $\mathbb{C}$ $\Lambda^2(\mathbf 1\oplus\mathbf 3\oplus\bar{\mathbf 3})=\mathbf 8\oplus\mathbf 1\oplus2\cdot\mathbf 3\oplus2\cdot\bar{\mathbf 3}$ (21 измерение). Но множества пар в таблице ниже — не инвариантные подпространства: у $\mathrm{SU}(3)$-инвариантной матрицы $7\times7$ недиагональные элементы есть только на $(A,D)$, $(S,U)$, $(L,E)$ (`test_su3_invariant_states_are_coherent_only_on_o_line_pairs`). Запись отозванной таблицы:

| Сектор | Пары | Число | $\mathrm{SU}(3)$-представление |
|---|---|---|---|
| O-to-3 | $\{A\text{-}O, S\text{-}O, D\text{-}O\}$ | 3 | $3$ |
| O-to-$\bar{3}$ | $\{L\text{-}O, E\text{-}O, U\text{-}O\}$ | 3 | $\bar{3}$ |
| 3-to-3 | $\{A\text{-}S, A\text{-}D, S\text{-}D\}$ | 3 | $\bar{3}$ ($\wedge^2 3$) |
| $\bar{3}$-to-$\bar{3}$ | $\{L\text{-}E, L\text{-}U, E\text{-}U\}$ | 3 | $3$ ($\wedge^2 \bar{3}$) |
| **3-to-$\bar{3}$** | **$\{A\text{-}L, A\text{-}E, A\text{-}U, S\text{-}L, S\text{-}E, S\text{-}U, D\text{-}L, D\text{-}E, D\text{-}U\}$** | **9** | **$8 \oplus 1$** |

**(d)** ~~Сектор 3-to-$\bar{3}$ содержит **присоединённое представление $\mathrm{SU}(3)$** (8 генераторов) плюс **$\mathrm{SU}(3)$-синглет** (1 генератор).~~ Отозвано [✗] вместе с (c): девять пар $\{A,S,D\}\times\{L,E,U\}$ не натягивают $\mathbf 8\oplus\mathbf 1$. Верно (b): восемь генераторов $\mathfrak{su}(3)$ — число глюонов в QCD.

**Доказательство.** Стандартная теория представлений исключительных алгебр Ли. Вложение $\mathrm{SU}(3) \subset G_2$ определяется стабилизатором: $\mathrm{Stab}_{G_2}(e_1) \cong \mathrm{SU}(3)$ для любого единичного вектора $e_1 \in S^6 \subset \mathrm{Im}(\mathbb{O})$. Разложение **7** следует из того, что $\mathrm{SU}(3)$ действует тривиально на $e_1$ (синглет) и как фундаментальное/антифундаментальное на ортогональном дополнении. Разложение **14** следует из структурной теоремы для пар $(G_2, \mathrm{SU}(3))$:

$$\mathfrak{g}_2 = \mathfrak{su}(3) \oplus \mathfrak{m}, \quad \mathfrak{m} \cong \mathbb{C}^3$$

где $\mathfrak{m}$ — ортогональное дополнение, изоморфное $3 \oplus \bar{3}$ как $\mathrm{SU}(3)$-модуль (Бессе, 1987). Для сектора (c): 21 пара $= C(7,2)$ разлагается по правилам тензорного произведения представлений $\mathrm{SU}(3)$. Сектор $3 \otimes \bar{3} = 8 \oplus 1$ — стандартное разложение (Клебш–Гордан). $\blacksquare$

### 1.3 Следствие 1.1 ($\mathrm{SU}(3)_C$ как стабилизатор времени)

:::tip[Статус: Теорема \[Т\]]
Выбор O-измерения как «часов» (Пейдж–Вуттерс, Аксиома 4) спонтанно нарушает $G_2 \to \mathrm{SU}(3)$.
:::

:::info Фундаментальность $G_2$-калибровки [Т]
$G_2$ — не произвольно выбранная симметрия, а **единственная максимальная калибровочная группа** УГМ, доказанная в [теореме $G_2$-ригидности](/docs/proofs/categorical/uniqueness-theorem#лемма-g4) [Т]: никакая большая подгруппа $U(7)$ не сохраняет все аксиоматические структуры. Следовательно, вся структура SM (нарушение $G_2 \to \mathrm{SU}(3)_C$, электрослабый сектор) — **необходимое** следствие единственности голономного представления, а не параметрический выбор.
:::

## 2. Электрослабый сектор из Фано-электрослабой конструкции (ФЭ) {#электрослабый-сектор-фэ}

### 2.1 Проблема ранга и её решение {#проблема-ранга}

**Проблема.** $\mathrm{rank}(\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y) = 2$, но после выделения $\mathrm{SU}(3) \subset G_2$ (rank 2) не осталось rank для электрослабого сектора — $G_2$ уже «израсходована».

**Решение через два механизма:**

| Механизм | Источник | Результат | Статус |
|---|---|---|---|
| $G_2 \to \mathrm{SU}(3)_C$ | Стабилизатор O-направления | rank 2 — сильное взаимодействие | **[Т]** |
| Фано-электрослабая конструкция (ФЭ) | Хиггсова линия $\{A,E,U\}$ | rank 2 — электрослабое взаимодействие | **[С при (ФЭ)]** (комбинаторика пары $(E,U)$ — [Т]; динамика [С]) |

**Анализ в 7D — отозван [✗] и заменён.** Прежний анализ читал $\bar{3} = \{L,E,U\}$ как антитриплет, считал $\lvert E\rangle\langle E\rvert - \lvert U\rangle\langle U\rvert$ одним из его генераторов Картана и заключал, что в 7D $\mathrm{SU}(2)_L$ — подгруппа «$\mathrm{SU}(3)_{\bar{3}}$». Обе посылки ложны: антитриплет натянут на $A+iD$, $S+iU$, $L+iE$, а генераторы $\mathrm{SU}(3)\subset G_2\subset\mathrm{SO}(7)$ — вещественные антисимметричные матрицы, каковой вещественная диагональная матрица не является. Что верно в 7D: $\mathrm{SU}(2)$, порождённая $T_{1,2,3}$ на $\mathrm{span}\{E,U\}$, **не** коммутирует с $\mathrm{SU}(3)_C$ (численно $\max_a\|[T_a,X]\|=3.6$ по базису $X$ алгебры $\mathfrak{su}(3)$), а лемма Шура даёт централизатор $\mathrm{SU}(3)_C$ в $\mathrm{U}(7)$ равным $\mathrm{U}(1)^3$ (размерность 3, проверено) — никакой $\mathrm{SU}(2)$ в нём нет. В 7D электрослабая группа (ФЭ) и цветовая группа, следовательно, не могут сосуществовать как коммутирующие множители.

**Разрешение в 42D:** В Пейдж–Вуттерс расширении (Аксиома A5):

$$\mathcal{H}_{\mathrm{total}} = \mathcal{H}_O \otimes \mathcal{H}_{6D} = \mathbb{C}^7 \otimes \mathbb{C}^6 = \mathbb{C}^{42}$$

$\mathrm{SU}(3)_C$ (от $G_2$ на часовом факторе) и $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ (от (ФЭ) на системном факторе) действуют на **разные** тензорные множители, поэтому коммутируют и rank складывается: $2 + 2 = 4 = \mathrm{rank}(\mathrm{SM})$. Статус: **[С при (ФЭ)]** при аксиоме A5 (Пейдж–Вуттерс). Сама коммутация здесь тривиальна — любые две группы на разных тензорных множителях коммутируют — и это единственный смысл, в котором две группы коммутируют; в 7D они не коммутируют (выше).

:::warning Бимодульная конструкция — отозвана как вывод [✗] (25.09.2026)
Этот бокс гласил «Решено [Т]»: SM-представления $(3,2)_{1/6}$ возникают **не** из тензорного произведения $\mathbb{C}^7 \otimes \mathbb{C}^6$, а из **бимодульного разложения** $H_F$ через реальную структуру $J$ (KO-dim 6) — левое действие $\mathbb{H}$ даёт слабый изоспин, правое $M_3(\mathbb{C})^\circ$ — цвет ([Бимодульная конструкция, T-178](/docs/proofs/physics/bimodule-construction#бимодульная-конструкция); бокс ссылался на неё как на «T-176»). Механизм принадлежит Конну и работает для его $A_F$, действующей на его $H_F$ (96 состояний для трёх поколений). Из тройки УГМ он не выведен: $H_{\text{int}}=\mathbb{C}^7$ не вмещает 16 состояний одного поколения, переход $A_{\text{int}}\to A_F$ опирался на утверждение о Морита-эквивалентности T-175a (отозвано), а $J$ = комплексное сопряжение не имеет KO-размерности 6 ([пространство-время, Шаг 6](/docs/core/foundations/spacetime#теорема-спектральная-тройка)). Статус представлений в УГМ: импортированы, а не выведены.
:::

### 2.2 Фановская структура и Хиггсова линия {#фановская-структура}

Семь Фано-линий $\mathrm{PG}(2,2)$ (с отождествлением $\{1,2,3,4,5,6,7\} = \{A,S,D,L,E,U,O\}$):

| Фано-линия | Измерения | Тип |
|---|---|---|
| $\{1,2,4\}$ | $\{A,S,L\}$ | Генерационный триплет |
| $\{2,3,5\}$ | $\{S,D,E\}$ | Цветовой-Gap мост |
| $\{3,4,6\}$ | $\{D,L,U\}$ | Цветовой-Gap мост |
| $\{4,5,7\}$ | $\{L,E,O\}$ | Временной-Gap |
| **$\{5,6,1\}$** | **$\{E,U,A\}$** | **Хиггсова линия** |
| $\{6,7,2\}$ | $\{U,O,S\}$ | Временной-Gap |
| $\{7,1,3\}$ | $\{O,A,D\}$ | Временной-пространственный |

Хиггсова линия $\{A,E,U\} = \{5,6,1\}$ — **единственная** Фано-линия, содержащая оба электрослабых измерения $E$ и $U$ (доказано в разд. 9.2, [Т]).

**Классификация по отношению к множествам осей $\{O\}$, $\{A,S,D\}$, $\{L,E,U\}$** (только комбинаторика инцидентности: эти множества — не секторы $\mathrm{SU}(3)$, Теорема 1.1(a); ниже «3» и «$\bar 3$» — имена двух множеств осей):

| Тип | Фано-линии | Число | Характеристика |
|-----|-----------|-------|----------------|
| O-линии | $\{L,E,O\}$, $\{U,O,S\}$, $\{O,A,D\}$ | 3 | Проходят через O |
| Смешанные | $\{A,S,L\}$, $\{S,D,E\}$, $\{A,E,U\}$ | 3 | Содержат элементы из 3 и $\bar{3}$, не проходят через O |
| Привязана к $\bar{3}$ | $\{D,L,U\}$ | 1 | Две точки в $\bar{3}$ ($L,U$), одна в $3$ ($D$) |

:::note Симметрия 3 и 3̄ [Т]
**Ни одна** Фано-линия не лежит целиком в $3 = \{A,S,D\}=\{1,2,3\}$ **и** ни одна — целиком в $\bar{3} = \{L,E,U\}=\{4,5,6\}$: ни $\{1,2,3\}$, ни $\{4,5,6\}$ не являются Фано-линиями. Каждая из четырёх не-O линий пересекает **оба** сектора — например, $\{D,L,U\}=\{3,4,6\}$ имеет $D\in 3$ и $L,U\in\bar 3$. Прежнее утверждение «$\{D,L,U\}$ целиком внутри $\bar 3$» было ошибкой о принадлежности сектору ($D\in 3$). Разбиение $3$/$\bar 3$ симметрично на уровне инцидентности; секторная асимметрия возникает лишь динамически (через связь с O-сектором), а не комбинаторно.
:::

### 2.3 Теорема 2.1 (Фано-электрослабая конструкция) {#теорема-фэ}

:::tip[Статус: \[С при (ФЭ)\]; пара $(E,U)$ и Хиггсова линия — \[Т\]]
Хиггсова линия $\{A,E,U\}$ и пара $(E,U)$, выделенная формулой $\kappa_0$ [Т], определяют электрослабую калибровочную симметрию $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ **при (ФЭ)**: электрослабая группа действует на $\mathrm{span}\{L,E,U\}$ системного фактора Пейджа–Вуттерса. До 25.09.2026 этот бокс гласил «Теорема [Т]», а (ФЭ) обеспечивалось прочтением $\{L,E,U\}$ как $\bar{\mathbf 3}$ группы $\mathrm{SU}(3)$; это прочтение отозвано (Теорема 1.1(a)). См. [разд. 2.3a](#теорема-единственности-фэ).
:::

**Фано-электрослабая конструкция (ФЭ).** *При (ФЭ) расщепление $\mathrm{span}\{L,E,U\}$ на $\mathrm{span}\{E,U\}\oplus\mathrm{span}\{L\}$, выделенное Хиггсовой линией $\{A,E,U\}$, несёт эффективную калибровочную симметрию электрослабого сектора [С при (ФЭ)].* Прежняя формулировка — «каноническая декомпозиция $\bar{3} \to 2_{EU} \oplus 1_L$ … определяет **единственную** эффективную калибровочную симметрию [Т]» — отозвана [✗].

**(a)** ~~Антифундаментальный триплет $\bar{3}_{LEU} = \{L, E, U\}$ разлагается по Хиггсовой линии, $\bar{3}_{LEU} \to 2_{EU} \oplus 1_L$~~ — отозвано [✗]: $\{L,E,U\}$ — не антифундаментальный триплет. Что остаётся [Т]: пара $\{E,U\}$ выделена формулой $\kappa_0$ и лежит ровно на одной Фано-линии, $\{A,E,U\}$ (разд. 9.2). Расщепление $\mathrm{span}\{L,E,U\}=\mathrm{span}\{E,U\}\oplus\mathrm{span}\{L\}$ на дублет $2_{EU}$ и синглет $1_L$ — тогда определение [О] на системном факторе.

**(b)** Калибровочная структура с явными генераторами:

$\mathrm{SU}(2)_L$ — 3 генератора (вращения в $\{E,U\}$-подпространстве):

$$
T_1 = \frac{1}{2}(\lvert E\rangle\langle U\rvert + \lvert U\rangle\langle E\rvert), \quad T_2 = \frac{1}{2i}(\lvert E\rangle\langle U\rvert - \lvert U\rangle\langle E\rvert), \quad T_3 = \frac{1}{2}(\lvert E\rangle\langle E\rvert - \lvert U\rangle\langle U\rvert)
$$

$\mathrm{U}(1)_Y$ — 1 генератор (слабый гиперзаряд):

$$
Y = \frac{1}{3}\left(\sum_{i \in 3} \lvert i\rangle\langle i\rvert - \sum_{j \in \bar{3}} \lvert j\rangle\langle j\rvert\right) + \alpha\left(\lvert L\rangle\langle L\rvert - \frac{1}{2}(\lvert E\rangle\langle E\rvert + \lvert U\rangle\langle U\rvert)\right)
$$

где первое слагаемое — аналог барионного числа (оно различает множества осей $\{A,S,D\}$ и $\{L,E,U\}$, названные «3» и «$\bar{3}$»), второе — слабый изоспин внутри $\{L,E,U\}$ (различает $1_L$ и $2_{EU}$). Итого: 4 генератора = $\dim(\mathrm{SU}(2) \times \mathrm{U}(1))$. Заметим, что в 7D первое слагаемое не коммутирует с $\mathrm{SU}(3)_C$: единственная $\mathfrak{u}(1)$ в $\mathfrak{so}(7)$, коммутирующая с $\mathfrak{su}(3)$, порождена векторным произведением $x\mapsto e_O\times x$ (левым умножением на $e_O$ на шести осях, ортогональных ему), которое не диагонально в осях и не лежит в $\mathfrak{g}_2$ (централизатор $\mathfrak{su}(3)$ в $\mathfrak{g}_2$ нулевой). Гиперзаряд, отделяющий $\mathbf 3$ от $\bar{\mathbf 3}$, лежит, следовательно, вне $G_2$.

Параметр α в генераторе гиперзаряда Y **не фиксирован** Фано-структурой. Единственность калибровочной группы SU(3)×SU(2)×U(1) — [С при (ФЭ)] (до 25.09.2026 заявлялась как [Т]); единственность гиперзарядового вложения — [С при фиксации α из аномалийной свободы или феноменологии].
:::

### 2.3a Теорема единственности электрослабой конструкции {#теорема-единственности-фэ}

:::tip[Статус: конструкция \[С при (ФЭ)\]; единственность \[Г\] в осевой картине и \[С при (Кл)\] через T-326; отождествление \[И\]]
Утверждается, что калибровочная группа SM $G_{\mathrm{SM}} = \mathrm{SU}(3)_C \times \mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ является **единственной** калибровочной группой ранга 4, совместимой со структурой Фано-плоскости и $G_2$-симметрией. Статус с 25.09.2026: конструкция ниже — [С при (ФЭ)]; единственность — [Г]: Шаг 3 не является классификацией (см. там), а теоремы единственности для $\mathrm{SU}(2)\times\mathrm{U}(1)$ в литературе нет; прежний статус «[Т]+[И]» отозван [✗]. Через систему Клиффорда на $\mathbb{C}\otimes\mathbb{O}$ ([§2.5](#sm-из-клиффорда), T-326) единственность верна как теорема конструкции, [С при (Кл)]: электрослабая алгебра — централизатор цвета в $\mathfrak{spin}(9)$, и альтернативы у неё нет. Ключевой элемент — категориальная единственность пары $(E,U)$ из формулы $\kappa_0$ [Т]. Отождествление абстрактных генераторов с физическими калибровочными полями SM — **[И]** (интерпретативный шаг).
:::

**Утверждение (Единственность электрослабой конструкции) — [С при (ФЭ)] для конструкции, [Г] для единственности.** При аксиомах A1–A5 и (ФЭ) калибровочная группа Стандартной Модели
$$G_{\mathrm{SM}} = \mathrm{SU}(3)_C \times \mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$$
является **единственной** калибровочной группой ранга 4, совместимой со структурой Фано-плоскости и $G_2$-симметрией.


#### Следствие: запрет ранга 4 — нет Z′ и пятой силы [Г] (T-297) {#запрет-z-прайм}

Прежний текст: единственность $G_{\mathrm{SM}}$ как группы **ранга 4**, совместимой с Фано + $G_2$, запрещает всякое калибровочное расширение старшего ранга: любой дополнительный калибровочный $\mathrm{U}(1)$ — $Z'$, калибровочный $B{-}L$, калибровочный «тёмный фотон» — поднял бы ранг до 5, а подгрупп ранга 5 инцидентная структура не допускает, так что коллайдерные и dark-sector поиски *калибровочного* $Z'$ останутся пустыми «при любой энергии». Понижено до **[Г]** (25.09.2026): единственность, на которой это держится, — [Г] (выше), а октонионные маршруты, действительно выводящие структуру Стандартной модели, заканчиваются лишним $\mathrm{U}(1)$: Фьюри и Хьюз получают из алгебраического нарушения симметрии «Стандартную модель + $B-L$» (*Phys. Lett. B* **831**, 137186 (2022), [arXiv:2210.10126](https://arxiv.org/abs/2210.10126)), Бойл — лево-право-симметричное расширение (*J. Math. Phys.* **67**, 071701 (2026), [arXiv:2006.16265](https://arxiv.org/abs/2006.16265)). Калибровочная $B-L$, нарушенная около собственного seesaw-масштаба корпуса $M_R\sim3\times10^{14}$ ГэВ, дала бы $Z'$ далеко за пределами любого коллайдера, и корпус этого не исключает; «пустые поиски» тогда утверждение не проверяли бы. Защитимая форма [Г]: конструкция (ФЭ) не содержит лишнего калибровочного $\mathrm{U}(1)$; калибровочный $Z'$, найденный в пределах досягаемости коллайдеров, противоречил бы (ФЭ). (Стража нотации: величина $Z'_\Phi(-2)$ из [$\Lambda$-бюджета](/docs/proofs/gap/lambda-budget) — *производная дзета-регуляризатора Эпштейна*, не бозон.)

**Что решает клиффордова рамка и на каком масштабе выживает $B-L$ (T-329).** При (Кл) из [§2.5](#sm-из-клиффорда) вопрос решается счётом. (i) В секторе дублетов $Z'$ нет [С при (Кл)]: централизатор $G_{\mathrm{SM}}$ в $\mathrm{Spin}(9)$ — сама $\mathrm{U}(1)_Y$ (размерность 1, проверено), а большей системы Клиффорда на $\mathbb{C}\otimes\mathbb{O}$ не существует (девять образующих — максимум на $\mathbb{R}^{16}$). (ii) Правых полей в $\mathbb{C}\otimes\mathbb{O}$ нет. Они живут в его комплексификации $\mathbb{R}^{32}=(\mathbb{C}\otimes\mathbb{O})\otimes_{\mathbb{R}}\mathbb{C}'$, где десятая образующая вынуждена ([§2.6](#поколение-t329), Теорема 2.6(a)). Там централизатор цвета в $\mathfrak{spin}(10)$ имеет размерность 7, с одномерным центром и шестимерной производной алгеброй. Это $\mathfrak{su}(2)_L\oplus\mathfrak{su}(2)_R\oplus\mathfrak{u}(1)_{B-L}$, вместе с цветом ранг 5 (`test_left_right_extension_brings_b_minus_l`). Это лево-правый исход Бойла и «Standard model + $B-L$» Фьюри и Хьюза, полученные с другой стороны. Итак, $B-L$ выживает ровно тогда, когда синглеты входят через расширение Клиффорда, и масштаб её нарушения УГМ не фиксирует. Если майорановская масса $\nu_R$ возникает при нарушении $B-L$ с константой связи порядка единицы, то $v_{B-L}\gtrsim M_R\approx3\times10^{14}$ ГэВ — масштаб качелей [нейтринной страницы](/docs/physics/particle-physics/neutrino-masses#seesaw), — и $Z'_{B-L}$ весит порядка $10^{14}$ ГэВ, далеко за пределами коллайдеров. Поэтому T-297 стратифицируется. Нет $Z'$ в секторе дублетов — [С при (Кл)]. Нет $Z'$ в пределах досягаемости коллайдеров — [С при (Кл)] и нарушении $B-L$ на масштабе качелей. Нет $Z'$ ни при какой энергии — [Г]: калибровочная $B-L$ на $\sim10^{14}$ ГэВ — ожидаемый, а не исключённый исход расширения.

#### Рассуждение {#доказательство-единственности-фэ}

**Шаг 1. $\mathrm{SU}(3)_C$ из $G_2$ [Т] (существующий результат).**

Стабилизатор O-направления в $G_2$-представлении на $\mathbb{C}^7$ есть $\mathrm{SU}(3)$ [Т]. Под действием $G_2 \to \mathrm{SU}(3)$:
$$7 \to 3 \oplus \bar{3} \oplus 1$$
где $1 = O$, а $3=\mathrm{span}_{\mathbb C}\{A-iD,S-iU,L-iE\}$, $\bar 3$ — сопряжённое. (Прежнее «$3 = \{A, S, D\}$, $\bar{3} = \{L, E, U\}$» отозвано [✗], Теорема 1.1(a).) Rank$(\mathrm{SU}(3)_C) = 2$, полностью исчерпывает rank$(G_2)$.

**Шаг 2. Необходимость тензорного расширения [Т].**

Rank$(G_{\mathrm{SM}}) = 4 > 2 =$ rank$(G_2)$. Следовательно, $G_{\mathrm{SM}} \not\subset G_2$. Дополнительный rank 2 может появиться **только** из тензорного расширения Пейдж–Вуттерс (A5):
$$\mathcal{H} = \mathcal{H}_O \otimes \mathcal{H}_S = \mathbb{C}^7 \otimes \mathbb{C}^6$$
где $G_2$ действует на $\mathcal{H}_O$ (структурный фактор), а электрослабая группа — на $\mathcal{H}_S$ (системный фактор). Тензорная независимость гарантирует коммутативность:
$$[\mathrm{SU}(3)_C^{(\text{struct})}, G_{\mathrm{EW}}^{(\text{sys})}] = 0$$
и сложение рангов.

**Шаг 3. Возможные калибровочные группы на $\mathrm{span}\{L,E,U\}$ — [С при (ФЭ)], не классификация.**

На системном факторе электрослабая группа $G_{\mathrm{EW}}$ действует на $\mathrm{span}\{L, E, U\} \cong \mathbb{C}^3$ — это и есть допущение (ФЭ); прежнее обоснование «$\bar{3} = \{L, E, U\}$» отозвано. Необходимый rank$= 2$. Таблица перечисляет некоторые подгруппы $\mathrm{U}(3)$ ранга 2; это не классификация — например, $\mathrm{SO}(3)\times\mathrm{U}(1)$ тоже имеет ранг 2 и действует на $\mathbb{C}^3$ неприводимо, без всякого расщепления $2+1$:

| Подгруппа | Rank | Фано-совместимость |
|-----------|:----:|:------------------:|
| $\mathrm{SU}(3)$ | 2 | Да, но тривиальная (вся $\bar{3}$-симметрия) |
| $\mathrm{SU}(2) \times \mathrm{U}(1)$ | 2 | **Требует** 2+1 декомпозиции $\bar{3}$ |
| $\mathrm{U}(1) \times \mathrm{U}(1)$ | 2 | Абелева — недостаточна для массового спектра |
| $\mathrm{U}(2)$ | 2 | Изоморфна $\mathrm{SU}(2) \times \mathrm{U}(1)$ с точностью до центра |

**Шаг 4. Единственность расщепления $\{L,E,U\} \to 2 \oplus 1$ [Т] при (ФЭ) (ключевой новый элемент).**

Каждое расщепление $\{L, E, U\} \to (2) \oplus (1)$ определяется выделенной **парой** в $\{L,E,U\}$. Пары:

| Пара | Остаток | Фано-линия через пару | Третья точка |
|------|---------|----------------------|-------------|
| $\{E, U\}$ | $\{L\}$ | $\{A, E, U\}$ | $A \in 3$ |
| $\{L, U\}$ | $\{E\}$ | $\{D, L, U\}$ | $D \in 3$ |
| $\{L, E\}$ | $\{U\}$ | $\{L, E, O\}$ | $O = 1$ |

Критерий единственности — **категориальная совместимость с $\kappa_0$ [Т]**.

Формула $\kappa_0 = \omega_0 \cdot |\gamma_{OE}| \cdot |\gamma_{OU}| / \gamma_{OO}$ [Т] выделяет **ровно пару $(E, U)$** через морфизмы $\mathrm{Hom}(O, E)$ и $\mathrm{Hom}(O, U)$. Это пара, через которую осуществляется регенерация: $O$ (Основание) связано с $E$ (Интериорность) и $U$ (Единство) **функционально**, через единственную аксиоматическую формулу. Замена на другую пару:

- Пара $\{L, U\}$: нет $\mathrm{Hom}(O, L)$ в $\kappa_0$ — $L$ не выделена категориально
- Пара $\{L, E\}$: исключает $U$ из дублета — разрушает нормировку $\mathrm{Tr}(\Gamma) = 1$ (функция U)

Следовательно, расщепление $\{L,E,U\} \to \{E, U\} \oplus \{L\}$ **единственно** среди трёх пар.

**Шаг 5. Единственность Фано-Хиггсовой линии [Т] (существующий результат).**

В PG(2,2) через точки $E = 5$ и $U = 6$ проходит ровно одна линия: $\{A, E, U\} = \{1, 5, 6\}$. $\blacksquare$

**Шаг 6. Единственность $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ [Т].**

На дублете $\{E, U\} \cong \mathbb{C}^2$:
- $\mathrm{SU}(2)_L$ — единственная (с точностью до изоморфизма) группа ранга 1, действующая неприводимо на $\mathbb{C}^2$
- $\mathrm{U}(1)_Y$ — единственный (с точностью до нормировки) генератор, коммутирующий с $\mathrm{SU}(2)_L$ и различающий множества осей $\{A,S,D\}$ и $\{L,E,U\}$ (на системном факторе; в 7D такой генератор не коммутирует с $\mathrm{SU}(3)_C$, Теорема 2.1(b))

**Шаг 7. Итог: rank = 4 [С при (ФЭ)].**

$$\text{rank}(\mathrm{SU}(3)_C) + \text{rank}(\mathrm{SU}(2)_L) + \text{rank}(\mathrm{U}(1)_Y) = 2 + 1 + 1 = 4$$

Единственность среди всех групп ранга 4, совместимых с аксиомами, — [Г]. $\blacksquare$

Шаг 4 — **категориальная единственность пары $(E, U)$** из формулы $\kappa_0$ [Т]. Формула $\kappa_0$ [Т] содержит **ровно** $|\gamma_{OE}|$ и $|\gamma_{OU}|$ — это не свободный параметр, а следствие сопряжения $\mathcal{D} \dashv \mathcal{R}$ [Т]. Пара выведена; трёхмерное пространство, на котором действует электрослабая группа, — нет. Этот вход, (ФЭ), прежде полагался отдельной гипотезой, затем считался выведенным через «$\bar{\mathbf 3}=\{L,E,U\}$», а после отзыва 25.09.2026 снова стал названным допущением.
:::

### 2.4 Теорема 2.2 (Согласование двух $\mathrm{SU}(3)$) — отозвана [✗] {#согласование-su3}

:::danger[Статус: Отозвано \[✗\] (25.09.2026)]
Теорема утверждала, что два пути к $\mathrm{SU}(3)_C$ — через $G_2$ (разд. 1.3) и через тензорную структуру 42D (разд. 2.1) — дают **одну и ту же** подгруппу и что она коммутирует с $\mathrm{SU}(2)_L\times\mathrm{U}(1)_Y$. Её доказательство (b) отождествляло триплет с осями $\{A,S,D\}$, а (c) выводило коммутацию из $\{A,S,D\} \cap \{E,U,L\} = \varnothing$. Не выдерживает ни то, ни другое. $\mathrm{SU}(3)_C$ действует сразу на все шесть осей, отличных от $O$, — $7\to1\oplus\mathbf 3\oplus\bar{\mathbf 3}$ есть комплексное расщепление, в котором ни одна ось не лежит ни в одном слагаемом, — а лемма Шура делает её централизатор в $\mathrm U(7)$ равным $\mathrm U(1)^3$ (размерность 3, проверено), где $\mathrm{SU}(2)$ нет: в 7D две группы не коммутируют ($\max_a\|[T_a,X]\|=3.6$, разд. 2.1). В 42D-расширении Пейджа–Вуттерса $\mathrm{SU}(3)_C$ на часовом факторе коммутирует с любой группой на системном факторе по тривиальной причине тензорной независимости; большего не утверждается.
:::

*Запись отозванной теоремы (причина — в боксе выше).*

**(a)** Определение согласования. $G_2$ действует на $\mathcal{H}_O \cong \mathbb{C}^7$ (7D формализм). В 42D PW-расширении $\mathrm{SU}(3)_C$ действует на $3_{ASD}$-фактор. Согласованное вложение:

$$\mathrm{SU}(3)_C \hookrightarrow G_2|_{\mathrm{Stab}(O)} \cap \mathrm{U}(6)|_{3_{ASD}}$$

определено условием: $\mathrm{SU}(3)_C$-преобразование когерентности $\gamma_{ij}$ (в 7D) **совпадает** с $\mathrm{SU}(3)$-преобразованием тензорного элемента $\Gamma_{ab,cd}$ (в 42D) при ограничении на 3-to-$\bar{3}$ сектор.

**(b)** Доказательство согласования. Из разложения:
- В 7D: $3_{ASD} = \{A, S, D\}$ — фундаментальное $\mathrm{SU}(3)$ из $G_2$
- В 42D: $3_{ASD}$ — тот же триплет в тензорном факторе $\mathcal{H}_{6D}$

Отождествление: $\{A, S, D\}_{7D} = \{1, 2, 3\}_{\mathrm{color}}$. В обоих формализмах $\mathrm{SU}(3)$ вращает $\{A, S, D\}$ как фундаментальный триплет.

**(c)** Коммутативность. $\mathrm{SU}(3)_C$ действует на $3_{ASD}$, а $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$ — на $\bar{3}_{LEU}$ (через декомпозицию $\bar{3} \to 2_{EU} \oplus 1_L$). Поскольку подпространства не пересекаются:

$$[\mathrm{SU}(3)_C, \, \mathrm{SU}(2)_L \times \mathrm{U}(1)_Y] = 0$$

Ранг полной калибровочной группы: $\mathrm{rank}(\mathrm{SU}(3)_C) + \mathrm{rank}(\mathrm{SU}(2)_L) + \mathrm{rank}(\mathrm{U}(1)_Y) = 2 + 1 + 1 = 4 = \mathrm{rank}(\mathrm{SM})$.

**Доказательство.** Конструктивное. $G_2 \subset \mathrm{SO}(7)$ действует на $\mathbb{R}^7 = \mathrm{Im}(\mathbb{O})$. Выбор O-направления даёт $\mathrm{SU}(3) \subset G_2$ с $7 \to 1 + 3 + \bar{3}$. Хиггсова линия $\{A,E,U\}$ разлагает $\bar{3} \to 2_{EU} \oplus 1_L$. Коммутативность диаграммы:

```
       G₂         Фано-плоскость PG(2,2)
        |                   |
        | Stab(O)           | Хиггсова линия {A,E,U}
        v                   v
      SU(3)_C        SU(2)_L × U(1)_Y
     (на 3_ASD)     (на 2_EU ⊕ 1_L из 3̄_LEU)
```

Коммутативность следует из того, что $\{A,S,D\} \cap \{E,U,L\} = \varnothing$. $\blacksquare$

### 2.5 Группа Стандартной модели из системы Клиффорда на $\mathbb{C}\otimes\mathbb{O}$ (T-326) {#sm-из-клиффорда}

:::tip[Статус: Теорема 2.5 — \[Т\] как математика; как результат УГМ — \[С при (Кл)\]]
Разделы 2.1–2.4 получают электрослабую группу, помещая её на оси, которые она не может делить с цветом. Этот раздел получает всю группу $(\mathrm{SU}(3)\times\mathrm{SU}(2)\times\mathrm{U}(1))/\mathbb{Z}_6$ вместе с гиперзарядами из одной структуры, которая в УГМ уже есть: октонионного умножения на семи осях и комплексных чисел квантовой механики. Плата — одно названное допущение (Кл), оно сформулировано ниже. При (Кл) электрослабая группа не выбирается: это централизатор цвета. Она действует на левых дублетах. В полном поколении из [§2.6](#поколение-t329) её $\mathrm{SU}(2)$ — диагональ $\mathrm{SU}(2)_L\times\mathrm{SU}(2)_R$, а её $\mathrm{U}(1)$ — $(B-L)/2$; на левой половине они действуют как $\mathrm{SU}(2)_L$ и $Y$. Строка реестра T-326; числа — в `website/scripts/check_core_numbers.py`.
:::

**Пространство.** Октонионы стоят на семи осях (T15 [Т] с канонической ориентацией линий Фано — [T15-канон](/docs/proofs/minimality/theorem-octonionic-derivation#каноническая-ориентация); названный здесь сперва вход (Альт) ею снят), и среди осей выделена единица часов $e_O$. Спинорный модуль алгебры Клиффорда пространства $\mathrm{Im}\,\mathbb{O}$ — само $\mathbb{O}$: образующие $\Gamma_i = L_{e_i}$ (§4.1), $G_2$-инвариантный спинор $\eta_0 = 1$ (§4.2). Квантовая механика его комплексифицирует:
$$\mathcal{S} := \mathbb{C}\otimes\mathbb{O} = \mathbb{C}\,\eta_0 \oplus \mathcal{H},\qquad \mathcal{H} = \mathbb{C}\otimes\mathrm{Im}\,\mathbb{O} = \mathbb{C}^7 .$$
Итак, $\mathcal{S}$ — гильбертово пространство УГМ плюс прямая параллельного спинора. Ниже оно читается как вещественное $\mathbb{R}^{16}$, а его вещественной структурой служит комплексное сопряжение $J$.

**Допущение (Кл).** *Внутренние калибровочные преобразования фермионов — элементы спинорной группы той системы Клиффорда, которую на $\mathcal{S}$ порождают октонионные структурные отображения. Часы нарушают эту группу до наибольшей связной подгруппы, в которой цвет $\mathrm{SU}(3)_C=\mathrm{Stab}_{G_2}(e_O)$ остаётся нормальным множителем.* (Кл) заменяет (ФЭ). Оно говорит, где живут фермионы и какая группа на них действует, и не называет ни одной тройки осей. Аксиомы УГМ его не содержат: то, что фермионы — спиноры $\mathrm{Im}\,\mathbb{O}$, есть вход. *Дополнение (T-329):* второе предложение — теорема: это стабилизатор часов, то же правило, что даёт цвет в $G_2$ ([§2.6](#поколение-t329)). Остаётся первое предложение, (Кл₀), и там показано, что оно не зависит от аксиом о $\Gamma$.

**Теорема 2.5 (T-326).**

**(a) Система Клиффорда вынуждена и максимальна [Т].** Девять операторов
$$\gamma_k = i L_{e_k}\ (k=1,\dots,7),\qquad \gamma_8 = J,\qquad \gamma_9 = iJ$$
удовлетворяют соотношению $\gamma_a\gamma_b+\gamma_b\gamma_a = 2\delta_{ab}$ на $\mathcal{S}\cong\mathbb{R}^{16}$. Последние два не выбираются: операторы, антикоммутирующие со всеми семью $iL_{e_k}$, образуют ровно двумерное пространство $\mathrm{span}\{J, iJ\}$. Десятого такого оператора на $\mathbb{R}^{16}$ нет. Произведения $\gamma_a\gamma_b/2$ натягивают $\mathfrak{spin}(9)$ (размерность 36), и $\mathfrak{g}_2\subset\mathfrak{spin}(7)\subset\mathfrak{spin}(9)$.

**(b) Электрослабая алгебра — централизатор цвета [Т].** Централизатор $\mathfrak{su}(3)_C$ в $\mathfrak{spin}(9)$ есть $\mathfrak{u}(2)=\mathfrak{su}(2)\oplus\mathfrak{u}(1)$: размерность 4, центр одномерен, производная алгебра трёхмерна. Нормализатор $\mathfrak{su}(3)_C$ равен $\mathfrak{su}(3)\oplus\mathfrak{su}(2)\oplus\mathfrak{u}(1)$ и имеет размерность 12. Он совпадает с централизатором правого умножения $R_{e_O}$ — это характеристика Краснова, полученная здесь со стороны цвета. Централизатор всей двенадцатимерной алгебры в $\mathfrak{spin}(9)$ — одна $\mathfrak{u}(1)$, гиперзаряд.

**(c) Глобальная группа — $(\mathrm{SU}(3)\times\mathrm{SU}(2)\times\mathrm{U}(1))/\mathbb{Z}_6$ [Т].** Параметризуем $\mathrm{U}(1)$ зарядом $6Y$ с периодом $2\pi$. Из 72 центральных троек $(\omega^a, \pm1, e^{i\pi n/6})$, где $a\in\{0,1,2\}$ и $n\in\{0,\dots,11\}$, тождественно на $\mathcal{S}$ действуют ровно шесть. Они образуют $\mathbb{Z}_6$ с образующей $(e^{2\pi i/3}, -1, e^{i\pi/3})$.

**(d) Представление [Т].** Возьмём комплексную структуру $\mathcal{J}=L_{e_O}$ (T-327, §4.4). Тогда
$$(\mathcal{S},\mathcal{J}) \cong (\mathbf 3,\mathbf 2)_{1/6}\oplus(\mathbf 1,\mathbf 2)_{-1/2},$$
то есть левый кварковый и левый лептонный дублеты одного поколения. Электрические заряды $Q=T_3+Y$ равны $\tfrac23$ (три состояния), $-\tfrac13$ (три), $0$ и $-1$. Лептонный дублет лежит на комплексной прямой $\mathbb{C}_{e_O}=\mathrm{span}\{\eta_0, e_O\}$, кварковый — на шести ортогональных ей осях, в цветовом $\mathbb{C}^3$ Теоремы 1.1(a). Отношение $Y_Q:Y_L = 1:(-3)$ получается на выходе, а не закладывается. Шестнадцать вещественных измерений несут индекс изоспина, а не лоренцев спинорный индекс: поле Вейля со значениями в $\mathcal{S}$ — это $\mathbb{C}_O^2\otimes_{\mathbb{C}}\mathcal{S}_{\mathbb{C}}$, где вейлевский индекс — отдельный множитель ([Пространство-время, теорема 48e](/docs/core/foundations/spacetime#теорема-48e)(d)–(e); 48d(e)).

**Доказательство.** (a) Соотношения проверяются прямым счётом. Продолжение: $\mathrm{Cl}_{7,0}$ действует на $\mathcal{S}=\mathbb{C}^8$ как $M_8(\mathbb{C})$, и его элемент объёма $\gamma_1\cdots\gamma_7$ равен $i$ (проверено). Если $T$ антикоммутирует со всеми $\gamma_k$, то $J^{-1}T$ с ними коммутирует. Значит, $J^{-1}T$ лежит в их коммутанте $\mathrm{span}\{1, i\}$, и $T\in\mathrm{span}\{J, Ji\}$. Вещественная алгебра Клиффорда девяти образующих с квадратом $+1$ есть $M_{16}(\mathbb{R})\oplus M_{16}(\mathbb{R})$, десяти — $M_{32}(\mathbb{R})$ (таблица периодичности: Lawson и Michelsohn, *Spin Geometry*, Princeton 1989, гл. I §4). Поэтому её неприводимые модули имеют вещественные размерности 16 и 32, и на $\mathbb{R}^{16}$ девять — максимум.

(b) $\mathrm{SU}(3)_C$ действует на комплексифицированных октонионах автоморфизмами, которые закрепляют $\eta_0$ и $e_O$ и коммутируют с $J$ и $i$. Поэтому $\mathbb{R}^9=\mathrm{span}\{\gamma_a\}$ расщепляется в сумму $\mathbb{R}^6\oplus\mathbb{R}^3$, где $\mathbb{R}^6=\mathrm{span}\{\gamma_k : e_k\perp e_O\}\cong\mathbf 3\oplus\bar{\mathbf 3}$, а $\mathbb{R}^3=\mathrm{span}\{\gamma_O, J, iJ\}$ тривиально. Отсюда $\mathfrak{so}(9)=\mathfrak{so}(6)\oplus\mathfrak{so}(3)\oplus(\mathbb{R}^6\otimes\mathbb{R}^3)$. Синглеты под $\mathfrak{su}(3)$ — одна $\mathfrak{u}(1)\subset\mathfrak{so}(6)$ (комплексная структура $\mathbb{R}^6$, то есть $L_{e_O}$ на $e_O^\perp$) и вся $\mathfrak{so}(3)$, а $\mathbb{R}^6\otimes\mathbb{R}^3$ — три копии $\mathbf 3\oplus\bar{\mathbf 3}$. Итого размерность 4. Так как $\mathfrak{su}(3)$ полупроста, её нормализатор равен $\mathfrak{su}(3)\oplus\mathfrak{c}(\mathfrak{su}(3))$, размерность 12. Совпадение с $\mathfrak{c}(R_{e_O})$ и одномерность централизатора всей алгебры вычислены.

(c), (d) Центральные элементы и спектр зарядов вычислены на $\mathcal{S}$. Ядро следует уже из зарядов: $(\omega^a, s, z)$ действует на кварках как $\omega^a s z$, на лептонах как $s z^{-3}$, и обе величины равны 1 ровно при $z=\omega^{-a}s$. Остаётся $3\times2=6$ элементов. $\blacksquare$

Свидетели: `test_complex_octonion_clifford_system_is_maximal_spin9`, `test_standard_model_algebra_is_the_centraliser_of_colour_in_spin9`, `test_spin9_standard_model_group_has_exactly_z6_kernel`, `test_complex_octonion_doublets_are_chiral`.

**Приоритет и что здесь нового.** Теоретико-групповое ядро опубликовано. Тодоров и Дюбуа-Виолетт получают $G_{\mathrm{SM}}$ как пересечение $\mathrm{Spin}(9)\cap(\mathrm{SU}(3)\times\mathrm{SU}(3))/\mathbb{Z}_3$ внутри $F_4=\mathrm{Aut}\,J_3(\mathbb{O})$ (*Int. J. Mod. Phys. A* **33**, 1850118 (2018), [arXiv:1806.09450](https://arxiv.org/abs/1806.09450)). Краснов доказывает, что «the group $G_{SM}$ is the subgroup of $\mathrm{Spin}(9)$ that commutes with … a certain complex structure $J_R$ in the space $\mathbb{O}^2$ of $\mathrm{Spin}(9)$ spinors», где $J_R$ — правое умножение на единичный мнимый октонион. Спинор у него разлагается на $L=(1,2)_{-1}$ и $Q=(3,2)_{1/3}$ (его нормировка — $2Y$), с тем же $\mathbb{Z}_6$. Он же отмечает: «the right-handed fermions that are SU(2) singlets are not part of $\mathbb{O}^2$» (*J. Math. Phys.* **62**, 021703 (2021), [arXiv:1912.11282](https://arxiv.org/abs/1912.11282), теорема 1 и §3.6). Собственного у УГМ здесь четыре вещи. (i) Спинорное пространство — это гильбертово пространство УГМ плюс параллельный спинор, и система Клиффорда на нём вынуждена: ни одна образующая не выбирается. (ii) Электрослабая алгебра охарактеризована как централизатор того цвета, который УГМ уже выводит из $G_2$. (iii) Мнимая единица $\mathcal{H}$ действует на $\mathcal{S}$ как генератор слабого изоспина: $i/2\in\mathfrak{su}(2)_L$ (проверено). (iv) Утверждение о хиральности T-327 и утверждение о $B-L$ T-329 ниже.

**Чего (Кл) не даёт.**
- *Лоренцев спинорный индекс — отдельный множитель (25.09.2026, [Пространство-время, теорема 48e](/docs/core/foundations/spacetime#теорема-48e)).* Ни одна $\mathrm{SU}(2)$, действующая на $\mathcal{S}_{\mathbb{C}}$, не коммутирует с $G_{\mathrm{SM}}$: коммутант $\mathfrak{g}_{\mathrm{SM}}$ в $\mathfrak{so}(32)$ абелев, размерности 6. Поэтому вейлевский индекс — цвет-неподвижная часть $\mathbb{C}_O^2$ октонионного спинора теоремы 48c, а одно поколение — $F=\mathbb{C}_O^2\otimes_{\mathbb{C}}\mathcal{S}_{\mathbb{C}}=(\mathbf 2,\mathbf{16})$ группы $\mathrm{SL}(2,\mathbb{C}_O)\times\mathrm{Spin}(10)$: $2\times16=32$ комплексные компоненты, $4$ у лептонного дублета. Пространственные вращения 48c действуют на первом множителе и коммутируют со всей $\mathrm{Spin}(10)$, так что $\mathrm{SU}(2)$ из (b) — не пространственное вращение (расхождение теоремы 48d(d) разрешено).
- *Правые поля — их даёт комплексификация.* В $\mathcal{S}$ лежат только левые дублеты. $\mathrm{SU}(2)_L$-синглеты $u_R, d_R, e_R$ (и $\nu_R$) в шестнадцать вещественных измерений не помещаются. Они появляются в $\mathcal{S}_{\mathbb{C}}=\mathcal{S}\otimes_{\mathbb{R}}\mathbb{C}'$, где десятая образующая вынуждена, с гиперзарядами Стандартной модели, и с ними приходит $\mathrm{U}(1)_{B-L}$ (T-329, [§2.6](#поколение-t329), разд. 2.3a).
- *Дублет Хиггса.* Векторное представление $\mathrm{Spin}(9)$ разлагается как $(\mathbf 1,\mathbf 3)_0\oplus(\mathbf 3,\mathbf 1)_{-1/3}\oplus(\bar{\mathbf 3},\mathbf 1)_{1/3}$ (проверено: гиперзаряды $0$ и $\pm\tfrac13$) и дублета не содержит. В векторе $\mathrm{Spin}(10)$ из [§2.6](#поколение-t329) бесцветная четырёхплоскость $\{iL_{e_O},J,iJ,\gamma_{10}\}$ — один дублет с $Y=\pm\tfrac12$ (Теорема 2.6(f); отождествление — [Г], юкавская структура открыта). Отождествление $H\sim\gamma_{EU}$ хиггсовского сектора принадлежит осевой картине и здесь опоры не получает.
- *Комплексная структура $\mathcal{H}$.* При (Кл) комплексной структурой фермионов служит $L_{e_O}$, а не $i$ пространства $\mathcal{H}$. Калибровочная группа с $i$ не коммутирует (норма коммутатора $0{,}97$), потому что $i$ сам является генератором $\mathrm{SU}(2)_L$. Совпадение глобальной фазы пространства состояний холона с поворотом слабого изоспина на $\mathcal{S}$ — структурное следствие (Кл). Его прочтение — [И]. В полном поколении $i/2=T_{3L}+T_{3R}$, а электрический заряд $Q=i/2+(B-L)/2$ (Теорема 2.6(d)).

**Что это меняет в разделах 2.1–2.4.** Электрослабой группе больше не нужно (ФЭ). Осевая конструкция §2.3 остаётся записью [С при (ФЭ)]. При (Кл) утверждение §2.3a — единственность $\mathrm{SU}(2)\times\mathrm{U}(1)$ при заданном цвете — верно как теорема конструкции: электрослабая алгебра есть централизатор, а в централизаторе выбора нет. Возражение §2.1 «централизатор $\mathrm{SU}(3)_C$ в $\mathrm{U}(7)$ равен $\mathrm{U}(1)^3$» касается комплексно-линейных отображений $\mathcal{H}$. $\mathrm{Spin}(9)$ действует на $\mathcal{S}$ вещественно-линейно, и там централизатор — $\mathrm{U}(2)$.

### 2.6 Полное поколение: комплексифицированный спинор и $\mathrm{Spin}(10)$ (T-329) {#поколение-t329}

:::tip[Статус: Теорема 2.6 (a)–(f) — \[Т\] как математика; как результат УГМ — \[С при (Кл)\]; отождествление хиггса в (f) — \[Г\]]
Раздел 2.5 оставляет правые поля снаружи. Они возвращаются без нового допущения. Вейлевское поле комплексно, поэтому поле со значениями в вещественном спиноре $\mathcal{S}$ принимает значения в его комплексификации $\mathcal{S}_{\mathbb{C}}$. На $\mathcal{S}_{\mathbb{C}}$ система Клиффорда получает ровно одну новую образующую, группа становится $\mathrm{Spin}(10)$, а $\mathcal{S}_{\mathbb{C}}$ — одним полным поколением с $\nu_R$. Тот же счёт решает, какая $\mathrm{SU}(2)$ левая: $\mathrm{SU}(2)$ Теоремы 2.5 — диагональ $\mathrm{SU}(2)_L\times\mathrm{SU}(2)_R$, и как $\mathrm{SU}(2)_L$ она действует лишь на левой половине. Строка реестра T-329; числа — в `website/scripts/check_core_numbers.py`.
:::

**Пространство.** Вейлевское спинорное поле принимает значения в комплексном пространстве $S_+\otimes_{\mathbb{C}}V$. Если внутреннее пространство — вещественный модуль $\mathcal{S}$ из §2.5, то
$$S_+\otimes_{\mathbb{R}}\mathcal{S} = S_+\otimes_{\mathbb{C}}\mathcal{S}_{\mathbb{C}},\qquad \mathcal{S}_{\mathbb{C}} := \mathcal{S}\otimes_{\mathbb{R}}\mathbb{C}' \cong \mathbb{R}^{32}.$$
Здесь у $\mathbb{C}'=\mathbb{R}^2$ своя мнимая единица $i'$ и своё сопряжение $K'$. Единица $i'$ — та, что нужна полю. Это не $i$ пространства $\mathcal{H}$: тот уже действует внутри $\mathcal{S}$ как генератор слабого изоспина. Это и есть удвоение $V\oplus\bar V$, в котором Дистлер и Гарибальди видят провал моделей $E_8$. Здесь оно даёт целое хиральное поколение, потому что группа, действующая на $\mathcal{S}_{\mathbb{C}}$, больше $\mathrm{Spin}(9)$.

**Теорема 2.6 (T-329).**

**(a) Десятая образующая вынуждена [Т].** Девять образующих §2.5, сделанные $\mathbb{C}'$-антилинейными, $\gamma_a K'$ ($a=1,\dots,9$), удовлетворяют соотношениям Клиффорда на $\mathcal{S}_{\mathbb{C}}$. Операторы, антикоммутирующие со всеми девятью, натягивают ровно $\{i'K',\,i'\}$. Из них симметричны и имеют квадрат $+1$ лишь $\pm i'K'=:\pm\gamma_{10}$; знак — ориентация $\mathbb{R}^{10}$. Элемент объёма $\omega=\gamma_1\cdots\gamma_{10}$ равен $\pm i'$: $\mathrm{Spin}(10)$-инвариантная комплексная структура — это мнимая единица поля. Одиннадцатой образующей на $\mathbb{R}^{32}$ нет. Десять образующих порождают $\mathfrak{spin}(10)$ (размерность 45); $\mathfrak{spin}(9)$ из §2.5 действует в ней как своё $\mathbb{C}'$-линейное продолжение, а $(\mathcal{S}_{\mathbb{C}},\omega)$ — это $\mathbf{16}$ группы $\mathrm{Spin}(10)$.

**(b) Левая и правая половины канонически определены [Т].** Цвет поточечно закрепляет четыре из десяти направлений: $iL_{e_O}$, $J$, $iJ$, $\gamma_{10}$. Элемент объёма $\omega_4$ этой четырёхплоскости удовлетворяет $\omega_4^2=1$ и расщепляет $\mathcal{S}_{\mathbb{C}}=V_L\oplus V_R$, $16+16$. На $V_L$ комплексная структура поля $\omega=+L_{e_O}$, на $V_R$ — $\omega=-L_{e_O}$, с одним знаком для кварков и лептонов. Итак, $(V_L,\omega)=(\mathcal{S},L_{e_O})$ — пространство дублетов Теорем 2.5(d) и 4.4, а $(V_R,\omega)$ — его сопряжённая копия. Централизатор цвета в $\mathfrak{spin}(10)$ (размерность 7) — $\mathfrak{su}(2)_L\oplus\mathfrak{su}(2)_R\oplus\mathfrak{u}(1)$. Здесь $\mathfrak{su}(2)_L$ действует только на $V_L$, а $\mathfrak{su}(2)_R$ — только на $V_R$. Центр — гиперзаряд Теоремы 2.5, который в пополнении есть $(B-L)/2$.

**(c) $\mathrm{SU}(2)$ Теоремы 2.5 диагональна [Т].** $\mathrm{Spin}(9)$ из §2.5 — стабилизатор $\gamma_{10}$. У каждого элемента её $\mathfrak{su}(2)$ компоненты в $\mathfrak{su}(2)_L$ и в $\mathfrak{su}(2)_R$ равны по норме: это диагональ. Ни одна $\mathrm{Spin}(9)\subset\mathrm{Spin}(10)$, содержащая цвет, не содержит $\mathrm{SU}(2)_L$. Такая $\mathrm{Spin}(9)$ закрепляет единичный вектор $v$ бесцветной четырёхплоскости. Стабилизатор $v$ в $\mathfrak{so}(4)=\mathfrak{su}(2)_L\oplus\mathfrak{su}(2)_R$ — график изоморфизма и пересекает $\mathfrak{su}(2)_L$ по нулю, потому что $\mathrm{SU}(2)_L$ действует на $\mathbb{R}^4=\mathbb{H}$ левым умножением и не закрепляет ни одного вектора. На $V_L\cong\mathcal{S}$ диагональ действует как $\mathrm{SU}(2)_L$, а $(B-L)/2$ — как $Y$, так что Теоремы 2.5 и 4.4 верно описывают левую половину. Но калибровочная группа полного поколения в этой $\mathrm{Spin}(9)$ не лежит.

**(d) Гиперзаряды: одно поколение с $\nu_R$ [Т].** Мнимая единица $\mathcal{H}$ поднимается на $\mathcal{S}_{\mathbb{C}}$ как $i/2=T_{3L}+T_{3R}$ — поворот плоскости $\{J,iJ\}$. Положим $T_{3R}:=(i/2)|_{V_R}$ и $Y:=(B-L)/2+T_{3R}$. Тогда
$$(V_L,\omega)=(\mathbf 3,\mathbf 2)_{1/6}\oplus(\mathbf 1,\mathbf 2)_{-1/2},\qquad (V_R,\omega)=(\bar{\mathbf 3},\mathbf 1)_{-2/3}\oplus(\bar{\mathbf 3},\mathbf 1)_{1/3}\oplus(\mathbf 1,\mathbf 1)_{1}\oplus(\mathbf 1,\mathbf 1)_{0},$$
то есть $Q_L, L_L$ и $u^c, d^c, e^c, \nu^c$: одно поколение с правым нейтрино, каждое поле — левое вейлевское. Электрический заряд
$$Q=T_{3L}+Y=\tfrac{i}{2}+\tfrac{B-L}{2},$$
и $\pm\tfrac23$, $\pm\tfrac13$ встречаются по три раза, $\pm1$ — по разу, $0$ — дважды. Стабилизатор $\nu^c$ в $\mathfrak{su}(3)\oplus\mathfrak{su}(2)_L\oplus\mathfrak{su}(2)_R\oplus\mathfrak{u}(1)_{B-L}$ — ровно $\mathfrak{g}_{\mathrm{SM}}$ (размерность 12), в $\mathfrak{spin}(10)$ — $\mathfrak{su}(5)$ (размерность 24). Ядро действия $\mathrm{SU}(3)\times\mathrm{SU}(2)_L\times\mathrm{U}(1)_Y$ на $\mathcal{S}_{\mathbb{C}}$ снова ровно $\mathbb{Z}_6$. Знак $T_{3R}$ не важен: два знака переводит друг в друга отражение Вейля $\mathrm{SU}(2)_R$.

**(e) Аномалии сокращаются [Т].** Для всякого $X\in\mathfrak{spin}(10)$ имеем $\mathrm{Tr}_{\mathbf{16}}X^3=0$ и $\mathrm{Tr}_{\mathbf{16}}X=0$, потому что у $\mathfrak{so}(10)$ нет кубического инварианта (Джорджи и Глэшоу, *Phys. Rev. D* **6**, 429 (1972)). Поскольку $Y\in\mathfrak{spin}(10)$, исчезают все пертурбативные аномалии поколения: $\mathrm{SU}(3)^2Y$, $\mathrm{SU}(2)^2Y$, $Y^3$, гравитационная $Y$ и $\mathrm{SU}(3)^3$ — два триплета $Q$ против двух антитриплетов $u^c, d^c$. Нет и глобальной аномалии $\mathrm{SU}(2)$ Виттена (*Phys. Lett. B* **117**, 324 (1982)): дублетов четыре, число чётное. С $\nu^c$ исчезают и аномалии $(B-L)^3$ и гравитационная $B-L$; без него $(B-L)^3=-1$ на поколение. Гиперзаряды не подогнаны. Возражение к T-179 — с $\nu_R$ проходит любая $Y+c(B-L)$ — здесь не действует: $Y$ фиксирован через $\nu^c$ и $i$.

**(f) Бесцветная плоскость Клиффорда — один дублет Хиггса [Т как представление; отождествление — \[Г\]].** Четыре направления $\{iL_{e_O},J,iJ,\gamma_{10}\}$ вектора $\mathbb{R}^{10}$ несут $(\mathbf 1,\mathbf 2,\mathbf 2)_0$ алгебры $\mathfrak{su}(2)_L\oplus\mathfrak{su}(2)_R\oplus\mathfrak{u}(1)_{B-L}$. Под $G_{\mathrm{SM}}$ это один комплексный дублет с $Y=\pm\tfrac12$: $\mathfrak{su}(2)_L$ не закрепляет ни одного вектора плоскости, а $Y$ поворачивает её с зарядом $\tfrac12$. Клиффордово умножение на эти векторы переставляет $V_L$ и $V_R$ — это форма дираковской массы. Стабилизатор в $\mathfrak{g}_{\mathrm{SM}}$ вектора $\gamma_{10}$ — и любого вектора плоскости $\{iL_{e_O},\gamma_{10}\}$ — есть $\mathfrak{su}(3)\oplus\mathfrak{u}(1)_Q$ ровно с $Q$ из (d). Поэтому вакуум в плоскости часов и десятой образующей оставляет фотон. Шесть цветных направлений — $(\mathbf 3\oplus\bar{\mathbf 3},\mathbf 1)_{\pm1/3}$, и половины они сохраняют. Это ответ на вопрос, где сидит дублет, которого §2.5 не нашёл в векторе $\mathrm{Spin}(9)$. Оговорка: один вещественный вектор, связанный клиффордовым умножением, даёт четырём членам поколения одну дираковскую массу. Это соотношение $m_t=m_b=m_\tau$ минимальной $\mathrm{SO}(10)$ с вещественным $\mathbf{10}$, и оно не выполняется. Юкавская структура открыта [Пр].

**Доказательство.** (a) Соотношения — прямой счёт. Элемент объёма девяти, $\gamma_1K'\cdots\gamma_9K' = K'$ (объём §2.5 равен $1$), централен в их алгебре Клиффорда и расщепляет $\mathbb{R}^{32}$ на собственные подпространства $\pm1$, $\mathcal{S}\otimes e_\pm$ — два неэквивалентных неприводимых модуля. - **Цвет ($\mathrm{SU}(3)_C$):** определяется числом прозрачных каналов в секторе 3-to-$\bar{3}$. 8 прозрачных $\to$ фундаментальное представление (кварк). 0 прозрачных $\to$ синглет (лептон).

- **Слабый изоспин ($\mathrm{SU}(2)_L$):** определяется прозрачностью канала E-U ($\bar{3}$-to-$\bar{3}$ сектор). $\mathrm{Gap}(E,U) = 0$ $\to$ дублет. $\mathrm{Gap}(E,U) \neq 0$ $\to$ синглет.

- **Гиперзаряд ($\mathrm{U}(1)_Y$):** определяется суммарным Gap в O-секторе:

$$Y = \frac{1}{3}\left(\sum_{i \in 3} \mathrm{Gap}(O,i) - \sum_{j \in \bar{3}} \mathrm{Gap}(O,j)\right)$$

### 3.2 Теорема 3.2 (Аномальная отмена)

:::tip[Статус: Теорема \[Т\]]

### 3.3 Теорема 3.3 (Число поколений)

:::tip[Статус: Теорема \[Т\]]
Результат $N_{\text{gen}} = 3$ имеет **составной статус: подсчёт [Т], отождествление [И]**. **Подсчёт** — точная мощность $N_{\text{gen}} = |\mathrm{QR}(7)| = |\mathbb{Z}_7^*/\{\pm1\}| = (7-1)/2 = 3$ **[Т]** — три поколения суть классы квадратичных вычетов (эквивалентно орбиты зарядового сопряжения, поскольку $-1$ — невычет по модулю $7$) единственной подгруппы порядка 3 $\{1,2,4\}\subset\mathbb{Z}_7^*$; это теоретико-групповой факт, **не зависящий от топологии Gap-потенциала** (прежняя граница через $A_4$-swallowtail теперь лишь проверка согласованности). Физическое отождествление этих классов с наблюдаемыми поколениями остаётся **[И]**. Полное обсуждение: [Теорема 1.2](/docs/physics/particle-physics/fermion-generations#теорема-ровно-три-генерации).
:::

:::note[Семейная симметрия при (Кл) — T-328]
Любая семейная симметрия обязана коммутировать с $G_{\mathrm{SM}}$. При (Кл) ([§2.5](#sm-из-клиффорда)) это можно вычислить. Одна копия $\mathbb{C}\otimes\mathbb{O}$ допускает лишь фазы $\mathrm{U}(1)_B\times\mathrm{U}(1)_L$, поэтому никакая перестановка трёх объектов внутри неё — осей, линий Фано через $O$, кватернионных подалгебр — не горизонтальна: рассуждение пунктов (c)–(d) ниже находит цвет, а не поколения. Тройственность закрепляет цвет, но поворачивает плоскость, натянутую на $L_{e_O}$ и $R_{e_O}$, на $2\pi/3$ и потому переставляет вложения группы Стандартной модели, а не копии фермионов. Отождествление поколений с этими гармониками — гипотеза (ПЧ) [Г]. Будь эта $\mathbb{Z}_3$ точной, все матрицы смешивания были бы тривиальны — это опровергает $|V_{us}|\approx0{,}224$, — так что при (ПЧ) семейная $\mathbb{Z}_3$ обязана быть нарушена. Подробности: [Поколения фермионов, §5.3](/docs/physics/particle-physics/fermion-generations#поколения-t328).
:::

**(a)** Каждое поколение соответствует **топологически различному** минимуму $V_{\mathrm{Gap}}$ в вакуумной конфигурации.

**(b)** Из Swallowtail-анализа: число минимумов $V_{\mathrm{eff}}$ зависит от кодимензии катастрофы. Для $A_4$ (swallowtail): до 3 минимумов.

**(c)** Число поколений $N_{\mathrm{gen}} =$ число различных **типов** вырожденных $\Gamma$-конфигураций с $R \to 0$, не связанных $G_2$-преобразованием.

**(d)** Из Фано-структуры: 7 Фано-линий определяют 7 «привилегированных» триплетов. Из Фано-двойственности (точка $\leftrightarrow$ линия): каждая точка лежит на 3 линиях $\to$ 3 неэквивалентных «типа» вакуумного выравнивания $\to$ **$N_{\mathrm{gen}} = 3$**.

Три класса неэквивалентных ориентаций триплета $(A,S,D)$ относительно Фано-структуры дают 3 поколения. Точнее: автоморфизм Фано-плоскости $\mathrm{PSL}(2,7)$ (порядок 168) действует на 7 точек. Стабилизатор одной точки (O) имеет порядок $168/7 = 24 \cong S_4$. Орбиты $S_4$ на парах из оставшихся 6 точек: $C(6,2) = 15$ пар, разделённых на классы по размеру. Три класса $\to$ три поколения.

## 4. Хиральность из $G_2$-ориентируемости {#кираль}

### 4.1 Спинорная алгебра Клиффорда на $\mathrm{Im}(\mathbb{O})$

Алгебра Клиффорда $\mathrm{Cliff}(7)$ определяется генераторами $\{\Gamma_i\}_{i=1}^{7}$, соответствующими 7 мнимым единицам октонионов $\{e_1, \ldots, e_7\} \leftrightarrow \{A, S, D, L, E, U, O\}$:

$$\Gamma_i \Gamma_j + \Gamma_j \Gamma_i = -2\delta_{ij} \cdot \mathbf{1}_8$$

$\mathrm{Cliff}(7) \cong M_8(\mathbb{R}) \oplus M_8(\mathbb{R})$. Спинорное представление: $\Delta_7 = \mathbb{R}^8$.

Существует изоморфизм спинорных представлений: пространство спиноров $\Delta_7 \cong \mathbb{O}$ (октонионы как 8-мерное вещественное пространство). Действие Клиффорд-генератора:

$$\Gamma_i(\psi) \;\longleftrightarrow\; e_i \cdot q \quad (i = 1, \ldots, 7)$$

где умножение — **левое** октонионное.

### 4.2 Параллельный спинор и $G_2$-голономия

На $G_2$-многообразии существует единственный ковариантно постоянный спинор $\eta_0 = 1_{\mathbb{O}} \in \mathbb{O}$ — единица октонионов. $G_2$ действует на $\mathrm{Im}(\mathbb{O})$ (оставляя 1 неподвижной), следовательно $g \cdot \eta_0 = \eta_0$ для всех $g \in G_2$.

Параллельный спинор $\eta_0$ определяет 3-форму:

$$\varphi_{ijk} = \langle \Gamma_{ijk} \eta_0, \eta_0 \rangle$$

Эта 3-форма — стандартная калибровочная форма $G_2$:

$$\varphi = \sum_{(i,j,k) \in \mathrm{Fano}} e^i \wedge e^j \wedge e^k$$

суммирование по 7 Фано-линиям. ~~Ориентируемость $G_2$-многообразия эквивалентна существованию параллельного спинора.~~ Исправлено (25.09.2026): параллельный спинор существует ровно тогда, когда голономия лежит в $G_2$; ориентируемость (при спинорной структуре) гарантирует лишь $G_2$-структуру, а не параллельную. А гладкое многообразие голономии $G_2$ не даёт хиральных фермионов в четырёх измерениях — для них нужны особенности (Ачарья и Виттен, «Chiral fermions from manifolds of $G_2$ holonomy», [arXiv:hep-th/0109152](https://arxiv.org/abs/hep-th/0109152)).

### 4.4 Хиральность дублетов при (Кл) (T-327) {#киральность-t327}

:::tip[Статус: Теорема 4.4 — \[Т\] как математика; как результат УГМ — \[С при (Кл)\]]
В §4.3 утверждение, что хиральность следует из $G_2$, отозвано: у $G_2$ только вещественные представления. Тем самым оно проходит требование, которое Дистлер и Гарибальди предъявляют объединённым моделям, и без выбора задним числом. Правые синглеты лежат вне $\mathbb{C}\otimes\mathbb{O}$. В его комплексификации ([§2.6](#поколение-t329)) однородный выбор из (c) вынужден, и всё поколение, включая $\nu_R$, хирально. Строка реестра T-327.

**Теорема 4.4 (T-327).** Пусть $G_{\mathrm{SM}}$ действует на $\mathcal{S}=\mathbb{C}\otimes\mathbb{O}\cong\mathbb{R}^{16}$, как в Теореме 2.5.

**(a)** Коммутант $\mathfrak{g}_{\mathrm{SM}}$ в $\mathrm{End}_{\mathbb{R}}(\mathcal{S})$ четырёхмерен. Это $\mathbb{C}\oplus\mathbb{C}$: один множитель на кварковом блоке (вещественная размерность 12), другой — на лептонном (размерность 4). Поэтому $G_{\mathrm{SM}}$-инвариантных комплексных структур на $\mathcal{S}$ ровно четыре: $\pm L_{e_O}$ на каждом блоке независимо.

**(b)** Каждая из четырёх делает $\mathcal{S}$ комплексным представлением, не изоморфным своему сопряжённому. Спектр гиперзаряда — $\tfrac16$ (шесть состояний) и $\pm\tfrac12$ (два), и он не симметричен относительно $Y\mapsto -Y$. Ни одна допустимая комплексная структура не даёт самосопряжённого, то есть нехирального, фермионного представления.

**(c)** Однородный выбор
$$\mathcal{J} = L_{e_O} = \gamma_O\,\gamma_8\,\gamma_9$$
есть элемент объёма трёх клиффордовых направлений, ортогональных цветовой плоскости. Это и та комплексная структура, которая делает цвет унитарной группой (T-279: умножение на ось — комплексная структура на её небе). Такой выбор даёт кварковому и лептонному дублетам одну хиральность, $(\mathbf 3,\mathbf 2)_{1/6}\oplus(\mathbf 1,\mathbf 2)_{-1/2}$, как в Стандартной модели. Смена знака на лептонном блоке даёт $(\mathbf 3,\mathbf 2)_{1/6}\oplus(\mathbf 1,\mathbf 2)_{+1/2}$. Смена общего знака даёт зеркальный мир, то есть выбор ориентации. В пополнении [§2.6](#поколение-t329) комплексная структура поля равна $\omega=+L_{e_O}$ на всей левой половине (Теорема 2.6(b)): структура с обращённым блоком не возникает, а общий знак — ориентация $\gamma_{10}$.

**Доказательство.** (a) Под $\mathfrak{g}_{\mathrm{SM}}$ пространство $\mathcal{S}$ — сумма двух вещественно-неприводимых модулей комплексного типа, и они не изоморфны, потому что у них разные гиперзаряды. По лемме Шура коммутант равен $\mathbb{C}\oplus\mathbb{C}$, а его комплексные структуры — $(\pm i,\pm i)$. Размерность 4 и тождество $\gamma_O\gamma_8\gamma_9=L_{e_O}$ вычислены. (b), (c) Спектры вычислены для $L_{e_O}$ и для структуры с обращённым лептонным блоком. $\blacksquare$

Свидетель: `test_complex_octonion_doublets_are_chiral` (оба выбора, заряды и $i/2\in\mathfrak{su}(2)_L$).

**Как это проходит тест Дистлера и Гарибальди.** Они доказывают, что ни одна вещественная или комплексная форма $E_8$ не содержит группу Лоренца и группу Стандартной модели так, чтобы фермионы вышли хиральными. Механизм провала общий: вещественное представление комплексифицируется в $V\oplus\bar V$, и вейлевский фермион со значениями в нём оказывается векторным (*Commun. Math. Phys.* **298**, 419–436 (2010), [arXiv:0905.2658](https://arxiv.org/abs/0905.2658)). Здесь фермионное поле — вейлевский спинор, умноженный тензорно над $\mathbb{C}$ на $(\mathcal{S},\mathcal{J})$: $\psi\in S_+\otimes_{\mathbb{C}}(\mathcal{S},\mathcal{J})$. Теорема 4.4(b) говорит, что никакая допустимая $\mathcal{J}$ не вернёт самосопряжённое $V$. *Дополнение (T-329):* отождествлять комплексную структуру поля с $\mathcal{J}$ больше не нужно. Тензорное произведение над $\mathbb{R}$ — это именно то, что делает поле со значениями в вещественном $\mathcal{S}$, и оно даёт $\mathcal{S}_{\mathbb{C}}=V\oplus\bar V$. Это удвоение векторно лишь для диагональной группы Теоремы 2.5. На нём десятая образующая Клиффорда вынуждена, и для $G_{\mathrm{SM}}\subset\mathrm{Spin}(10)$ из Теоремы 2.6(d) пространство $(\mathcal{S}_{\mathbb{C}},\omega)$ — хиральное $\mathbf{16}$: его гиперзаряды $\tfrac16$ (шесть), $-\tfrac12$ (два), $-\tfrac23$, $\tfrac13$ (по три), $1$ и $0$ не симметричны при $Y\mapsto-Y$. Комплексная единица поля — $i'=\pm\omega$. Это ни $i$ пространства $\mathcal{H}$, ни $L_{e_O}$; с $L_{e_O}$ она совпадает на левой половине. *Обновление ([Пространство-время, теорема 48e](/docs/core/foundations/spacetime#теорема-48e)(e)):* вейлевский спинор — это $S_+=\mathbb{C}_O^2$, цвет-неподвижная часть спинора $\mathbb{O}^2$ теоремы 48c, и $i'$ — его комплексная единица. На $F=S_+\otimes_{\mathbb{C}}\mathcal{S}_{\mathbb{C}}$ (вещественная размерность 64) алгебра Лоренца $\mathfrak{sl}(2,\mathbb{C}_O)$ и $\mathfrak{spin}(10)$ коммутируют, их совместный коммутант — $\mathbb{C}$, а вейлевская единица действует как $+L_{e_O}$ на $F_L$ и как $-L_{e_O}$ на $F_R$. Значит, $F=(\mathbf 2,\mathbf{16})$ хирально для $\mathrm{SL}(2,\mathbb{C}_O)\times G_{\mathrm{SM}}$: шестнадцать левых вейлевских полей; сопряжённое представление правое, а гиперзаряды $\mathbf{16}$ не симметричны при $Y\mapsto-Y$. *Обновление (26.09.2026, [Пространство-время, теорема 48e](/docs/core/foundations/spacetime#теорема-48e)(f), (h)):* механизм Дистлера и Гарибальди выполняется внутри УГМ как теорема. При вещественном лоренцевом множителе $F=\mathbb{R}^m\otimes_{\mathbb{R}}\mathcal{S}$ с любой комплексной структурой, коммутирующей с $\mathfrak{g}_{\mathrm{SM}}$, есть $p\,Q_L\oplus(m-p)\,\bar Q_L\oplus r\,L_L\oplus(m-r)\,\bar L_L$, и оно свободно от аномалий, только если векторно. Хиральности нужна комплексная единица лоренцева множителя, а не две его компоненты: $\mathbb{C}^n\otimes_{\mathbb{C}}\mathcal{S}_{\mathbb{C}}$ хирально и свободно от аномалий при всяком $n$.

(Прежнее пояснение «они связывают пространственный ($3$) и Gap ($\bar{3}$) секторы» использовало отозванные метки осей, Теорема 1.1(a).) Масса определяется Gap в секторах O-to-$3$ и O-to-$\bar{3}$:

$$M_{G_2}^{(\mathrm{extra})} \sim \mu_{\mathrm{phys}} \cdot \mathrm{Gap}_{\mathrm{vac}}^{(O)} \cdot |\gamma_{\mathrm{vac}}^{(O)}|$$

**(b)** Общее число калибровочных бозонов: $8 + 3 + 1 + 6 = $ **18**.

:::info[Замечание: X,Y-лептокварки убраны]
В прежней версии 12 X,Y-лептокварков выводились из цепочки $\mathrm{SU}(6) \to \mathrm{SU}(5) \to \mathrm{SM}$. Фано-электрослабая конструкция (ФЭ) не требует промежуточной $\mathrm{SU}(5)$-структуры, поэтому X,Y-лептокварки **не предсказываются**. Их отсутствие ослабляет предсказание распада протона через d=6 операторы (см. разд. 13).
:::

### 5.2 Иерархия масс калибровочных бозонов

:::warning[Статус: Гипотеза \[Г\]]
Масштабная иерархия калибровочных бозонов определяется Gap-иерархией вакуума.
:::

**(a)** Безмассовые ($\mathrm{Gap} = 0$ в соответствующем секторе):
- Глюоны: $\mathrm{Gap} = 0$ в 3-to-$\bar{3}$ $\to$ конфайнмент (нелинейная динамика при $\mathrm{Gap} \to 0$)
- Фотон: $\mathrm{Gap} = 0$ для диагональной $\mathrm{U}(1)_{\mathrm{EM}}$ комбинации

**(b)** Электрослабая шкала ($\mathrm{Gap} \sim 10^{-17}$ от Планка):
- $W^\pm, Z$: $\mathrm{Gap}(E,U) \sim v/M_{\mathrm{Planck}} \sim 10^{-17}$

**(c)** Планковская шкала:
- $G_2$-экстра: $\mathrm{Gap} \sim 1$ $\to$ масса $\sim M_{\mathrm{Planck}}$

**Следствие.** Иерархия масс $M_\gamma = 0 \ll M_W \ll M_{G_2}$ следует из иерархии Gap-значений $0 \ll 10^{-17} \ll 1$ в соответствующих секторах когерентности. Проблема иерархии масс сводится к вопросу: **почему Gap-вакуум имеет столь различные значения в разных секторах?**

### 5.3 Гипотеза 5.1 (Решение проблемы иерархии через RG)

:::warning[Статус: Гипотеза \[Г\]]
Иерархия Gap-значений в вакууме следует из RG-эволюции с демократическими начальными условиями на планковском масштабе.
:::

**(a)** На планковском масштабе: все $\mathrm{Gap} \sim O(1)$ (демократическое начальное условие).

**(b)** RG-поток от Планка к ИК: различные секторы текут с различными аномальными размерностями:

| Сектор | Аномальная размерность | Gap на ИК-масштабе |
|---|---|---|
| 3-to-$\bar{3}$ (цвет) | $\Delta_{3\bar{3}} = 0$ (маргинальный) | $\sim 0$ (конфайнмент) |
| $\bar{3}$-to-$\bar{3}$ (EW) | $\Delta_{\bar{3}\bar{3}} = \Delta_3 = 5/42$ | $\sim 10^{-17}$ (EW-шкала) |
| O-to-3 (гравитация) | $\Delta_{O3} \gg 1$ (ИК-релевантный) | $\sim 1$ (Планк-шкала) |

**(c)** Различие аномальных размерностей определяется Фано-комбинаторикой: число Фано-линий, проходящих через пару $(i,j)$, влияет на $\Delta_{ij}$.

:::info[Замечание]
Аномальная размерность $\Delta_3 = 5/42$ в $\bar{3}$-to-$\bar{3}$ секторе — характерное значение, фиксируемое $G_2$-инвариантностью и Фано-структурой (см. [эволюция](/docs/core/dynamics/evolution)). Экспоненциальное подавление $e^{-\Delta \cdot \ln(M_P/M_{EW})} \sim 10^{-17}$ при $\Delta = 5/42$ и 39 e-fold'ах RG-бега воспроизводит электрослабую иерархию.
:::

## 6. Механизм Хиггса из Gap-конденсации

### 6.1 Теорема 6.1 (Хиггсово поле как когерентность E-U)

:::warning[Статус: Гипотеза \[Г\]]
Спонтанное электрослабое нарушение симметрии возникает из Gap-конденсации в секторе $\bar{3}$-to-$\bar{3}$ (пары осей из $\{L,E,U\}$; это не сектор $\mathrm{SU}(3)$, Теорема 1.1(a)). Конденсат $\gamma_{EU}\neq0$ не $\mathrm{SU}(3)_C$-инвариантен (разд. 9.4), так что в этой формулировке гипотеза нарушает цвет вместе с электрослабой группой.
:::

**(a)** Поле Хиггса отождествляется с когерентностью E-U ($\bar{3}$-to-$\bar{3}$ сектор):

$$H \sim \gamma_{EU} = |\gamma_{EU}| e^{i\theta_{EU}}$$

**(b)** VEV (вакуумное среднее):

$$\langle H \rangle = \langle |\gamma_{EU}| \rangle e^{i\langle\theta_{EU}\rangle} \neq 0$$

Ненулевое VEV нарушает $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y \to \mathrm{U}(1)_{\mathrm{EM}}$:
- $\mathrm{SU}(2)_L$: 3 генератора $\to$ 2 нарушены ($W^+, W^-$) + 1 линейная комбинация нарушена ($Z$)
- $\mathrm{U}(1)_Y$: 1 генератор
- $\mathrm{U}(1)_{\mathrm{EM}}$ = диагональная подгруппа (фотон) — ненарушена

**(c)** Масса $W$-бозона:

$$M_W = \frac{g}{2} v, \quad v = \langle |\gamma_{EU}| \rangle \cdot \mu_{\mathrm{phys}}$$

где $g$ — электрослабая константа связи, $\mu_{\mathrm{phys}} = \mu \cdot \omega_0$.

**(d)** Gap-потенциал проецируется на E-U канал:

$$V_{EU}(\gamma_{EU}) = \mu^2 |\gamma_{EU}|^2 + \lambda_4 |\gamma_{EU}|^4 + \lambda_3 \bar{A} |\gamma_{EU}|^3 \cos(\text{фаза})$$

:::danger Предупреждение C7: непертурбативный режим
Параметр λ₃ ≈ 74 ≫ 4π означает, что октонионный кубический вертекс находится в **сильной связи**. Все петлевые вычисления, использующие λ₃ как пертурбативный параметр, формально ненадёжны. Количественные результаты данного раздела (массы, отношения ветвления, числовые коэффициенты) имеют статус **[Г]** до проведения непертурбативного анализа.
:::

При $\mu^2 < 0$ (низкотемпературный режим): минимум при $|\gamma_{EU}| = v \neq 0$ — стандартный механизм Хиггса, применённый к Gap-потенциалу.

### 6.2 Теорема 6.2 (Масса Хиггса с октонионной коррекцией)

:::tip[Статус: Гипотеза \[Г\]]
Октонионная структура предсказывает отклонение массы Хиггса от стандартного соотношения.
:::

**(a)** Масса Хиггса бозона (вторая производная $V_{EU}$ в минимуме):

$$M_H^2 = 2\lambda_4 v^2 + \frac{3\lambda_3^2 \bar{A}^2}{4\mu^2}$$

Первый член — стандартный (из $V_4$). Второй — **октонионная коррекция** из $V_3$.

**(b)** В SM: $M_H^2 = 2\lambda v^2$ (один параметр $\lambda$). В УГМ: $M_H^2 = 2\lambda_4 v^2 + \delta M_H^2$, где:

$$\delta M_H^2 = \frac{3\lambda_3^2 \bar{A}^2}{4\mu^2} \approx \frac{3 \cdot (73.8)^2 \cdot (0.047)^2}{4 \cdot 16.6} \approx 0.54$$

**(c)** Октонионная поправка к $\lambda_{\mathrm{eff}} = \lambda_4 + \delta\lambda$:

$$\frac{\delta\lambda}{\lambda_4} = \frac{3\lambda_3^2 \bar{A}^2}{8\lambda_4 \mu^2 v^2}$$

:::info[Фальсифицируемое предсказание \[И\]]
При повышении точности измерения тройной вершины Хиггса (HL-LHC, FCC) эффективная самосвязь $\lambda_{\mathrm{eff}}$ отличается от SM-значения на:

$$\frac{\delta\lambda}{\lambda_{\mathrm{SM}}} \sim \frac{\lambda_3^2 \bar{A}^2}{\lambda_4 \mu^2} \sim O(10^{-2}\text{--}10^{-3})$$

-- на уровне процента, потенциально доступном FCC-hh. Обнаружение отклонения $\lambda_{\mathrm{eff}}$ от SM-предсказания подтверждает вклад $V_3$; отсутствие отклонения на уровне $10^{-3}$ ограничивает $\lambda_3 \bar{A}/\mu$.
:::

## 7. Тождества Уорда и фактор подавления $\Lambda$

### 7.1 Вакуумный коррелятор из тождеств Уорда

14 тождеств Уорда, порождённых $G_2$-симметрией, однозначно фиксируют вакуумный двухточечный коррелятор Gap:

$$C_{(ij),(kl)}^{(\mathrm{vac})} = \langle\mathrm{Gap}(i,j) \cdot \mathrm{Gap}(k,l)\rangle_{\mathrm{vac}} = \alpha \delta_{(ij),(kl)} + \beta \sum_p \Pi_p^{(ij)} \Pi_p^{(kl)} + \gamma \epsilon^{\mathrm{Fano}} \epsilon^{\mathrm{Fano}}$$

С учётом $G_2$-инвариантности: $C$ разлагается на $G_2$-инвариантные тензоры:

$$C = \alpha \cdot \mathbf{1}_{21} + \beta \cdot \mathbf{F}_{21} + \gamma \cdot \mathbf{F}_{21}^2$$

Тождества Уорда фиксируют соотношения:

$$\beta = -\frac{3\alpha}{7}, \quad \gamma = \frac{3\alpha}{49}$$

Единственный свободный параметр — $\alpha$ (общая амплитуда флуктуаций).

### 7.2 Антикорреляция и фактор подавления $19/49$

:::tip[Статус: Теорема \[Т\]]
Тождества Уорда приводят к подавлению суммарного вклада Gap-флуктуаций в $\Lambda$.
:::

Коррелятор $C = \lambda_+ P_7 + \lambda_- P_{14}$ с собственными значениями $\lambda_+ = 19\alpha/49$ и $\lambda_- = 73\alpha/49$ (из [спектра $F_{21}$](/docs/physics/gauge-symmetry/noether-charges#собственные-значения-f21)). Вектор $\mathbf{1}_{21}$ целиком лежит в Фано-симметричном секторе $V_7$ ($P_7\mathbf{1} = \mathbf{1}$), поэтому суммарный вклад Gap-флуктуаций в $\Lambda$ определяется только «малым» собственным значением $\lambda_+$:

$$\frac{\mathbf{1}^T C \mathbf{1}}{\mathbf{1}^T (\alpha I_{21}) \mathbf{1}} = \frac{\lambda_+}{\alpha} = \frac{19}{49} \approx 0.39$$

Подавление на множитель $\sim 2.6$ (или $10^{-0.41}$), применяемое к космологической постоянной $\Lambda$. Подробнее: [Космологическая постоянная](/docs/physics/gravity/cosmological-constant).

## 8. Принцип отбора поколений

### 8.1 PSL(2,7)-классификация Z₇-орбит

Три поколения фермионов определяются тремя Фано-фазами $\phi_n = 2\pi k_n / 7$, где $(k_1, k_2, k_3) \subset \mathbb{Z}_7^*$. Из 20 неупорядоченных троек ($C(6,3)$) — какая реализуется?

**Определение.** Z₇-триплет — неупорядоченная тройка $\{k_1, k_2, k_3\} \subset \mathbb{Z}_7 \setminus \{0\}$ с $k_i \neq k_j$.

Три Фано-линии через O определяют разбиение $\{1,2,3,4,5,6\}$ на три пары. Число таких разбиений:

$$\frac{6!}{(2!)^3 \cdot 3!} = 15$$

### 8.2 Теорема 8.1 (PSL(2,7)-орбиты)

:::tip[Теорема 8.1 (PSL(2,7)-орбиты) \[Т\]]
Группа автоморфизмов Фано-плоскости $\mathrm{PSL}(2,7)$ (порядок 168) действует на множестве разбиений и разделяет 15 разбиений на два класса эквивалентности.
:::

**(a)** $\mathrm{PSL}(2,7)$ содержит стабилизатор точки O: $\mathrm{Stab}(O) \cong S_4$ (порядок 24). Действие $S_4$ на 6 точках $\{1,\ldots,6\}$ через $S_4 \subset S_6$.

**(b)** Число орбит на 15 разбиениях под действием $S_4$: по лемме Бёрнсайда:

$$|X/S_4| = \frac{1}{|S_4|} \sum_{g \in S_4} |X^g| = 2$$

Два класса эквивалентности:
- **Класс I** (тип «ассоциативный»): 6 разбиений. $(k_1, k_2, k_3)$ такое, что $k_1 + k_2 + k_3 \equiv 0 \pmod{7}$.
- **Класс II** (тип «неассоциативный»): 9 разбиений. $k_1 + k_2 + k_3 \not\equiv 0 \pmod{7}$.

**(c)** Пример. Мультипликативная группа $\mathbb{Z}_7^* = \{1,2,3,4,5,6\}$. Тройка $(1,2,4)$: $1+2+4 = 7 \equiv 0 \pmod{7}$ — **Класс I**.

**Доказательство.** Из структурной теоремы для $\mathrm{PSL}(2,7)$: стабилизатор точки $S_4$ действует на $\mathbb{F}_7 \setminus \{0\}$ через линейные/аффинные преобразования. Разбиение $\{a_1,b_1\},\{a_2,b_2\},\{a_3,b_3\}$ инвариантно относительно $g \in S_4$ тогда и только тогда, когда $g$ переставляет пары. Орбитная структура определяется «суммарным инвариантом» $\sigma = k_1 + k_2 + k_3 \bmod 7$. При $S_4$-действии $\sigma \equiv 0$ — инвариантное условие (подмножество ядра). $\blacksquare$

### 8.3 Теорема 8.2 (Принцип отбора: минимальный ассоциатор)

:::tip[Теорема 8.2 (Принцип отбора) \[Т\]]
Физически реализуемый Z₇-триплет минимизирует полный ассоциатор трёх поколений. Единственный триплет с $\mathcal{A} = 0$ — это $(1,2,4)$.
:::

**(a)** Ассоциаторная мера триплета:

$$\mathcal{A}(k_1, k_2, k_3) := \|[e_{k_1}, e_{k_2}, e_{k_3}]\|^2 = \|(e_{k_1} \cdot e_{k_2}) \cdot e_{k_3} - e_{k_1} \cdot (e_{k_2} \cdot e_{k_3})\|^2$$

где $e_k$ — мнимые единицы октонионов.

**(b)** Из таблицы умножения октонионов (см. [октонионный вывод](/docs/proofs/minimality/theorem-octonionic-derivation)):

Для Фано-триплета $(i,j,k)$: $[e_i, e_j, e_k] = 0$ (ассоциатор нуль). Для не-Фано-триплета:

$$\|[e_i, e_j, e_k]\|^2 = 4 \quad \text{для всех не-Фано-триплетов}$$

**(c)** Классификация:

| Триплет $(k_1,k_2,k_3)$ | Фано-линия? | $\mathcal{A}$ | Класс |
|---|---|---|---|
| **(1,2,4)** — квадр. вычеты | **Да** | **0** | **I (единственный)** |
| (3,5,6) — невычеты | Нет | 4 | II |
| (1,3,5), (2,4,6), ... | Нет | 4 | II |

**(d)** Триплеты Класса I с $\mathcal{A} = 0$ — **ассоциативные**: три мнимых единицы $e_{k_1}, e_{k_2}, e_{k_3}$ формируют ассоциативную подалгебру $\mathbb{H} \subset \mathbb{O}$ (кватернионную).

**(e)** Принцип отбора. Из $V_3$-динамики: вакуумная конфигурация минимизирует энергию. Вклад трёх поколений:

$$V_3^{(\text{gen})} \propto \mathcal{A}(k_1, k_2, k_3) \cdot \lambda_3 \prod_n |\gamma_n|$$

**Минимум достигается при $\mathcal{A} = 0$** — Класс I.

**(f)** $(1,2,4)$ — **единственный** триплет из $\mathbb{Z}_7^* \setminus \{7\}$ с $\mathcal{A} = 0$ (с точностью до перестановок). Это подгруппа индекса 2 в $\mathbb{Z}_7^*$, изоморфная $\mathbb{Z}_3$ (квадратичные вычеты $\bmod 7$).

:::info[Замечание об уникальности]
Отображение $k \to 7-k \pmod{7}$ **не** является автоморфизмом Фано-плоскости ($k \to -k \notin \mathrm{Aut}(\mathrm{PG}(2,2)) = \mathrm{PSL}(2,7)$), поэтому $\{3,5,6\}$ не эквивалентно $\{1,2,4\}$. Проверка: $\{3,5,6\}$ не является Фано-линией, $\mathcal{A}(3,5,6) = 4 \neq 0$. Принцип отбора выделяет $(1,2,4)$ **единственным** образом, без вырождения.
:::

**Доказательство.** Шаг 1: из PSL(2,7)-классификации (разд. 7.2) — два класса. Шаг 2: из $V_3$-минимизации — Класс I ($\mathcal{A} = 0$). Шаг 3: из определения ассоциатора в $\mathbb{O}$ — тройка $(k_1,k_2,k_3)$ формирует кватернионную подалгебру тогда и только тогда, когда тройка — подгруппа $\mathbb{Z}_7^*$. Единственная подгруппа порядка 3 в $\mathbb{Z}_7^*$: квадратичные вычеты $\{1,2,4\}$. $\blacksquare$

## 9. Фановское правило отбора Юкавских связей

### 9.1 Определение (Фано-Хиггсовая линия)

**Определение.** Фано-Хиггсовой линией называется Фано-линия $\mathrm{PG}(2,2)$, содержащая **оба** Хиггсовых измерения $E = 5$ и $U = 6$.

### 9.2 Теорема 9.1 (Единственность Фано-Хиггсовой линии)

:::tip[Теорема 9.1 (Единственность) \[Т\]]
Существует ровно одна Фано-Хиггсовая линия: $\{1, 5, 6\} = \{A, E, U\}$.
:::

**Доказательство.** В $\mathrm{PG}(2,2)$ через любые две точки проходит ровно одна линия. Точки $E=5$ и $U=6$. Из таблицы Фано-линий (см. [октонионный вывод](/docs/proofs/minimality/theorem-octonionic-derivation)):

$$\{5,6,1\} = \{A, E, U\}$$

Это единственная линия, содержащая и 5, и 6. $\blacksquare$

### 9.3 Теорема 9.2 (Фановское правило отбора)

:::tip[Теорема 9.2 (Фановское правило отбора) \[Т\]]
Древесная (tree-level) Юкавская связь поколения $k_n$ с Хиггсовым полем $\gamma_{EU}$ пропорциональна октонионной структурной константе $f_{k_n, E, U}$, которая ненулевая тогда и только тогда, когда $(k_n, E, U)$ — Фано-линия.

Статус **[Т]**: доказано через октонионные структурные константы $f_{ijk}$ — единственный $G_2$-инвариантный трилинейный оператор на $\mathrm{Im}(\mathbb{O})$. Полное доказательство: [Теорема 2.2](/docs/physics/gauge-symmetry/fano-selection-rules#теорема-фано-отбор-fijk).
:::

$$y_n^{(\text{tree})} = g_W \cdot f_{k_n, E, U} \cdot \sin\left(\frac{2\pi k_n}{7}\right) \cdot |\gamma_{\text{vac}}^{(EU)}|$$

где $f_{ijk} = \pm 1$ если $(i,j,k)$ — Фано-линия, и $f_{ijk} = 0$ иначе.

**(a)** Для $k_n = 1$: тройка $(1, 5, 6) = \{A, E, U\}$ — Фано-линия. $f_{1,5,6} = 1$.

$$y_1^{(\text{tree})} = g_W \cdot 1 \cdot \sin(2\pi/7) \cdot |\gamma_{\text{vac}}| \neq 0$$

**(b)** Для $k_n = 2$: тройка $(2, 5, 6)$. Линия через 2 и 5: $\{2,3,5\}$ (содержит 3, не 6). Линия через 2 и 6: $\{6,7,2\}$ (содержит 7, не 5). $f_{2,5,6} = 0$.

$$y_2^{(\text{tree})} = 0$$

**(c)** Для $k_n = 4$: тройка $(4, 5, 6)$. Линия через 4 и 5: $\{4,5,7\}$ (содержит 7, не 6). Линия через 4 и 6: $\{3,4,6\}$ (содержит 3, не 5). $f_{4,5,6} = 0$.

$$y_4^{(\text{tree})} = 0$$

**(d)** Резюме правила отбора:

| Поколение | $k_n$ | Измерение | $(k_n, E, U)$ Фано? | $y^{(\text{tree})}$ |
|---|---|---|---|---|
| **Тяжелейшее** | **1** | **A (awareness)** | **Да: $\{1,5,6\}$** | **$\neq 0$** |
| Лёгкое | 2 | S (stability) | Нет | $= 0$ |
| Лёгкое | 4 | L (levels) | Нет | $= 0$ |

**Доказательство.** Юкавская связь трёх измерений $(a,b,c)$ пропорциональна структурной константе октонионов:

$$y_{abc}^{(\text{tree})} \propto f_{abc}$$

где $f_{abc} = \pm 1$ тогда и только тогда, когда $\{a,b,c\}$ — Фановская линия $\mathrm{PG}(2,2)$, и $f_{abc} = 0$ иначе. Это следует из таблицы умножения $\mathbb{O}$: $e_a e_b = f_{abc} e_c + \delta_{ab}$.

Для поколения $k=1$ (линия $\{1,5,6\}$): $f_{156} = 1$ — Юкавская $O(1)$.
Для поколений $k=2,4$: тройки $(2,5,6)$ и $(4,5,6)$ — не Фановские линии, $f_{256} = f_{456} = 0$ — Юкавские равны нулю. $\blacksquare$

### 9.4 Z₃-симметрия и её нарушение

Отображение $\sigma: k \mapsto 2k \bmod 7$ является автоморфизмом плоскости Фано и циклически переставляет элементы Фано-линии $\{1,2,4\}$:

$$\sigma: 1 \to 2 \to 4 \to 1 \quad (\text{цикл } (1\,2\,4))$$

**Следствие.** Любой Фано-инвариантный функционал $F(k_1, k_2, k_3)$ удовлетворяет $F(1,2,4) = F(2,4,1) = F(4,1,2)$, т.е. **одинаков** для всех трёх поколений. Следовательно, массовая иерархия $m_t \gg m_c \gg m_u$ **не может** быть объяснена только Фано-геометрией — необходим Z₃-нарушающий фактор.

Этот фактор предоставляет Фано-Хиггсовая линия $\{1,5,6\}$: среди элементов генерационного триплета $(1,2,4)$ только $k=1$ лежит на этой линии. ~~Вакуумный Gap-профиль дополнительно нарушает Z₃, поскольку $k=1$ (A) и $k=2$ (S) лежат в 3-секторе, а $k=4$ (L) — в $\bar{3}$-секторе.~~ Отозвано [✗] (25.09.2026): метки секторов не являются разложением по $\mathrm{SU}(3)$ (Теорема 1.1(a)).

:::warning $\mathbb{Z}_3$ поколений — цветовое вращение

В базисе $A-iD$, $S-iU$, $L-iE$ триплета это циклическая матрица перестановки с определителем 1 (`test_generation_z3_lies_in_colour_su3`). ## 10. Массовая иерархия поколений

### 10.1 Теорема 10.1 (Массовая иерархия: качественная)

:::tip[Теорема 10.1 (Массовая иерархия) \[Т\]]
Фановское правило отбора [Т] (разд. 9.3) порождает иерархию масс $m_t \gg m_c, m_u$, разрешая уязвимость К-1 (парадокс IR fixed point).
:::

**(a)** $k=1$ (A) — **третье поколение** (t, b, $\tau$): древесная Юкавская связь $y_1^{(\text{tree})} \sim O(1)$. При RG-эволюции $y_1$ притягивается к quasi-IR fixed point (Пендлтон–Росс, 1981):

$$m_t = y_t^{(\text{FP})} \cdot \frac{v}{\sqrt{2}} \approx 1.0 \times 174 \approx 173 \text{ ГэВ}$$

**(b)** $k=2$ (S) и $k=4$ (L) — первое и второе поколения: $y_{2,4}^{(\text{tree})} = 0$. Массы генерируются **петлевыми** (loop) поправками через $V_3$-потенциал:

$$y_{2,4}^{(\text{eff})} \sim \epsilon_{\text{loop}} \ll 1$$

**(c)** Петлевые Юкавские **не** притягиваются к IR fixed point (поскольку $y \ll 1$, квадратичный член $c_1 y^2$ пренебрежим по сравнению с калибровочным $c_3 g_s^2$). Их RG-бег определяется аномальной размерностью массы:

$$y_n(\mu) = y_n(\mu_0) \cdot \left(\frac{\alpha_s(\mu)}{\alpha_s(\mu_0)}\right)^{12/(33-2N_f)} \quad (n = 2, 4)$$

### 10.2 Разрешение парадокса IR fixed point

:::info[Разрешение уязвимости К-1]
Ранее постулировались три O(1) начальные Юкавские ($|y_1|:|y_2|:|y_3| = 0.78:0.98:0.43$), которые все стягиваются к единой IR fixed point, не порождая иерархии. Фановское правило отбора устраняет эту проблему: начальные Юкавские — $y_1^{(0)} \sim O(1)$, $y_2^{(0)} = 0$, $y_4^{(0)} = 0$.
:::

RG-система с одной O(1) Юкавской + двумя малыми:

$$\frac{dy_1}{d\ln\mu} \approx \frac{y_1}{16\pi^2}(c_1 y_1^2 - c_3 g_s^2 - c_4 g_W^2)$$

$$\frac{dy_n}{d\ln\mu} \approx \frac{y_n}{16\pi^2}(c_2 y_1^2 - c_3 g_s^2 - c_4 g_W^2) \quad (n = 2, 4;\; y_n \ll 1)$$

$y_1$ притягивается к $y^{(\text{FP})} = \sqrt{(c_3 g_s^2 + c_4 g_W^2)/c_1} \approx 1$. Малые $y_{2,4}$ бегут с аномальной размерностью и **сохраняют** свою малость. Иерархия устойчива при RG-эволюции к электрослабому масштабу.

### 10.3 Механизм генерации масс лёгких поколений

Поколения $k=2$ (S) и $k=4$ (L) с $y^{(\text{tree})} = 0$ получают массы через **смешивание** с поколением $k=1$ (A), индуцированное $V_3$-вершинами на не-Фано тройках через промежуточное измерение $D=3$:

- $V_3 \supset \lambda_3 |\gamma_{12}| |\gamma_{23}| |\gamma_{13}| \sin(\theta_{12} + \theta_{23} - \theta_{13})$ — тройка $\{1,2,3\} = \{A,S,D\}$
- $V_3 \supset \lambda_3 |\gamma_{24}| |\gamma_{43}| |\gamma_{23}| \sin(\theta_{24} + \theta_{43} - \theta_{23})$ — тройка $\{2,4,3\} = \{S,L,D\}$
- $V_3 \supset \lambda_3 |\gamma_{14}| |\gamma_{43}| |\gamma_{13}| \sin(\theta_{14} + \theta_{43} - \theta_{13})$ — тройка $\{1,4,3\} = \{A,L,D\}$

Все три — не-Фано тройки (содержат $D=3$ как посредник). Смешивание поколений проходит через **измерение D**, которое страница называла «цветовым измерением» и связывала с [конфайнментом](/docs/physics/gauge-symmetry/confinement); ни одна ось не есть цветовое направление (триплет натянут на $A-iD$, $S-iU$, $L-iE$, Теорема 1.1(a)), так что эта связь отозвана [✗].

### 10.4 Теорема 10.2 (Назначение поколений и Фано-расстояние до Хиггса)

:::warning[Гипотеза 10.2 (Назначение поколений) \[Г\]]
Различие между $k=2$ и $k=4$ определяется типом промежуточного сектора в Фано-пути к Хиггсу. Строго — гипотеза, требующая решёточного подтверждения. «Секторы» ниже — множества пар осей, а не секторы $\mathrm{SU}(3)$ (Теорема 1.1(a)); посылка, что пара $(L,D)$ несёт Gap $\approx0$, а $(S,D)$ — Gap $\sim\epsilon$, есть вакуумное допущение (СА) [Г] из [поколений фермионов, §4.4](/docs/physics/particle-physics/fermion-generations#гипотеза-секторной-асимметрии).
:::

Определим **О-свободное Фано-расстояние** $d_H(k_n)$ как минимальное число Фано-линий в пути от $k_n$ к Хиггсу $(E, U)$, не проходящем через $O = 7$ ($\mathrm{Gap} \sim 1$, подавленные пути).

**(a)** $k=1$ (A): прямая Фано-линия $\{1,5,6\}$. $d_H(1) = 0$ (древесный уровень).

**(b)** $k=2$ (S): путь $\{2,3,5\}: S \to D \to E$, затем $\{5,6,1\}: E \to U$. Один промежуточный шаг через $3$-to-$3$ сектор ($\mathrm{Gap} \sim \epsilon_{\text{space}} \neq 0$). $d_H(2) = 1$.

**(c)** $k=4$ (L): путь $\{3,4,6\}: L \to D \to U$, затем $\{5,6,1\}: U \to E$. Один промежуточный шаг, целиком через конфайнмент-сектор ($\mathrm{Gap} \approx 0$). $d_H(4) = 1$.

**(d)** Ключевое различие: путь $k=2$ проходит через $3$-to-$3$ сектор ($\mathrm{Gap} \sim \epsilon_{\text{space}} \neq 0$), а путь $k=4$ — целиком через конфайнмент-сектор ($\mathrm{Gap} \approx 0$). Поэтому $k=4$ имеет бо&#769;льшую связность с Хиггсом:

$$y_4^{(\text{eff})} > y_2^{(\text{eff})}$$

**(e)** Предсказание назначения поколений:

## 11. N=1 суперсимметрия из $G_2$-голономии

### 11.1 Теорема 11.1 (N=1 SUSY из параллельного спинора)

:::tip[Теорема 11.1 (N=1 SUSY) \[Т\]]
Параллельный спинор $\eta_0 = 1_\mathbb{O}$ определяет ровно одну сохраняющуюся суперсимметрию — N=1 SUSY в 4D. Стандартный результат теории $G_2$-компактификации.
:::

**(a)** Из M-теории (Аганагич–Витте, 2001; Аткия–Виттен, 2001): компактификация 11D $\to$ 4D на 7-мерном $G_2$-многообразии $M_7$:

$$\mathbb{R}^{1,3} \times M_7, \quad \mathrm{Hol}(M_7) = G_2$$

Число суперсимметрий в 4D = число ковариантно постоянных спиноров на $M_7$ = число синглетов в разложении $8_s \to 1 \oplus 7$.

**(b)** $G_2 \subset \mathrm{Spin}(7)$: $\Delta_7 = \mathbb{R}^8 \to 1 \oplus 7$ — ровно **один** параллельный спинор $\eta_0$. Следовательно, **N=1 SUSY** в 4D.

**(c)** Генератор суперсимметрии:

$$Q_\alpha = \eta_0 \otimes \psi_\alpha^{(4D)}$$

Антикоммутатор:

$$\{Q_\alpha, \bar{Q}_{\dot{\beta}}\} = 2\sigma^\mu_{\alpha\dot{\beta}} P_\mu$$

**(d)** SUSY-преобразования. Для Gap-поля $\theta_{ij}$ и его суперпартнёра $\tilde{\theta}_{ij}$ (гапсино):

$$\delta_\epsilon \theta_{ij} = \bar{\epsilon} \tilde{\theta}_{ij}, \quad \delta_\epsilon \tilde{\theta}_{ij} = i\sigma^\mu \bar{\epsilon} \partial_\mu \theta_{ij}$$

**Доказательство.** Стандартный результат теории $G_2$-компактификации (Joyce-Karigiannis, 2017). Ковариантно постоянный спинор $\nabla \eta_0 = 0$ на $M_7$ тогда и только тогда, когда $\mathrm{Hol} \subseteq G_2$ (теорема Бергера). $\blacksquare$

### 11.2 Теорема 11.2 (Суперпартнёрный спектр)

:::tip[Теорема 11.2 (Суперпартнёрный спектр) \[Т\]]
N=1 SUSY удваивает Gap-спектр: каждому Gap-полю $\theta_{ij}$ (бозон, спин 0) соответствует суперпартнёр — гапсино $\tilde{\theta}_{ij}$ (фермион, спин 1/2).
:::

| Частица SM | Gap-конфигурация | Суперпартнёр | Gap-конфигурация |
|---|---|---|---|
| Кварк $q_L$ | $\mathrm{Gap}(E,U)=0$, $\mathrm{Gap}(3\text{-}\bar{3})\neq 0$ | Скварк $\tilde{q}_L$ | $\theta_{\text{Gap}} \to$ бозон |
| Глюон $g$ | $\delta\theta_{ij}^{(3\bar{3})}$ | Глюино $\tilde{g}$ | $\tilde{\theta}_{ij}^{(3\bar{3})}$ |
| $W^\pm, Z$ | $\delta\theta_{EU}$, $\delta\theta_{LE,LU}$ | Wino, Zino | $\tilde{\theta}_{EU}$, ... |
| Хиггс $H$ | $\gamma_{EU}$ (VEV) | Хиггсино $\tilde{H}$ | $\tilde{\gamma}_{EU}$ |
| Гравитон $g_{\mu\nu}$ | Метрика из Gap | Гравитино $\psi_{3/2}$ | $\tilde{g}_{\mu\nu}$ |

В незнарушенной SUSY: масса суперпартнёра = масса частицы. Наблюдательно: SUSY нарушена ($m_{\tilde{q}} \gg m_q$).

### 11.3 SUSY-нарушение в Gap-формализме

:::warning[Гипотеза 11.3 (SUSY-нарушение через $V_3$) \[Г\]]
Нарушение SUSY в Gap-формализме — несовпадение бозонных и фермионных минимумов $V_{\text{Gap}}$. Конструкция суперпотенциала $W(\Theta)$ остаётся открытой задачей.
:::

**(a)** $V_3$ (PT-нечётный) нарушает SUSY: бозонный и фермионный вклады в $V_3$ не компенсируются:

$$V_3^{(\text{bos})} + V_3^{(\text{ferm})} \neq 0$$

**(b)** Параметр SUSY-нарушения (F-член):

$$F = \langle \partial V_{\text{Gap}} / \partial \theta \rangle_{\text{ferm}} \neq 0$$

**(c)** Масштаб SUSY-нарушения из $V_3$-динамики:

$$\sqrt{F} \sim \sqrt{\lambda_3 \cdot 28 \cdot \epsilon^3} \cdot \mu_{\text{phys}}$$

Для космологического Gap: $\mu_{\text{phys}} \sim M_{\text{Planck}}$, $\epsilon \sim \epsilon_{\text{GUT}} \sim 10^{-3}$:

$$\sqrt{F} \sim \sqrt{73.8 \times 28 \times 10^{-9}} \times M_{\text{Planck}} \approx 1.4 \times 10^{-3} \times M_{\text{Planck}} \approx 3.4 \times 10^{16} \text{ ГэВ}$$

Масштаб SUSY-нарушения $\sqrt{F} \sim 10^{16}$ ГэВ — промежуточный масштаб, близкий к GUT.

### 11.4 Теорема 11.4 (Масса гравитино)

:::warning[Гипотеза 11.4 (Масса гравитино) \[Г\*\]]
Предсказание $m_{3/2} \sim 10^{13}$ ГэВ условно на $\mu_{\text{phys}} = M_{\text{Planck}}$; при $\mu_{\text{phys}} = M_{\text{GUT}}$ значение смещается на 3-6 порядков.
:::

**(a)** Стандартная формула супергравитации:

$$m_{3/2} = \frac{F}{\sqrt{3} M_{\text{Planck}}}$$

**(b)** Из оценки $F \approx (1.4 \times 10^{-3})^2 M_{\text{Planck}}^2 \approx 2 \times 10^{-6} M_{\text{Planck}}^2$:

$$m_{3/2} \approx \frac{2 \times 10^{-6} M_{\text{Planck}}^2}{\sqrt{3} M_{\text{Planck}}} \approx 1.2 \times 10^{-6} M_{\text{Planck}} \approx 2.9 \times 10^{13} \text{ ГэВ}$$

**(c)** $m_{3/2} \sim 10^{13}$ ГэВ — **сверхтяжёлый** гравитино. Характерно для моделей с SUSY-нарушением на высокоэнергетическом масштабе (high-scale SUSY).

**(d)** Следствие: массы скварков и слептонов того же порядка:

$$m_{\tilde{q}} \sim m_{\tilde{l}} \sim m_{3/2} \sim 10^{13} \text{ ГэВ}$$

Недоступны для LHC ($\sqrt{s} = 14$ ТэВ). Это объясняет ненаблюдение суперпартнёров.

### 12.2 Следы SUSY

Косвенные следы SUSY могут проявляться в:

1. **Объединении калибровочных констант** при $\mu_{\text{GUT}} \sim 2 \times 10^{16}$ ГэВ (предсказывается). При $m_{\text{SUSY}} \sim 10^{13}$ ГэВ бета-функции содержат пороговые поправки (SM ниже $10^{13}$ ГэВ, MSSM выше), и точность объединения требует отдельной проверки.

2. **Массе Хиггса** $m_H \approx 125$ ГэВ — в пределах MSSM с тяжёлыми стопами.

3. Объединение калибровочных констант. Из Gap-RG:

$$\alpha_s(\mu_{\text{GUT}}) = \alpha_W(\mu_{\text{GUT}}) = \alpha_{\text{GUT}} \approx 1/24$$

Масштаб объединения:

$$\mu_{\text{GUT}} = M_Z \cdot \exp\left(\frac{2\pi}{\beta_1^{(1)}} \cdot \frac{1}{\alpha_1(M_Z) - \alpha_{\text{GUT}}}\right) \approx 2 \times 10^{16} \text{ ГэВ}$$

## 13. Распад протона {#распад-протона}

:::info[Замечание: пересмотр предсказаний распада протона]
В рамках Фано-электрослабой конструкции (ФЭ) X,Y-лептокварки **не предсказываются** (они были артефактом промежуточной $\mathrm{SU}(5)$-структуры). Однако распад протона остаётся возможен через $G_2$-экстра бозоны и высшие операторы.
:::

### 13.1 Распад протона через $G_2$-экстра бозоны

:::warning[Статус: Гипотеза \[Г\]]
Распад протона в рамках (ФЭ) опосредуется $G_2$-экстра бозонами планковской массы. Время жизни $\tau_p \sim 4\times10^{47}$ лет — практически ненаблюдаемо.
:::

6 $G_2$-экстра бозонов с $M_{G_2} \sim M_{\text{Planck}}$ опосредуют каналы распада протона (d=6 операторы через обмен $G_2$-экстра). Время жизни:

$$\tau_p^{(G_2)} \sim \frac{M_{\text{Planck}}^4}{\alpha_{G_2}^2 m_p^5} \sim 4\times10^{47} \text{ лет}$$

Это на $\sim 13$ порядков выше текущего экспериментального предела (Super-Kamiokande: $\tau_p > 2.4 \times 10^{34}$ лет). **Протон фактически стабилен** в рамках (ФЭ): вычисление $M_{\text{Planck}}^4/(\alpha_{G_2}^2 m_p^5)$ при $M_{\text{Planck}}=1.22\times10^{19}$ ГэВ, $\alpha_{G_2}\sim1/24$ даёт $\sim4\times10^{47}$ лет — далеко за пределами любого детектора.

### 13.2 Следствия для экспериментов

| Эксперимент | Канал | Чувствительность | Статус в (ФЭ) |
|---|---|---|---|
| Super-Kamiokande | $p \to e^+\pi^0$ | $> 2.4 \times 10^{34}$ лет | Не ограничивает |
| Hyper-Kamiokande | $p \to e^+\pi^0$ | до $10^{35}$ лет | Не ограничивает |
| DUNE | $p \to K^+\bar{\nu}$ | до $10^{35}$ лет | Не ограничивает |

:::info[Фальсифицируемое следствие]
Обнаружение распада протона на масштабах $\tau_p \lesssim 10^{40}$ лет **фальсифицировало бы** (ФЭ), поскольку указывало бы на промежуточную калибровочную структуру (типа $\mathrm{SU}(5)$) с бозонами масштаба $M_X \ll M_{\text{Planck}}$.
:::

## 14. Обновлённая CKM-феноменология

### 14.1 Теорема 14.1 (Обновлённая фаза $\delta_{\text{CP}}$)

:::warning[Гипотеза 14.1 (Фаза CP-нарушения) \[Г\]]
Формула $\delta_{\text{CP}} = \arg(e^{2\pi i(k_{1\text{st}} + k_{2\text{nd}} - k_{3\text{rd}})/7})$ — эвристическая, не выведена из диагонализации Юкавских матриц.
:::

С назначением $k_{\text{1st}}=2$, $k_{\text{2nd}}=4$, $k_{\text{3rd}}=1$:

**(a)** Голое значение:

$$\delta_{\text{CP}} = \arg(e^{2\pi i(2+4-1)/7}) = \arg(e^{10\pi i/7}) = -\frac{4\pi}{7} \approx -102.9°$$

Модуль: $|\delta_{\text{CP}}| = 180° - 102.9° = 77.1°$ (приведение к первой полуплоскости; $\sin 77.1° = \sin 102.9°$).

**(b)** Двухпетлевая RG-поправка:

$$\delta^{(2)} \sim \frac{y_t^2}{16\pi^2} \cdot \ln\frac{\mu_{\text{GUT}}}{\mu_{\text{EW}}} \cdot \frac{2\pi}{7}$$

$$|\delta^{(2)}| \sim \frac{1.0}{16\pi^2} \times 39 \times 0.898 \approx 0.22 \text{ рад} \approx 12.6°$$

**(c)** Итоговое предсказание (при отрицательном знаке поправки):

$$|\delta_{\text{CP}}^{(\text{phys})}| \approx 77.1° - 12.6° = 64.5° \pm 5°$$

Наблюдаемое: $65.7° \pm 1.5°$ (глобальный фит PDG 2024); древесная (tree-level) комбинация LHCb даёт $64.6° \pm 2.8°$ (ICHEP 2024). Предсказанное $64.5°$ согласуется в пределах $\sim 0.1°$ ($\approx 0.04\sigma$) с прямым значением и в пределах $\sim 1\sigma$ с фитом. Прежнее $69° \pm 4°$ устарело. См. [CKM §4.2](/docs/physics/particle-physics/ckm-matrix#thm-4-2) для канонического значения.

:::info[Замечание о знаке]
Знак двухпетлевой поправки определяется из $\mathrm{Im}\,\mathrm{Tr}(Y_u Y_u^\dagger Y_d Y_d^\dagger [Y_u Y_u^\dagger, Y_d Y_d^\dagger])$ (Antusch et al., 2003). При положительном знаке: $77.1° + 12.6° = 89.7°$ — расхождение $> 8\sigma$ от прямого $64.6° \pm 2.8°$. Новое назначение **предсказывает отрицательный знак** поправки. Полный диапазон: $|\delta_{\text{CP}}| = 77.1° \pm 12.6°$ (от $64.5°$ до $89.7°$).
:::

### 14.2 Обновлённые углы CKM

С назначением $k_{\text{1st}}=2$, $k_{\text{2nd}}=4$, $k_{\text{3rd}}=1$:

**(a)** Фано-разности для CKM-углов:

$$\Delta k_{12} = |k_{\text{1st}} - k_{\text{2nd}}| = |2 - 4| = 2$$
$$\Delta k_{23} = |k_{\text{2nd}} - k_{\text{3rd}}| = |4 - 1| = 3$$
$$\Delta k_{13} = |k_{\text{1st}} - k_{\text{3rd}}| = |2 - 1| = 1$$

**(b)** Отношения Фано-фаз: $\Delta k_{12} : \Delta k_{23} : \Delta k_{13} = 2 : 3 : 1$. Наблюдаемые отношения углов: $\theta_{12} : \theta_{23} : \theta_{13} \approx 13° : 2.4° : 0.2° \approx 65 : 12 : 1$. Различие обусловлено RG-подавлением через текстуру Фрича:

$$\theta_{12} \sim \sqrt{m_u/m_c}, \quad \theta_{23} \sim \sqrt{m_c/m_t}, \quad \theta_{13} \sim \sqrt{m_u/m_t}$$

Углы определяются эффективными Юкавскими связями, а не Фано-разностями напрямую.

### 14.3 Лептонный сектор

**(a)** Фановское правило отбора применяется и к заряженным лептонам:
- $\tau$ (тяжелейший) — $k=1$ (A): древесная Юкавская.
- $\mu, e$ — $k=4, k=2$: петлевые.

**(b)** Нейтрино: массы определяются механизмом seesaw. Правило отбора даёт:

$$y_{\nu_\tau}^{(\text{tree})} \neq 0, \quad y_{\nu_\mu}^{(\text{tree})} = y_{\nu_e}^{(\text{tree})} = 0$$

$$m_\nu \sim \frac{y_\nu^2 v^2}{M_R} \implies m_{\nu_\tau} \gg m_{\nu_\mu} \gg m_{\nu_e}$$

Согласуется с нормальной иерархией масс нейтрино.

:::warning[Гипотеза (PMNS) \[Г\]]
Большие углы смешивания PMNS ($\theta_{12} \sim 34°$, $\theta_{23} \sim 45°$) объясняются тем, что массовая матрица правых нейтрино $M_R$ не подчиняется Фановскому правилу отбора (правые нейтрино — синглеты, не связаны с Хиггсом через E-U). Обоснование частичное: правило отбора специфично для электрослабых Юкавских связей.
:::
