# Представления калибровочной группы Стандартной модели

## Цвет на одном узле {#теорема-фэ}

<a id="теорема-единственности-фэ"></a>
<a id="электрослабое-разграничение"></a>

Стабилизатор выбранной мнимой единицы октонионов $u$ изоморфен $SU(3)$. Его действие на комплексном семимерном узле разлагается как $\mathbf1\oplus\mathbf3\oplus\bar{\mathbf3}$. Каждое из этих неэквивалентных неприводимых представлений входит один раз. По лемме Шура любой коммутирующий комплексно-линейный оператор скалярен на каждом слагаемом. Поэтому в коммутанте нет нетривиального действия независимой слабой $SU(2)$. Кроме того, $\mathrm{rank}(G_2)=2$, а ранг группы Стандартной модели равен четырём. [Стабилизатор мнимой единицы](./g2-structure).

## Слабый дублет на двух узлах {#кираль}

<a id="киральность-t327"></a>

Выберем общую ось $u$, один цветовой триплет $W$ и сектор с одним возбуждением. Его носитель имеет вид $\mathbb C^2\otimes(\mathbb C u\oplus W)$. Группа $SU(2)$, действующая на кратности по узлам, коммутирует с цветом. У абелева генератора с зарядами $q_s,q_t$ на синглете и триплете условие бесследовости даёт $q_s+3q_t=0$. При примитивной целочисленной нормировке $(-3,1)$ на лептонном дублете действует $z^{-3}h$, а на кварковом — $z(h\otimes g)$, где $g\in SU(3)$, $h\in SU(2)$ и $z\in U(1)$. Общее ядро порождено элементом $(e^{2\pi i/3}I_3,-I_2,e^{i\pi/3})$. Верный образ группы равен

$$
(SU(3)\times SU(2)\times U(1))/\mathbb Z_6.
$$

Ось, триплет, слабое действие и сектор здесь заданы. Расчёт зарядов не даёт правых синглетов и киральной теории полей. На трёх узлах элементарные обмены на соседних рёбрах уже не коммутируют. Локальный калибровочный закон требует согласованного действия на связях и материи в каждом узле. [Сетевые проверки](../../reference/network-results).

## Спинорная конструкция {#sm-из-клиффорда}

<a id="поколение-t329"></a>
<a id="запрет-z-прайм"></a>

В другой конструкции на вещественном спиноре $\mathrm{Spin}(9)$ выбирают комплексную структуру. При выборе, изученном Красновым, её централизатор реализует ту же глобальную группу. Отождествление спинорного модуля с физической материей — самостоятельная предпосылка (Cl₀). Выбор представления оставляет открытыми число его копий, дополнительные синглеты, динамику и взаимодействия. Сокращение аномалий можно проверить для полностью заданного кирального представления материи.
