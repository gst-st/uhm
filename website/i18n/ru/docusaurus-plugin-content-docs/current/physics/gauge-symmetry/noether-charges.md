# Заряды инвариантного действия

## Сохранение вдоль траектории {#шаг-6-доказательство}

Пусть для дифференцируемого лагранжиана $L(q,\dot q)$ каждая бесконечно малая вариация $\delta_a q$ меняет $L$ на полную производную $dB_a/dt$. Тогда вдоль решений уравнений Эйлера–Лагранжа сохраняется $Q_a=\sum_i (\partial L/\partial\dot q_i)\delta_a q_i-B_a$. Для применения к $G_2$ нужно динамическое действие с этой симметрией. Выбранный прибор или внешняя сила могут её нарушать. При локальной калибровочной симметрии определение физических зарядов дополнительно зависит от связей и граничных условий. [Нётер](https://arxiv.org/abs/physics/0503066).

## Инвариантные ковариации {#тождества-уорда-разложение}

<a id="6-тождества-уорда-для-gap-корреляторов"></a>

На $\Lambda^2\mathbb R^7=\mathbf7\oplus\mathbf{14}$ симметричная $G_2$-инвариантная ковариация имеет вид $a\mathsf P_7+b\mathsf P_{14}$ для проекторов соответствующего представления. Каждое неприводимое слагаемое входит один раз. Положительность требует $a,b\ge0$, а измерение следа задаёт $7a+14b$. Для определения обоих коэффициентов нужно ещё одно независимое измерение.

## Ковариация в координатах Фано {#оператор-f21-определение}

<a id="собственные-значения-f21"></a>

На 21 неориентированном ребре Фано соединим различные рёбра одной прямой. Каждое ребро входит в единственную прямую, поэтому матрица смежности $F$ состоит из семи блоков $J_3-I_3$. Её собственные значения 2 и $-1$ имеют кратности 7 и 14. У выбранного многочлена $C=\alpha(I-3F/7+3F^2/49)$ собственное значение на равномерном векторе равно $19\alpha/49$, второе значение равно $73\alpha/49$. Отношение зависит от многочлена. Для физической ковариации нужно задать состояние и измерение флуктуаций. Совпадение кратностей само по себе не даёт сплетающего оператора между беззнаковыми рёбрами и внешним квадратом представления.
