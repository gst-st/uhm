# Смешивание кварков и проверки моделей аромата

## Относительные базисы ароматов {#6-ckm-из-несовпадения-юкавских-текстур}

<a id="ckm-non-circularity"></a>
<a id="thm-10-1-t-265"></a>

Пусть $U_{uL},U_{dL}$ диагонализуют $Y_uY_u^\dagger,Y_dY_d^\dagger$ в общем базисе слабого взаимодействия. При трёх левых кварковых дублетах и обычном заряженном токе $V=U_{uL}^\dagger U_{dL}$ унитарна. Шесть сингулярных чисел не определяют это произведение. При тех же массах можно повернуть левый базис $Y_d$ относительно $Y_u$. Спектральная модель с заданными матрицами Юкавы позволяет вычислить $V$. Для проверки динамики ароматов нужно независимо обосновать эти матрицы. [Пример конечной спектральной модели](https://arxiv.org/abs/hep-th/0610241).

## Проверка текстуры на другой наблюдаемой {#derivation-vus}

Нулевая компонента матрицы масс зависит от базиса. Гипотеза о текстуре должна задать вид обеих матриц в одном базисе. В эрмитовом анзаце Фрича с шестью нулями $V_{cb}$ равен сумме трёх комплексных вкладов с двумя свободными относительными фазами. При бегущих массах из проверки репозитория на масштабе $M_Z$, $(m_u,m_c,m_t)=(0.00123,0.620,168.26)$ ГэВ и $(m_d,m_s,m_b)=(0.00267,0.05316,2.839)$ ГэВ, диагонализация даёт модули вкладов $a_i$, равные $0.00002491$, $0.13181608$ и $0.05993983$. Если направить два меньших вклада против большего, достигается граница треугольника $2\max_i a_i-\sum_i a_i=0.07185$. Опорное значение в этой проверке равно $0.04183$. Близость $\sqrt{m_d/m_s}$ к оценке угла Кабиббо этого расхождения не устраняет. [Воспроизводимые проверки масс и смешивания](https://github.com/gst-st/uhm/blob/main/website/scripts/check_core_numbers.py).

## Часы с семью тактами {#11-вкус-с-часов}

<a id="thm-4-2"></a>

У сдвига семь различных комплексных собственных значений. Любой коммутирующий с ним оператор диагонален в базисе Фурье. Если оба массовых оператора сохраняют отдельные моды семейств и имеют невырожденный спектр, их относительное преобразование сводится к перестановке и фазам. Для физического угла смешивания и CP-фазы требуется взаимодействие, различающее два базиса. При подгонке поправки к измеренной фазе это измерение становится параметром калибровки.
