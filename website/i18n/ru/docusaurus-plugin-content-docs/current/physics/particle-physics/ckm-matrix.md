# Смешивание кварков и проверки моделей аромата

## Относительные базисы ароматов {#6-ckm-из-несовпадения-юкавских-текстур}

<a id="ckm-non-circularity"></a>
<a id="thm-10-1-t-265"></a>

Пусть $U_{uL},U_{dL}$ диагонализуют $Y_uY_u^\dagger,Y_dY_d^\dagger$ в общем базисе слабого взаимодействия. При трёх левых кварковых дублетах и обычном заряженном токе $V=U_{uL}^\dagger U_{dL}$ унитарна. Шесть сингулярных чисел не определяют это произведение. При тех же массах можно повернуть левый базис $Y_d$ относительно $Y_u$. Спектральная модель с заданными матрицами Юкавы позволяет вычислить $V$. Для проверки динамики ароматов нужно независимо обосновать эти матрицы. [Пример конечной спектральной модели](https://arxiv.org/abs/hep-th/0610241).

## Проверка текстуры на другой наблюдаемой {#derivation-vus}

Нулевая компонента матрицы масс зависит от базиса. Гипотеза о текстуре должна задать вид обеих матриц в одном базисе. В эрмитовом анзаце Фрича с шестью нулями $V_{cb}$ равен сумме трёх комплексных вкладов с двумя свободными относительными фазами. При бегущих массах из проверки репозитория на масштабе $M_Z$, $(m_u,m_c,m_t)=(0.00123,0.620,168.26)$ ГэВ и $(m_d,m_s,m_b)=(0.00267,0.05316,2.839)$ ГэВ, диагонализация даёт модули вкладов $a_i$, равные $0.00002491$, $0.13181608$ и $0.05993983$. Если направить два меньших вклада против большего, достигается граница треугольника $2\max_i a_i-\sum_i a_i=0.07185$. Опорное значение в этой проверке равно $0.04183$. Близость $\sqrt{m_d/m_s}$ к оценке угла Кабиббо этого расхождения не устраняет. [Воспроизводимые проверки масс и смешивания](https://github.com/gst-st/uhm/blob/main/website/scripts/check_core_numbers.py).

## Часы с семью тактами {#11-вкус-с-часов}

<a id="thm-4-2"></a>

У сдвига семь различных комплексных собственных значений. Любой коммутирующий с ним оператор диагонален в базисе Фурье. Если оба массовых оператора сохраняют отдельные моды семейств и имеют невырожденный спектр, их относительное преобразование сводится к перестановке и фазам. Для физического угла смешивания и CP-фазы требуется взаимодействие, различающее два базиса. При подгонке поправки к измеренной фазе это измерение становится параметром калибровки. [Гармоники часов](./fermion-generations#поколения-t328).

## Запрет вильсоновских линий, модулярное нарушение CP и аудит CKM на $M = 7$ {#orbifold-ckm-cp-audit}

Прямая проверка смешивания CKM и инварианта Ярлскога $J_{\mathrm{CP}}$ в двухдублетной модели Хиггса на намагниченном орбифолде $(T^2/\mathbb{Z}_2, M = 7)$ (`verify_deep_frontier_v6.py`–`verify_deep_frontier_v10.py`, `ToEFrontierV7.lean`–`ToEFrontierV10.lean`) устанавливает четыре жёстких запрета и $SU(2)_L$-инвариантный / $G_2$-инстантонный пути:

1. **Безаксиомный запрет дискретных $\mathbb{Z}_2$ вильсоновских линий (`discrete_wilson_line_m7_disjoint_or_wrong_ng`) [Т] / [✗]:** Всякая нетривиальная дискретная скрутка $(\alpha, \beta) \neq (0, 0)$ либо сдвигает активную неподвижную точку $d_R$ с $z_{\mathrm{top}} = (\frac{1}{2}, \frac{1}{2})$, либо активирует 3 неподвижные точки ($N_{\mathrm{odd}} = 4 \neq 3$).
2. **Точный вещественный вакуум при $\tau = 1{,}5i$, запрет «иерархия против CP» и $SU(2)_L$-запрет на $(Y^a)^*$ [✗]:** При чисто мнимом $\tau = 1{,}5i$ тензор Юкавы чисто вещественен ($\max\lvert\mathrm{Im}\,Y\rvert = 1{,}4\times 10^{-17}$), а вещественный CP-инвариантный вакуум даёт строгий глобальный минимум с точным $J_{\mathrm{CP}} = 0$. При комплексном $\tau = 0{,}25 + 1{,}5i$ и одинаковом потоке $M_u = M_d = 7^-$ слабое отталкивание (`lam_ud = 0.05`) сохраняет обе иерархии ($r_u = [1{,}9\times 10^{-5}, 4{,}1\times 10^{-3}, 1]$, $r_d = [1{,}2\times 10^{-3}, 1{,}8\times 10^{-2}, 1]$), но даёт малые $\lvert V_{cb}\rvert = 0{,}0035$ и $J_{\mathrm{CP}} = 1{,}34\times 10^{-8}$, тогда как сильное отталкивание (`lam_ud = 0.45`) восстанавливает $J_{\mathrm{CP}} = 7{,}29\times 10^{-6}$ ценой разрушения $r_d = [0{,}11, 0{,}43, 1]$ и сдвига $\lvert V_{us}\rvert = 0{,}994$. Сопряжение всего нижнего тензора $M_d \to \sum v_{d,a}(Y^a)^*$ явно нарушает $SU(2)_L$ на дублете $Q_L = (u_L, d_L)$ ($M(d_L) = -7 \neq M(u_L) = +7$), а сопряжение только $d_R^c$ вынуждает $M_{H_d} = 0$ и $Y_d = I_3$ (ошибка $2{,}2\times 10^{-16}$).
3. **Исчерпывающее закрытие единого $M_Q = M_u = M_d = 7$ на чистом $T^2_{12}/\mathbb{Z}_2$ (`verify_deep_frontier_v10.py` V10.2.B, `z2_orbifold_wilson_line_discretization_and_twist_gap`, `F-37B`, 0 аксиом) [Т] / [✗]:** Непрерывные линии Вильсона явно нарушают инволюцию орбифолда $\mathbb{Z}_2$ ($\lVert P^2 - I\rVert = 0{,}418$ при $\alpha = 0{,}10$, $1{,}209$ при $\alpha = 0{,}25$ против $3{,}5\times 10^{-15}$ при $\alpha \in \{0, 1/2\}$). По всем четырём допустимым дискретным $\mathbb{Z}_2\times\mathbb{Z}_2$-скруткам на $H_d$ при ненарушенном $M_Q = M_u = M_d = 7$: нескрученная `(0,0)` ($n_{H_d}=8$, зазор `0.5145`) выравнивает $v_u \parallel v_d$ внутри 5D подпространства Веронезе ($\lvert V_{us}\rvert = 0{,}033$, $\lvert V_{ub}\rvert = 0{,}000$, $J = 7{,}75\times 10^{-11}$ [✗]), а **все три** нетривиальные скрутки `(0.5,0), (0,0.5), (0.5,0.5)` теряют единственную 8-ю ранг-1 синглетную моду $H^+(14)$ (`8 -> 7`, зазор `0.0000` — точное 3-кратное вырождение!), разрушая иерархию нижних кварков ($m_s/m_b = 0{,}796\text{–}0{,}912$) и переворачивая смешивание 1-го/3-го поколений ($\lvert V_{ub}\rvert = 0{,}833\text{–}0{,}978$ [✗]). Тем самым реалистичная CKM **строго требует** либо расщепления потока $T_{3R}$ ($M_d = 4$), либо многоторной / раздутой локализации юкавских связей $\overline{\mathbf{126}}_H$.
4. **Истинно $SU(2)_L$-инвариантная $T_{3R}$-сдвинутая 2HDM и $G_2$-инстантонная стабилизация CP (`V10.2.A`, `g2_membrane_instanton_cp_bifurcation_cq`, `F-37A`) [Т] / [С] / [П]:** Выбор $M_Q = M_{u^c} = 7^-$, $M_{d^c} = 4^+$ ($M_{H_u} = 14^+$, $M_{H_d} = 11^-$) при комплексном $\tau = 0{,}25 + 1{,}5i$ (`c_d = 30`) нарушает модулярную CP при точном сохранении $SU(2)_L$, давая $r_u = [2{,}2\times 10^{-5}, 3{,}8\times 10^{-3}, 1]$, $\lvert V_{cb}\rvert = 0{,}092$, $\lvert V_{ub}\rvert = 0{,}0081$ и $J_{\mathrm{CP}} = 1{,}92\times 10^{-5}$ (против СМ $3{,}1\times 10^{-5}$). Более того, $\gamma$-нарушающий мембранный $G_2$-инстантон с полуцелой фазой $\phi_{\mathrm{EH}} = \pi/2$ добавляет $-A_{\mathrm{np}}\sin(2\pi\operatorname{Re}\tau)$ к радиационному барьеру Хиггса V9.4 $\Delta V = +2{,}057\times 10^{-3}$, порождая точную вилочную фазовую диаграмму CP-стабилизации с минимумом $\sin(2\pi\operatorname{Re}\tau)_* = \min(1, A_{\mathrm{np}}/(2\Delta V)) > 0$ для всякого $A_{\mathrm{np}} > 0$ и жёсткой фиксацией максимального CKM CP в $\operatorname{Re}\tau = 1/4$ ($J_{\mathrm{CP}} = 1{,}92\times 10^{-5}$) при всех $A_{\mathrm{np}} \ge 2\Delta V = 4{,}114\times 10^{-3}$ (тогда как $\gamma$-сохраняющий $\phi_{\mathrm{EH}} = 0$ остаётся строго в $\operatorname{Re}\tau = 0$) [Т/С]. Воспроизведение остатка $\lvert V_{us}\rvert = 0{,}225$ (сейчас $0{,}057$) и $m_s/m_b = 0{,}021$ (сейчас $0{,}086$) через раздутую/многоторную юкавскую структуру $\overline{\mathbf{126}}_H$ остаётся открытым [П].
