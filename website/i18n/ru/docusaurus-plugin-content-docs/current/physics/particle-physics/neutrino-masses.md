# Массы и смешивание нейтрино

## Исключение тяжёлого сектора {#seesaw}

<a id="гипотеза-o-секторного-масштаба"></a>
<a id="теорема-нейтрино-o-сектор"></a>
<a id="теорема-mr-из-gap"></a>

В seesaw типа I задают электрослабые синглетные фермионы, дираковскую массу $m_D$ и обратимую симметричную майорановскую матрицу $M_R$. Если синглеты тяжелы по сравнению со смешиванием, главную часть матрицы лёгких масс даёт дополнение Шура

$$
M_\mathrm{light}=-m_D M_R^{-1}m_D^T .
$$

В одном семействе видно, что масштаб остаётся свободным. При вещественном $c>0$ замена $m_D\mapsto c m_D$, $M_R\mapsto c^2 M_R$ сохраняет лёгкую массу в главном порядке, меняя тяжёлый масштаб. Частота часов и размерность октонионного представления сами по себе не фиксируют ни одну матрицу. Для петлевого происхождения $M_R$ потребовались бы явные взаимодействия с нарушением лептонного числа.

## Наблюдаемые спектральные разности {#теорема-отношение-нейтринных-масс}

Лёгкие массы — неотрицательные сингулярные числа в факторизации Такаги. Фазы осцилляций зависят от разностей $\Delta m^2_{ij}$ и отношения длины базы к энергии. Общий сдвиг всех $m_i^2$ сохраняет эти разности. Абсолютные массы, порядок масс и тяжёлый масштаб требуют различных входных данных или измерений.

## Смешивание {#теорема-pmns-анархия}

Матрица лептонного смешивания сопоставляет диагонализующие базисы заряженных лептонов и лёгких нейтрино. Качественное предположение об анархии $M_R$ не задаёт численный угол без распределения на матрицах и прочих входных данных. Проверить предложенную модель можно на осцилляционном спектре, который не использовался при фиксации параметров. [Варианты измерений](../../reference/frontier-ledger).

## Не-PQ механизм качелей `Chain A2`, $3\times 3$ матрица плотности лептогенеза и запрет Вейля {#nonpq-chain-a2-seesaw}

В цепочке Пати–Салама стабилизатора оси часов УГМ ($\mathrm{Spin}(10) \to G_{422} \to G_{\mathrm{SM}}/\mathbb{Z}_6$) ограничения по распаду протона запирают $M_{\mathrm{PS}} \le 3{,}06\times 10^{11}\,\text{ГэВ}$ ([Распад протона](./proton-decay#chain-a2-proton-decay)), жёстко разделяя жизнеспособные и фальсифицированные механизмы масс нейтрино и бариогенеза (`verify_deep_frontier_v4.py`–`verify_deep_frontier_v9.py`, `ToEFrontierDynamics.lean`, `ToEFrontierV6.lean`–`ToEFrontierV9.lean`):

1. **Фальсифицированные минимальные механизмы [✗]:** Наивный Type-I seesaw Пати–Салама ($Y_\nu = Y_u$ при $M_{\mathrm{PS}} \approx 9{,}19\times 10^{10}\,\text{ГэВ}$) предсказывает $m_{\nu 3} = 102{,}1\,\text{эВ}$ — перелёт в $2042\times$ (`patiSalam_naive_seesaw_exceeds_obs_cq`). Ограничение сектором с симметрией Печчеи–Квинн $\mathbf{10}_H \oplus \overline{\mathbf{126}}_H$ также не проходит под потолком Super-K (требует $M_{N_3} \sim 5{,}4\times 10^{12}\text{–}1{,}1\times 10^{13}\,\text{ГэВ}$).
2. **Точное спасение не-PQ `Chain A2` (`nonPQ_chainA2_decoupling_cq`) [Т] / [С]:** Отказ от внешней симметрии PQ (отсутствующей в клиффордовом содержании УГМ, `T-333`) даёт цепочке `Chain A2` ($\mathbf{10}_H \oplus \mathbf{10}_H^* \oplus \overline{\mathbf{126}}_H$, комплексный бидублет $(1,2,2)_{\mathbb{C}}$) точное алгебраическое разложение $M_{\nu_D} = M_u - r_u(M_d - M_e)$ и $M_R \propto B = \frac{1}{4}(M_d - M_e)$. При тождественном воспроизведении всех 9 заряженных масс и CKM достигается $\chi^2_\nu = 0{,}000000$ по всем 4 наблюдаемым осцилляций/PMNS ($\sin^2\theta_{12}=0{,}3070$, $\sin^2\theta_{23}=0{,}5460$, $\sin^2\theta_{13}=0{,}02200$, $r_{\Delta m}=0{,}02956$, $J_{\mathrm{PMNS}} = 0{,}0329$), выполняется космологический предел DESI $\sum m_\nu = 0{,}0650 < 0{,}072\,\text{эВ}$ (нормальный порядок: $[4{,}83, 9{,}87, 50{,}30]\,\text{мэВ}$) и потолок Super-K ($M_N \le 3{,}06\times 10^{11}\,\text{ГэВ}$) при пертурбативном $r_u$.
3. **Полный 13-ODE $3\times 3$ плотностно-матричный лептогенез с динамическим $y_c(z)$ и 3-канальным теплово-пороговым EW $\Delta L = 1$ (`spectator_3x3_u2_covariant_collapse_cq`, `dynamic_yc_onsager_schur_complement_cq`, F-34) [Т] / [С]:** При $T = M_{N_1} = 1{,}801\times 10^{10}\,\text{ГэВ}$ 12-уравненческая химическая сеть СМ с динамическим равновесием чарма $\Delta_c(z) = \mu_{cR} - \mu_{uR}$ удовлетворяет точному онзагер-симметричному ранговому тождеству дополнения Шура ($v_c = -6w_c$, релаксационное собственное число Ляпунова $\lambda_c = 237/230 > 0$, $C_{230} - v_c w_c^T/\lambda_c \equiv C_{316}$). Интегрирование связанной 13-ODE системы в немодифицированной строго пертурбативной точке `X_RES` ($M_N = [1{,}801\times 10^{10}, 1{,}827\times 10^{10}, 3{,}005\times 10^{11}]\,\text{ГэВ}$, расщепление $1{,}41\%$, $(M_2 - M_1)/\Gamma_2 = 9{,}69 \gg 1$, $r_u = +9{,}59 + 6{,}36i$) доказывает динамическое уравновешивание чарма (`Dc_fin/Dc_eq = 1,0000`), схлопывая прежнюю статическую вилку по $y_c$ с $-19{,}1\%$ до **$-0{,}34\%$** (`+5,925e-10 → +5,905e-10`). Замена прокси на точные первопринципные 4D дираковские теплово-пороговые EW-калибровочные рассеяния $\Delta L = 1$, проверенные по **всем трём кроссинг-каналам** ($N\ell\leftrightarrow\phi A$, $N\bar{\phi}\leftrightarrow\bar{\ell} A$, $NA\leftrightarrow\bar{\ell}\phi$; тождество Уорда $< 10^{-15}$, замкнутые формы $< 10^{-13}$, асимптотические тепловые массы $m_{W,B,H,\ell}/T$ и кинематические пороги $u_{\min} = (1+m_{\mathrm{in}}/M_1)^2$), даёт честное безподгоночное **$\eta_B = +5{,}591\times 10^{-10}$** (**$-8{,}65\%$** к Planck 2018 $+6{,}12\times 10^{-10}$). Количественный расчёт NLO-полосы тепловых неопределённостей в немодифицированной точке `X_RES` (`verify_deep_frontier_v9.py` V9.3.B) даёт: мягко/жёсткую ИК-отсечку $t$/$u$-каналов $\kappa_{\mathrm{IR}}\in[0{,}5,2{,}0] \Rightarrow [5{,}483, 5{,}711]\times 10^{-10}$ (`-10,41% .. -6,69%`), NLO-интерференцию топ-юкавского и EW-калибровочного секторов $\pm 15\% \Rightarrow [5{,}530, 5{,}654]\times 10^{-10}$ (`-9,64% .. -7,61%`), коллинеарное $1\leftrightarrow 2$ LPM-расщепление ($c_{\mathrm{LPM}} = +0{,}25$) $\Rightarrow 5{,}515\times 10^{-10}$ (`-9,88%`) и физический тепловой фазовый порог GNRS $f_{12}$ $\Rightarrow$ **`6,027e-10` (`-1,52%`)** отдельно либо **`5,821e-10` (`-4,88%`)** с LPM — итоговая физическая NLO-огибающая **`[5,354, 6,424] × 10⁻¹⁰` (`-12,52% .. +4,97%`)** чисто накрывает значение Planck $+6{,}12\times 10^{-10}$ без перенастройки `X_RES`. Первопринципное конечно-температурное NLO/LPM-пересуммирование остаётся открытым [П].
4. **Запрет Вейля на $U(1)_{L_e - L_\mu}$ и подгруппы $\mathrm{PSL}(2,7)$ (`weyl_2d_le_lmu_nogo_ratio_cq`) [Т] / [✗] / [П]:** В любом 2D $(e,\mu)$-блоке матрицы $B = \frac{1}{4}(M_d - M_e)$ сингулярное неравенство Вейля вынуждает $M_2/M_1 \ge (m_\mu - m_s)/(m_s + m_e) = 2{,}8318 \gg 1{,}01414$, доказывая необходимость примеси 3-го поколения $m_\tau$. Внутри $\mathrm{PSL}(2,7)$ модулярные стабилизаторы $D_4, S_3, \mathbb{Z}_4, \mathbb{Z}_3$ допускают 2-мерные майорановские инварианты с точным $M_1 = M_2 \neq M_3$, однако их динамическая связка с $B = \frac{1}{4}(M_d - M_e)$ остаётся открытой [П].
