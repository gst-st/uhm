# Гармоники часов и число семейств материи

## Три вещественные гармоники {#теорема-ровно-три-генерации}

<a id="поколения-t328"></a>

Циклический сдвиг на семи состояниях имеет комплексные характеры $k=0,\ldots,6$. Для вещественного сигнала шесть непостоянных характеров образуют три сопряжённые пары $\{1,6\}$, $\{2,5\}$, $\{3,4\}$. Каждая пара даёт одну вещественную двумерную гармоническую плоскость. Квадратичные вычеты $\{1,2,4\}$ дают по представителю каждой пары. Сопоставление каждой плоскости одному семейству фермионов — гипотеза (GC). Для любого представления материи $V$ та же внутренняя группа действует на $V^{\oplus m}$ при любом целом $m>0$.

## Разбиения на пары у точки Фано {#thm-2-1}

Зафиксируем точку Фано $O$. Четыре прямые вне неё задают вершины тетраэдра. Каждая из остальных шести точек принадлежит двум из этих прямых и обозначает соответствующее ребро. Три прямые через $O$ спаривают противоположные рёбра. Стабилизатор точки $S_4$ переставляет вершины тетраэдра.

Всего у шести рёбер 15 разбиений на пары. Одно содержит все три противоположные пары. Шесть содержат ровно одну (три выбора противоположной пары и два способа спарить остальные рёбра), восемь — ни одной. Формула Бёрнсайда показывает, что каждый случай образует одну орбиту. Тождество фиксирует все 15 разбиений, шесть 4-циклов — по одному, остальные 17 перестановок — по три. Число орбит равно $(15+6+51)/24=3$. Их размеры — **1, 6 и 8**.

## Физическое отождествление семейств {#прецеденты-три-поколения}

<a id="thm-gen-4-1"></a>
<a id="thm-gen-4-2"></a>
<a id="гипотеза-секторной-асимметрии"></a>

Ассоциатор октонионов обращается в нуль на каждой из семи прямых Фано, в том числе на всех четырёх прямых без $O$. Этого условия недостаточно для выбора семейств. Физическая модель должна отождествить поля материи, сохранить их калибровочные преобразования и различить их отклики. При назначении меток по наблюдаемому порядку масс этот порядок уже входит в исходные данные. Маног и Дрей исследовали другое отождествление, использующее кватернионные подалгебры через выбранную единицу. [Их конструкция](https://arxiv.org/abs/hep-th/9807044) · [Проверка по смешиванию](./ckm-matrix#11-вкус-с-часов).

## Безусловная модулярная единственность $M = 7$ и нечётный отбор топ-кварка {#modular-uniqueness-m7}

На намагниченном орбифолде тора $T^2/\mathbb{Z}_2$ с потоком $M$ независимые конструктивные теоремы (`ToEFrontierV6.lean`–`ToEFrontierV10.lean`, `verify_deep_frontier_v6.py`–`verify_deep_frontier_v10.py`) однозначно выделяют фановский поток $M = 7$ и его $N_g = 3$ нечётных хиральных нулевых моды:

1. **Безусловная модулярная единственность (`psl2_order_168_unique_fano7`) [Т]:** Конструктивное доказательство оценки $M \le J_2(M)$ для всех $M \ge 2$ показывает, что $\lvert\mathrm{PSL}(2,\mathbb{Z}_M)\rvert = 168 = \lvert\mathrm{Aut}(\mathrm{PG}(2,2))\rvert$ выполняется **тогда и только тогда, когда $M = 7$** (при всех $M \ge 19$ строго $\lvert\mathrm{PSL}(2,\mathbb{Z}_M)\rvert > 168$). Поскольку $7 \equiv 3 \pmod 4$, 7-мерное пространство Ландау распадается как $H_7 = H_4^+ \oplus H_3^-$, где 4 чётные моды несут **проективное** представление с $\mathbb{Z}_2$-препятствием ($\lVert S_{\mathrm{even}}^2 + I_4\rVert = 2{,}4\times 10^{-15}$), а **$N_g = 3$ нечётных поколения** несут точное **линейное** неприводимое 3D представление Вейля группы $\mathrm{PSL}(2,7)$ ($\lVert S_{\mathrm{odd}}^2 - I_3\rVert = 3{,}3\times 10^{-15}$, $\lvert\langle S_{\mathrm{odd}}, T_{\mathrm{odd}}\rangle\rvert = 168$, норма характера $1{,}0000000000$) [Т].
2. **Закон отбора нечётного $M = 7$ против чётного $M = 8$ (`fano7_vs_m8_odd_generation_selection`, `fano7_vs_m8_active_fixed_point_counts`) [Т]:** Оба потока $M = 7$ и $M = 8$ дают $N_g = 3$ нечётных поколения, однако любой чётный поток ($M = 6, 8$) обращается в нуль **во всех четырёх** неподвижных точках орбифолда (`[0, 0, 0, 0]`): при $M = 8$ юкавское ядро имеет нулевой спектральный зазор ($0{,}0000$) и неиерархический спектр $[0{,}605, 0{,}658, 1{,}0]$ (концентрация Шура $0{,}4084$) [✗]. Напротив, нечётный фановский $M = 7$ концентрирует $100\%$ плотности нечётных мод в единственной неподвижной точке $z_{\mathrm{top}} = (\frac{1}{2}, \frac{1}{2})$ ($\sum \lvert\chi_i\rvert^2 = 7{,}00 = M$), единственным образом давая $\lambda_{\max}(K^{\mathrm{Yuk}}) = 7/2$ и точное ранг-1 доминирование третьего поколения $[0, 0, 1]$ (концентрация Шура $1{,}0000$) [Т].
3. **$G_2$-инстантонная компактификация на $T^7/\mathbb{Z}_2^3$ и точный $\gamma$-запрет CP (`F-35A,B,C,C',C''`) [Т] / [С] / [П]:** Хотя нескрученный абелев поток на орбифолде Джойса $T^7/\mathbb{Z}_2^3$ тождественно зануляется ($b_2^{\mathrm{untw}} = 0/21$) [✗], подъём $\gamma$ внешним/коммутантным зарядовым сопряжением $\hat{\gamma}(H) = -H$ (напр. $U(1)_H \subset E_6$, сохраняющим ненарушенную $\mathrm{Spin}(10)$) делает спаренный поток $F \otimes H = ((7/A_{12})e^{12} - (1/A_{34})e^{34})\otimes H$ решением всех 7 $G_2$-инстантонных уравнений ровно в BPS-минимуме кэлеровых площадей $A_{12}/A_{34} = 7$ ($E_{\mathrm{YM}}(7) = 7$), давая ровно $N_g = 3\times 1 + 4\times 0 = 3$ поколения $H_3^-(7) \otimes \bar{H}_1^+(-1)$ [С]. Однако $\gamma: z_{12} \mapsto \bar{z}_{12}$ вынуждает $2\operatorname{Re}\tau \in \mathbb{Z}$, поэтому CP-нарушающий CKM-модуль $\tau = 0{,}25 + 1{,}5i$ ($2\operatorname{Re}\tau = 0{,}5 \notin \mathbb{Z}$, `joyce_gamma_tau_obstruction_cq`) явно нарушает $\gamma$ [✗]. Более того, на **непрямоугольной $\gamma_1$-сохраняющей границе $\operatorname{Re}\tau = 1/2$** ($2\operatorname{Re}\tau = 1 \in \mathbb{Z}$) точное действие Шерка–Шварца $\gamma_1(\alpha,\beta)=(-\alpha,\beta+\alpha+M/2)\bmod 1$ (`max proj err = 3,3e-15`) однозначно отбирает $\alpha = 1/2$ для нечётных потоков $M\in\{7,11\}$ и $\alpha = 0$ для чётных $M\in\{4,14\}$ (`joyce_gamma_twist_parity_selection`, `F-35C'`, 0 аксиом), а $\gamma_1$-вещественный базис Такаги делает обе матрицы $Y_u, Y_d$ строго вещественными по всем 4 трёхпоколенческим скруткам $(\beta_Q,\beta_u)\in\{0,1/2\}^2$ (`max|Im Y| < 1,4e-14`), навязывая базисно-независимое зануление **$\det([M_u M_u^T, M_d M_d^T]) = 0$** (`joyce_gamma_real_basis_cp_nogo_cq`, `det3_skew_symm_eq_zero_cq`, `F-35C''`, `|det| = 4,20e-20`) с сертифицированным положительно определённым 11×11 мнимым гессианом ($\lambda_{\min}(H_{\mathrm{im}}) = +11{,}0022 > 0$) в иерархическом режиме (`cu=12, cd=30`), тогда как спонтанное CPV в квартическом пределе ($c_u=c_d=0$, $\lambda_{\min} = -0{,}234$, $J_{\mathrm{CP}} = 2{,}67\times 10^{-2}$) разрушает иерархию масс кварков ($m_c/m_t = 0{,}967$, $m_s/m_b = 0{,}958$) [✗]. Скан по $\operatorname{Re}\tau \in [0, 0{,}5]$ при $\operatorname{Im}\tau = 1{,}5$ показывает, что хотя $J_{\mathrm{CP}}$ достигает пика в $\operatorname{Re}\tau = 0{,}25$ ($1{,}924\times 10^{-5} \approx 1{,}92\times 10^{-5}\sin(2\pi\operatorname{Re}\tau)$), радиационный потенциал Хиггса тянет $\operatorname{Re}\tau$ обратно к CP-сохраняющему $\operatorname{Re}\tau = 0$ через барьер $\Delta V(0{,}25\to 0) = +2{,}057\times 10^{-3}$ ($1{,}89\times 10^{-5}|V|$). В `V10.2`/`V11.2` (`F-37B`, `ToEFrontierV11.lean` `F-41A,B`) единый поток $M_Q = M_u = M_d = 7$ на чистом $T^2_{12}/\mathbb{Z}_2$ исчерпывающе закрыт по непрерывным линиям Вильсона и всем 4 дискретным $\mathbb{Z}_2\times\mathbb{Z}_2$-скруткам (потеря 8-й синглетной моды `8 -> 7`, точное 3-кратное вырождение, $m_s/m_b = 0{,}80\text{–}0{,}91$ [✗]); при этом прежнее утверждение `V10.2.A` о $G_2$-инстантонной стабилизации CP (`F-37A`) **явно отозвано** (`V11.2.B,C`: категориальная ошибка «метрика против $C_3$-аксиона», $|q| = 8{,}070\times 10^{-5}$ в $50{,}98\times$ ниже $A_{\mathrm{crit}}$, 11D объёмные тиски $G_2$ с $t_{\mathrm{EH}} < \ell_{11}$ и $114\times$ обвалом предфактора $e^K$, запрет Харви–Мура $b_1(S^2_{\mathrm{EH}}\times S^1) = 1 \neq 0$ и CP-сохраняющие минимумы $\mathrm{SL}(2,\mathbb{Z})$), а строго безаксиомная **`F-41`** исключает $\overline{\mathbf{126}}_H$ ($c(D_5,5) = 225/13 > 16$) и $\mathbf{210}_H$ из всех ADE-развёрток и геометрических гетеротических компактификаций [Т/✗] (см.
