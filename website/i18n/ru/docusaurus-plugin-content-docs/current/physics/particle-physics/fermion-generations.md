# Гармоники часов и число семейств материи

## Три вещественные гармоники {#теорема-ровно-три-генерации}

<a id="поколения-t328"></a>

Циклический сдвиг на семи состояниях имеет комплексные характеры $k=0,\ldots,6$. Для вещественного сигнала шесть непостоянных характеров образуют три сопряжённые пары $\{1,6\}$, $\{2,5\}$, $\{3,4\}$. Каждая пара даёт одну вещественную двумерную гармоническую плоскость. Квадратичные вычеты $\{1,2,4\}$ дают по представителю каждой пары. Сопоставление каждой плоскости одному семейству фермионов — гипотеза (GC). Для любого представления материи $V$ та же внутренняя группа действует на $V^{\oplus m}$ при любом целом $m>0$.

## Разбиения на пары у точки Фано {#thm-2-1}

Зафиксируем точку Фано $O$. Четыре прямые вне неё задают вершины тетраэдра. Каждая из остальных шести точек принадлежит двум из этих прямых и обозначает соответствующее ребро. Три прямые через $O$ спаривают противоположные рёбра. Стабилизатор точки $S_4$ переставляет вершины тетраэдра.

Всего у шести рёбер 15 разбиений на пары. Одно содержит все три противоположные пары. Шесть содержат ровно одну (три выбора противоположной пары и два способа спарить остальные рёбра), восемь — ни одной. Формула Бёрнсайда показывает, что каждый случай образует одну орбиту. Тождество фиксирует все 15 разбиений, шесть 4-циклов — по одному, остальные 17 перестановок — по три. Число орбит равно $(15+6+51)/24=3$. Их размеры — **1, 6 и 8**.

## Физическое отождествление семейств {#прецеденты-три-поколения}

<a id="thm-gen-4-1"></a>
<a id="thm-gen-4-2"></a>
<a id="гипотеза-секторной-асимметрии"></a>

Ассоциатор октонионов обращается в нуль на каждой из семи прямых Фано, в том числе на всех четырёх прямых без $O$. Этого условия недостаточно для выбора семейств. Физическая модель должна отождествить поля материи, сохранить их калибровочные преобразования и различить их отклики. При назначении меток по наблюдаемому порядку масс этот порядок уже входит в исходные данные. Маног и Дрей исследовали другое отождествление, использующее кватернионные подалгебры через выбранную единицу. [Их конструкция](https://arxiv.org/abs/hep-th/9807044) · [Проверка по смешиванию](./ckm-matrix#11-вкус-с-часов).
