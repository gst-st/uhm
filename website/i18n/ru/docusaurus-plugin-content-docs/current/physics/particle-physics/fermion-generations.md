# Гармоники часов и число семейств материи

## Три вещественные гармоники {#теорема-ровно-три-генерации}

<a id="поколения-t328"></a>

Циклический сдвиг на семи состояниях имеет комплексные характеры $k=0,\ldots,6$. Для вещественного сигнала шесть непостоянных характеров образуют три сопряжённые пары $\{1,6\}$, $\{2,5\}$, $\{3,4\}$. Каждая пара даёт одну вещественную двумерную гармоническую плоскость. Квадратичные вычеты $\{1,2,4\}$ дают по представителю каждой пары. Сопоставление каждой плоскости одному семейству фермионов — гипотеза (GC). Для любого представления материи $V$ та же внутренняя группа действует на $V^{\oplus m}$ при любом целом $m>0$.

## Разбиения на пары у точки Фано {#thm-2-1}

Зафиксируем точку Фано $O$. Четыре прямые вне неё задают вершины тетраэдра. Каждая из остальных шести точек принадлежит двум из этих прямых и обозначает соответствующее ребро. Три прямые через $O$ спаривают противоположные рёбра. Стабилизатор точки $S_4$ переставляет вершины тетраэдра.

Всего у шести рёбер 15 разбиений на пары. Одно содержит все три противоположные пары. Шесть содержат ровно одну (три выбора противоположной пары и два способа спарить остальные рёбра), восемь — ни одной. Формула Бёрнсайда показывает, что каждый случай образует одну орбиту. Тождество фиксирует все 15 разбиений, шесть 4-циклов — по одному, остальные 17 перестановок — по три. Число орбит равно $(15+6+51)/24=3$. Их размеры — **1, 6 и 8**.

## Физическое отождествление семейств {#прецеденты-три-поколения}

<a id="thm-gen-4-1"></a>
<a id="thm-gen-4-2"></a>
<a id="гипотеза-секторной-асимметрии"></a>

Ассоциатор октонионов обращается в нуль на каждой из семи прямых Фано, в том числе на всех четырёх прямых без $O$. Этого условия недостаточно для выбора семейств. Физическая модель должна отождествить поля материи, сохранить их калибровочные преобразования и различить их отклики. При назначении меток по наблюдаемому порядку масс этот порядок уже входит в исходные данные. Маног и Дрей исследовали другое отождествление, использующее кватернионные подалгебры через выбранную единицу. ## Безусловная модулярная единственность $M = 7$ и нечётный отбор топ-кварка {#modular-uniqueness-m7}

На намагниченном орбифолде тора $T^2/\mathbb{Z}_2$ с потоком $M$ две независимые теоремы (`ToEFrontierV6.lean`–`ToEFrontierV8.lean`, `verify_deep_frontier_v6.py`–`verify_deep_frontier_v8.py`) однозначно выделяют фановский поток $M = 7$ и его $N_g = 3$ нечётных хиральных нулевых моды:

1. **Безусловная модулярная единственность (`psl2_order_168_unique_fano7`) [Т]:** Конструктивное доказательство оценки $M \le J_2(M)$ для всех $M \ge 2$ показывает, что $\lvert\mathrm{PSL}(2,\mathbb{Z}_M)\rvert = 168 = \lvert\mathrm{Aut}(\mathrm{PG}(2,2))\rvert$ выполняется **тогда и только тогда, когда $M = 7$** (при всех $M \ge 19$ строго $\lvert\mathrm{PSL}(2,\mathbb{Z}_M)\rvert > 168$). Поскольку $7 \equiv 3 \pmod 4$, 7-мерное пространство Ландау распадается как $H_7 = H_4^+ \oplus H_3^-$, где 4 чётные моды несут **проективное** представление с $\mathbb{Z}_2$-препятствием ($\lVert S_{\mathrm{even}}^2 + I_4\rVert = 2{,}4\times 10^{-15}$), а **$N_g = 3$ нечётных поколения** несут точное **линейное** неприводимое 3D представление Вейля группы $\mathrm{PSL}(2,7)$ ($\lVert S_{\mathrm{odd}}^2 - I_3\rVert = 3{,}3\times 10^{-15}$, $\lvert\langle S_{\mathrm{odd}}, T_{\mathrm{odd}}\rangle\rvert = 168$, норма характера $1{,}0000000000$) [Т].
2. **Закон отбора нечётного $M = 7$ против чётного $M = 8$ (`fano7_vs_m8_odd_generation_selection`, `fano7_vs_m8_active_fixed_point_counts`) [Т]:** Оба потока $M = 7$ и $M = 8$ дают $N_g = 3$ нечётных поколения, однако любой чётный поток ($M = 6, 8$) обращается в нуль **во всех четырёх** неподвижных точках орбифолда (`[0, 0, 0, 0]`): при $M = 8$ юкавское ядро имеет нулевой спектральный зазор ($0{,}0000$) и неиерархический спектр $[0{,}605, 0{,}658, 1{,}0]$ (концентрация Шура $0{,}4084$) [✗]. Напротив, нечётный фановский $M = 7$ концентрирует $100\%$ плотности нечётных мод в единственной неподвижной точке $z_{\mathrm{top}} = (\frac{1}{2}, \frac{1}{2})$ ($\sum \lvert\chi_i\rvert^2 = 7{,}00 = M$), единственным образом давая $\lambda_{\max}(K^{\mathrm{Yuk}}) = 7/2$ и точное ранг-1 доминирование третьего поколения $[0, 0, 1]$ (концентрация Шура $1{,}0000$) [Т].
3. **Открытая предпосылка [П]:** Динамический вывод отождествления $\Gamma_M \leftrightarrow \mathrm{Aut}(\mathrm{PG}(2,2))$ из 7D $G_2$-голона остаётся открытым ([Правило отбора в базисе Фано](../gauge-symmetry/fano-selection-rules#psl2-7-fano-bridge)).
