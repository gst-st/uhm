# Представление Хиггса и параметры его массы

## Отождествление дублета Хиггса {#теорема-отождествление-хиггса}

<a id="запрет-второго-дублета"></a>
<a id="юкавы-t340"></a>
<a id="голоморфность-вп"></a>

У кандидата на параметр порядка нужно проверить цветовое и слабое представления и гиперзаряд. Если группа цвета стабилизирует $e_O$, она смешивает шесть перпендикулярных вещественных осей. Поэтому изолированная ненулевая когерентность на осях $E,U$ не даёт цветового синглета в вакууме. Единственная прямая Фано через две отмеченные точки определяет инцидентность. Для поля Хиггса нужны носитель дублета и закон калибровочного преобразования. Подсчёт прямых оставляет свободным число других скалярных мультиплетов. [Цветовые представления](../gauge-symmetry/standard-model).

## Масса и самодействие {#теорема-f0-канонический}

<a id="итоговая-оценка-mh"></a>

Для канонически нормированного дублета с $V(H)=-\mu^2H^\dagger H+\lambda(H^\dagger H)^2$, $\mu^2,\lambda>0$, положим $H=(0,(v+h)/\sqrt2)^T$. Из условия стационарности следует $v^2=\mu^2/\lambda$. Кривизна потенциала равна $m_h^2=2\lambda v^2$, а третья производная в вакууме — $6\lambda v$. Соотношения относятся к указанному древесному потенциалу. Выбор $v$ и измеренной массы Хиггса фиксирует $\lambda$ в этом приближении. Независимое измерение тройной вершины тогда может проверить форму потенциала.

## Условия для перехода между вакуумами {#4-4}

<a id="скорость-хирального-туннелирования"></a>

Для вычисления скорости туннелирования нужны как минимум две заданные конфигурации, кинетический член, потенциальный барьер и граничные условия перехода. Статический тензор инцидентности не задаёт ни барьера, ни пространственно-временного масштаба, ни действия вдоль пути. [Условные экспериментальные проверки](../../reference/frontier-ledger).

## Двухпетлевая критичность Хиггса на $M_{\mathrm{PS}}$ и препятствие иерархии Виссани {#higgs-criticality-vissani}

Анализ скалярного сектора в не-SUSY цепочке УГМ `Chain A2` ($\mathrm{Spin}(10) \to G_{422} \to G_{\mathrm{SM}}/\mathbb{Z}_6$, `verify_deep_frontier_v7.py`, `ToEFrontierV7.lean`) чётко разделяет устойчивость вакуума (успех) и электрослабую естественность (неустранимое конечное пороговое препятствие):

1. **Двухпетлевая критичность Хиггса СМ и пороговая стабилизация $\Delta_R$ в CCvS (`F-42`, `verify_deep_frontier_v11.py` V11.3.C) [С]:** Двухпетлевой бег констант СМ по данным PDG 2024 ($m_t = 172{,}57\text{–}172{,}69\,\text{ГэВ}$, $m_h = 125{,}25\,\text{ГэВ}$) переводит квартическую связь $\lambda_H(\mu)$ через нуль при $\mu_{\mathrm{inst}} = 5{,}28\times 10^{10}\,\text{ГэВ}$ (двухпетлевой расчёт Буттаццо даёт $\lambda_H(M_{\mathrm{PS}}^-) = -0{,}00412$ на масштабе `Chain A2` $M_{\mathrm{PS}} = 1{,}45\times 10^{11}\,\text{ГэВ}$, $\lambda_H(M_{\mathrm{Pl}}) = -0{,}01021$). Поскольку масштаб нарушения Пати–Салама $M_{\mathrm{PS}} \approx 0{,}94\text{–}1{,}45\times 10^{11}\,\text{ГэВ}$ (как в `Chain A2`, так и в расщеплённом подъёме CCvS `F-42`) лежит непосредственно у $\mu_{\mathrm{inst}}$, интегрирование тяжёлого скаляра $\Delta_R = (\overline{10},1,3)$ порождает положительный древесный пороговый сдвиг $\lambda_H(M_{\mathrm{PS}}^+) = \lambda_H(M_{\mathrm{PS}}^-) + \lambda_{H\Delta}^2 / \lambda_\Delta$, стабилизируя электрослабый вакуум при $\lambda_{H\Delta}/\sqrt{\lambda_\Delta} \ge 0{,}064$ и одновременно согласуя положительное граничное условие НКГ Конна–Шамседдина–ван Суйлекома ($\lambda_H^+ \approx 0{,}10$) при $\lambda_{H\Delta}/\sqrt{\lambda_\Delta} \approx 0{,}323$ для $m_h = 125{,}25\,\text{ГэВ}$ (снимая классическое противоречие $170\,\text{ГэВ}$ в НКГ без суперсимметрии). Поскольку **`Super-F-40`** закрывает все 4D дираковские спектральные действия для гравитации, данный скалярный механизм Пати–Салама CCvS действует строго на уровне внутреннего материально-хиггсова сектора **Страты B** ([Ренормгрупповой поток](../gauge-symmetry/rg-flow#ccvs-pati-salam-rge)).
2. **Конечное $\overline{\mathrm{MS}}$-препятствие иерархии Виссани (`vissani_hierarchy_tuning_lower_bound_cq`) [Т] / [✗] / [П]:** Даже без учёта квадратичных УФ-расходимостей интегрирование тяжёлых правых нейтрино $N_i$ порождает **конечный** однопетлевой $\overline{\mathrm{MS}}$-сдвиг квадрата массы Хиггса $\delta m_H^2 \sim y_\nu^2 M_N^2 / (4\pi^2)$. Условие естественности ($\lvert\delta m_H^2\rvert \le m_h^2$) ограничивает $M_N \le 5{,}73\times 10^6\,\text{ГэВ}$ (консервативно $7{,}21\times 10^6\,\text{ГэВ}$). При фактических значениях `Chain A2` ($M_{N_3} = 3{,}005\times 10^{11}\,\text{ГэВ}$, $y_{\nu 3} = 0{,}542$) классическая масштабная инвариантность не защищает электрослабый масштаб, вынуждая тонкую настройку $\Delta_{\mathrm{EW}} = 8{,}58\times 10^{16}$ ($\ge 1{,}45\times 10^{17}$ при $y = 1$). Решение проблемы иерархии $v_{\mathrm{EW}}/M_{\mathrm{Pl}} \sim 10^{-17}$ без суперсимметрии остаётся открытым [П].
