# Представление Хиггса и параметры его массы

## Отождествление дублета Хиггса {#теорема-отождествление-хиггса}

<a id="запрет-второго-дублета"></a>
<a id="юкавы-t340"></a>
<a id="голоморфность-вп"></a>

У кандидата на параметр порядка нужно проверить цветовое и слабое представления и гиперзаряд. Если группа цвета стабилизирует $e_O$, она смешивает шесть перпендикулярных вещественных осей. Поэтому изолированная ненулевая когерентность на осях $E,U$ не даёт цветового синглета в вакууме. Единственная прямая Фано через две отмеченные точки определяет инцидентность. Для поля Хиггса нужны носитель дублета и закон калибровочного преобразования. Подсчёт прямых оставляет свободным число других скалярных мультиплетов. [Цветовые представления](../gauge-symmetry/standard-model).

## Масса и самодействие {#теорема-f0-канонический}

<a id="итоговая-оценка-mh"></a>

Для канонически нормированного дублета с $V(H)=-\mu^2H^\dagger H+\lambda(H^\dagger H)^2$, $\mu^2,\lambda>0$, положим $H=(0,(v+h)/\sqrt2)^T$. Из условия стационарности следует $v^2=\mu^2/\lambda$. Кривизна потенциала равна $m_h^2=2\lambda v^2$, а третья производная в вакууме — $6\lambda v$. Соотношения относятся к указанному древесному потенциалу. Выбор $v$ и измеренной массы Хиггса фиксирует $\lambda$ в этом приближении. Независимое измерение тройной вершины тогда может проверить форму потенциала.

## Условия для перехода между вакуумами {#4-4}

<a id="скорость-хирального-туннелирования"></a>

Для вычисления скорости туннелирования нужны как минимум две заданные конфигурации, кинетический член, потенциальный барьер и граничные условия перехода. Статический тензор инцидентности не задаёт ни барьера, ни пространственно-временного масштаба, ни действия вдоль пути. [Условные экспериментальные проверки](../../reference/frontier-ledger).
