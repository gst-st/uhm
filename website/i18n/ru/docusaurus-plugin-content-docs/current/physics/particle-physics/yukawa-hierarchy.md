# Матрицы Юкавы и массы

## Из каких данных получается масса? {#thm-2-1}

При одном канонически нормированном дублете Хиггса с вакуумным значением $v/\sqrt2$ матрица Юкавы $Y$ на древесном уровне даёт $M=vY/\sqrt2$. Её сингулярные числа определяют массы фермионов при указанном масштабе и правилах сшивки. Тензор Фано с двумя отмеченными индексами может задать носитель отдельной вершины. Даже у матрицы ранга один единственная ненулевая масса зависит от коэффициента. Возникновение двух остальных масс зависит от других взаимодействий. [Вершина Фано](../gauge-symmetry/fano-selection-rules).

## Что сохраняет ренормгрупповой поток {#3-quasi-ir-fixed-point-и-масса-t-кварка}

<a id="теорема-mb-mt"></a>
<a id="c7-nonperturbative"></a>

Поток $dy/d\log\mu=yF(\mu,y)$ с локально единственным решением сохраняет нулевую связь. В частности, в пертурбативной модели с точной независимой симметрией правого нижнего кварка бег связей не порождает запрещённый юкавский член. Для ненулевой массы $b$-кварка такой модели нужно взаимодействие, нарушающее симметрию. Инфракрасная фокусировка может ослабить чувствительность к начальной ненулевой связи топ-кварка, однако в расчёт его массы входят калибровочные связи, интервал масштабов, $v$ и поправки сшивки.

## Смысл параметра иерархии {#9-аналитическая-формула-ε}

<a id="thm-5-2"></a>

В анзаце $Y=\sum_r\epsilon^r A_r$ степени $\epsilon$ оставляют свободными ранги, сингулярные векторы и возможные компенсации в $A_r$. По одному отношению масс можно откалибровать $\epsilon$. Для проверки нужны фиксированные матрицы, общие соглашения о массах и другое отношение или угол смешивания. Пример — проверка текстуры с шестью нулями по $|V_{cb}|$. [Проверка по смешиванию](./ckm-matrix#derivation-vus).
