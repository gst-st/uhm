## От записей к состоянию {#records}

Если два источника дают одинаковые записи, важно уточнить, что лаборатории вправе *добавить* к опыту. Ещё один экземпляр от неизвестного источника и образец от независимо откалиброванного источника могут нести разную информацию. В [определении операционального состояния](../core/foundations/operational-processes) доступные приготовления и совместные приборы определяют семейство проверок. Для каждого фиксированного семейства сохраняется правило подстановки.

## Как построить различающий опыт {#pair}

Пусть у каждой из двух лабораторий есть вещественный двухуровневый регистр. Положим $J=\left(\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right)$, $K=J\otimes J$, $\rho(t)=(I+tK)/4$, $-1\le t\le1$. Матрица $K$ симметрична, бесследова и в квадрате даёт единицу: состояния положительны и нормированы. Это конкретная модель. Для приготовления крайних состояний не нужно заранее записывать совместный ответ. Закрытый равновероятный бит выбирает согласованные либо противоположные локальные собственные состояния $X$ и $Z$; затем применяется когерентная управляемая инверсия. При первом управляющем регистре она переводит $X\otimes Z$ в $K$: согласованные входы дают положительный край. Обратная операция и два тех же локальных измерения считывают знак. Управление по уже измеренному классическому биту — другой прибор. Смешение крайних приготовлений даёт весь интервал. [Доказательство для схемы](https://github.com/gst-st/uhm/blob/main/website/research/operational-reconstruction/network/RebitExperiment.lean)

На одном экземпляре любая пара вещественных симметричных локальных эффектов пропускает знак. Это сохраняется для **любого конечного числа** независимых экземпляров, даже если каждая лаборатория измеряет все свои провода совместно. Транспонирование всех индексов первой лаборатории переводит каждое $t_i$ в $-t_i$, оставляя её симметричный эффект на месте. Полная свёртка неизменна; аргумент действует почленно для сумм произведений локальных эффектов. Речь об одновременной смене знаков всех источников. Фиксированный ориентированный эталон, когерентная связь *между* лабораториями при считывании или локальные комплексные эффекты для мнимой оси меняют доступные операции. Физически исполнять частичное транспонирование для доказательства не требуется. [Точное доказательство для конечных серий](https://github.com/gst-st/uhm/blob/main/website/research/operational-reconstruction/network/ReferenceOrientation.lean)

## Что измеряет эталон {#reference}

Добавим независимое приготовление $\rho(r)$. Теперь каждая лаборатория измеряет симметричную инволюцию $J\otimes J$ на **своей паре проводов** и сообщает знак. Для исходов $A,B\in\{-1,+1\}$ средние по отдельности равны нулю, а совместное распределение удовлетворяет

$$
\mathbb E[AB]=t\,r,\qquad \Pr(A=a,B=b)=(1+ab\,t r)/4.
$$

Два независимых экземпляра одного неизвестного источника дают $t^2$: виден модуль, но знаки по-прежнему неразличимы. Откалиброванный $r\ne0$ даёт знаковый отклик; инверсия эталона меняет знак, а нейтральный эталон обнуляет отклик. Общий абсолютный знак из относительных сравнений не восстанавливается. Например, при $t=3/5$ вероятности согласия с эталонами $r=3/5,-3/5,0$ равны соответственно $17/25,8/25,1/2$. Это расчётные вероятности, не результаты измерений. В Lean матричные тождества доказаны на целых числителях для произвольных рациональных параметров; конечные полиномы продолжают их на вещественные параметры.

## Предсказание для сети без подбора состояния {#network}

Пусть вершины — источники с ненулевым откликом, а рёбра — воспроизводимые знаки парных сравнений. В связной компоненте с обратимым направлением считывания согласованный знак каждой вершины существует **тогда и только тогда**, когда произведение знаков на любом замкнутом пути положительно. Выбираем знак корня и переносим его по измеренному пути. Два пути дают разные ответы ровно тогда, когда их замыкание отрицательно. Смена конвенции корня меняет все знаки компоненты. На одном дереве знаки согласуются всегда; для проверки нужно оставить хотя бы одно замыкающее ребро. Нулевой или неразрешённый знак не задаёт ориентации. Такое применение [критерия баланса Харари](https://doi.org/10.1307/mmj/1028989917) справедливо и для неквантовых источников. [Конструктивное доказательство](https://github.com/gst-st/uhm/blob/main/website/research/operational-reconstruction/network/ComparisonNetwork.lean)

Для величины отклика модель независимых источников предсказывает $C_{ij}=t_i t_j$. Тогда $C_{12}C_{34}=C_{13}C_{24}$, в том числе при нулях. Три пары ограничивают отклик четвёртой до её наблюдения. Из одного согласия знаков это более сильное равенство не следует. Зависимые приготовления, разная реакция детектора на настройки или дрейф могут нарушить факторизацию.

## Опыт, который может опровергнуть модель {#trial}

До сбора данных фиксируют четыре настройки источников, инвертированный и нейтральный эталоны, метки детекторов, времена и правило образования пар. Даже для сравнения источника с собой делают два независимых приготовления; деление или клонирование одного сигнала не годится. Калибровочные и проверочные пробы различны. Настройки перемешивают по заранее закреплённому случайному расписанию, наблюдателям их не раскрывают, исходы четвёртой пары хранят закрытыми до фиксации прогноза. Каждая назначенная проба оставляет строку, включая пропуски с любой стороны. Когерентность прибора и независимость источников проверяют отдельно: агрегированные счётчики этого не удостоверяют.

[Фиксированный анализ](https://github.com/gst-st/uhm/blob/main/website/research/operational-reconstruction/network/reference_trial.py) принимает восемь условий по 6 000 проб. Три калибровочных корреляции дают ограничение на четвёртую; остальные условия проверяют нейтральный эталон, инверсию знака и сравнения двух источников с самими собой. Модуль отдельного исхода не превосходит единицы. При независимых пробах одновременная вероятность ошибки Хёффдинга для радиуса $1/20$ не больше $16\exp(-6000/800)<0.01$. Для каждого пропущенного произведения допускаются оба знака; отбор по успешной регистрации исключён. Непересекающиеся интервалы произведений опровергают факторизацию. Если интервал знаменателя содержит ноль, отношение не даёт прогноза, но проверка без деления сохраняет смысл. Пересечение интервалов оставляет вопрос открытым. Измерений сети УГМ по этому протоколу пока нет.

Классический источник тоже может выдавать скрытый знак со средним $t_i$. Для двух независимых знаков среднее произведение равно $t_i t_j$. Если прибор сравнения получает оба знака, он может выдать с одной стороны равновероятный бит, с другой — тот же бит, умноженный на произведение. Так воспроизводится **полное совместное распределение** для данного набора измерений. [Нативные контроли](https://github.com/gst-st/uhm/blob/main/website/research/operational-reconstruction/network/ReferenceControls.vr) проверяют это правило. Согласие с опытом поддержит закон сравнения; для выбора физического носителя нужны новые вмешательства, ограничивающие также связи классического конкурента. Несогласие после проверки прибора исключит факторизацию в пределах указанных погрешностей. Ни один исход сам по себе не выбирает комплексную квантовую механику, семь измерений или теорию всего.

Вещественная квантовая механика и нарушение локальной томографии исследованы у [Харди и Вуттерса](https://arxiv.org/abs/1005.4870). Различие вещественных и комплексных локальных измерений имеет и [оптическую экспериментальную проверку](https://arxiv.org/abs/2007.14847). Описанный здесь опыт определяет, какой вопрос о сети УГМ можно решить её собственными приготовлениями и считываниями.
