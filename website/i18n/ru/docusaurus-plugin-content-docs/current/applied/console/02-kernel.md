# 02 · Спецификация ядра

> *Одна библиотека, переиспользуемая для человека, команды и агента. Она берёт оценённое состояние и его неопределённость и возвращает отсчёт с пробросанной неопределённостью. Всё, что нужно доменному модулю, он получает вызовом ядра; ядро не вызывает ничего, кроме линейной алгебры.*

## §1. Представление Γ {#представление}

Единственный входной тип ядра — **объект-оценка** `GammaEstimate`:

- `gamma`: комплексная эрмитова матрица $7\times7$, PSD, единичный след — порядок осей фиксирован как $[A,S,D,L,E,O,U]$.
- `cov`: ковариация над 48 вещественными степенями свободы (7 населённостей − 1 след + 21 величина + 21 фаза; ограничение следа убирает одну степень свободы населённости), используется для проброса доверия. Может быть `null` для якоря III.
- `anchor`: одно из `MEASURED | AUTOEPHEMERIS | ORACLE` (тег честности).
- `t`: временная метка, для сборки траектории.

**Валидация и проекция.** Всякая входящая `gamma` проецируется на ближайшее валидное состояние перед использованием: эрмитизация ($\Gamma \leftarrow \tfrac12(\Gamma+\Gamma^\dagger)$), обнуление отрицательных собственных значений, ренормировка следа. Расстояние проекции записывается как флаг качества входа — большая проекция означает, что оценщик произвёл нечто далёкое от физического состояния, что слой честности выносит наружу.

## §2. Одиннадцать инвариантов — точные процедуры {#инварианты}

Всякая процедура — чистая функция `gamma` (плюс, где отмечено, второе состояние для инкрементов или явно заданный потенциал $V$ для гессианного показателя). Все $O(1)$ по размеру задачи (фиксированные $7\times7$); единственные нетривиальные вычисления — собственное разложение при PSD-проекции и, при запросе, гессиан заданного потенциала.

**Чистота $P$ `[Т]`.** `P = trace(gamma @ gamma).real`. Унитарный инвариант. Диапазон $[1/7, 1]$; $1/7$ — максимально смешанное состояние «тепловой смерти» $I/7$, $1$ — чистое. Порог жизнеспособности $P > 2/7$ ([Т](/docs/core/dynamics/viability)).

**Рефлексия $R$ `[О]`.** `R = 1.0 / (7*P)`. Унитарный инвариант. Диапазон $[1/7, 1]$; нормированная близость к $I/7$. Полоса сознания $R \geq 1/3$ (эквивалентно $P \leq 3/7$; [самонаблюдение](/docs/consciousness/foundations/self-observation#формы-r)). Это *каноническая* $R$; не путать с $R_\varphi$ (ниже) — это различные рабочие формы, и ядро экспонирует обе под своими именами.

**Качество самомодели $R_\varphi$ `[Т]`.** Требует явно заданного отображения самомодели $\varphi$. Для семейства **линейного якорного смешивания** ([T-249](/docs/proofs/categorical/formalization-phi#дф-производная)),

$$\varphi_{\mathrm{lin}}(\Gamma) := R(\Gamma)\,\Gamma + (1 - R(\Gamma))\,I/7 = (1-k)\,\Gamma + k\,I/7, \qquad k = 1 - R(\Gamma) = 1 - \frac{1}{7P(\Gamma)},$$

вычисляется `R_phi = 1 - fro(gamma - phi_lin(gamma))**2 / fro(gamma)**2`, что тождественно сводится к $R_\varphi = 1 - (1 - R)^3 \in [0, 1]$ и унитарно инвариантно. **Не смешивать** $\varphi_{\mathrm{lin}}$ (вес $R$ на $\Gamma$, $1-R$ на $I/7$) с **когерентным дефазирующе-якорным** отображением $\varphi_{\mathrm{coh}}(\Gamma) := (1-R)\,\mathcal{P}_\alpha(\Gamma) + R\,I/7$ и **заякоренным** отображением $\varphi_J(\Gamma) := (1-R)\,\mathcal{P}_\alpha(\Gamma) + R\,|\psi\rangle\langle\psi|$ ([T-334](/docs/reference/status-registry)). Где задан обученный якорь $\rho_\theta$ ([формализация $\varphi$](/docs/proofs/categorical/formalization-phi#механизмы-rφ)), вместо него вычисляется $\varphi_\theta(\Gamma) = R\,\Gamma + (1-R)\,\rho_\theta$.

**Интеграция $\Phi$ `[О]/[Т]`.** Вычисляется напрямую по каноническому отношению когерентностей в фиксированном базисе из [dimension-U](/docs/core/structure/dimension-u#мера-интеграции-φ) и [T-129](/docs/proofs/consciousness/operationalization#t-129):

$$\Phi(\Gamma) = \frac{P - P_{\mathrm{diag}}}{P_{\mathrm{diag}}} = \frac{\sum_{i \neq j} |\gamma_{ij}|^2}{\sum_{i=1}^7 \gamma_{ii}^2}, \qquad P_{\mathrm{diag}} = \sum_{i=1}^7 \gamma_{ii}^2.$$

Алгоритм: `P_diag = sum(diag(gamma).real**2); Phi = (P - P_diag) / P_diag`. Поскольку $\mathbb C^7$ имеет простую размерность $7$, оно **не допускает** нетривиальных тензорных факторизаций или бипартиций; $\Phi$ — алгебраическое отношение $O(1)$ в фиксированном базисе, **не** перебор разбиений и **не** инвариант произвольных унитарных вращений. Диапазон $[0, 6]$, с оценкой $\Phi \leq 7P - 1$ (откуда $\Phi \leq 2$ в окне сознания $P \leq 3/7$); критерий доступа $\Phi \geq 1$ `[О]`, алгебраически влекущий $P \geq 2/7$ (`T-129 [Т]`).

**Дифференциация $D_{\mathrm{diff}}^{7D}$ `[О]`.** В нативном 7D-пространстве состояний ядро вычисляет канонический **7D-нативный прокси** из [операционализации](/docs/proofs/consciousness/operationalization#t-128):

$$\mathrm{Coh}_E(\Gamma) = \frac{\gamma_{EE}^2 + 2\sum_{j \neq E} |\gamma_{Ej}|^2}{P} = \frac{\|\pi_E(\Gamma)\|_F^2}{P} \in [0, 1], \qquad D_{\mathrm{diff}}^{7D}(\Gamma) = 1 + 6\,\mathrm{Coh}_E(\Gamma).$$

Алгоритм (ось $E$ имеет индекс `4` в $[A,S,D,L,E,O,U]$): `coh_E = (gamma[4,4].real**2 + 2*sum(abs(gamma[4, j])**2 for j != 4)) / P; D_diff_7D = 1.0 + 6.0 * coh_E`. Диапазон $[1, 7]$; рабочий порог $D_{\mathrm{diff}}^{7D} \geq 2$ `[О]`. Зависит от базиса (выделенная ось $E$). Спектральная мера фон Неймана $\exp S_{vN}(\rho_E)$ определена **только** при наличии расширенного опытного регистра $\mathcal H_E$ с явной тензорной факторизацией и частичным следом $\rho_E$; она **никогда** не отождествляется с $\exp S_{vN}(\Gamma)$ на полной матрице $\Gamma$ размера $7\times 7$ (в $|E\rangle\langle E|$ имеем $D_{\mathrm{diff}}^{7D} = 7$, тогда как $\exp S_{vN}(\Gamma) = 1$; в $I/7$ имеем $D_{\mathrm{diff}}^{7D} = 13/7$, тогда как $\exp S_{vN}(\Gamma) = 7$).

**Карта Gap `[О]`.** Для всякой пары $(i,j)$: `Gap[i,j] = abs(sin(angle(gamma[i,j])))`, с [конвенцией исчезающей когерентности](/docs/core/dynamics/gap-operator#конвенция-нулевой-когерентности): если `abs(gamma[i,j]) < eps_min`, положить `Gap[i,j] = 1` (канал без когерентности не «прозрачен», он отсутствует — фаза не определена). Возвращает 21 значение верхнего треугольника как карту прозрачности в фиксированном базисе.

**Мандалаграмма `[О]`.** Чистое переформатирование: 7 населённостей `diag(gamma).real` и 21 когерентность `(величина, фаза)` на карте 7-узлов / 21-ребро ([матрица когерентности](/docs/core/dynamics/coherence-matrix), [Gap-диагностика](/docs/applied/research/gap-diagnostics#фано-паттерны)). Никаких вычислений, только раскладка — это render-модель, которую потребляет UI.

**Архетип `[Т]/[О]`.** Пороговать диагональ на $\tau$ (по умолчанию средняя населённость $1/7$) до 7-битного слова $\{p_i > \tau\} \in \{0,1\}^7$, затем синдромно декодировать в единственное ближайшее кодовое слово среди **16 кодовых слов кода Хэмминга $H(7,4)$** ([T-224](/docs/applied/research/syndrome-calculus#теорема-сигма)). Возвращает id кодового слова (0–15) плюс отступ до ближайшего соседнего слова. Следует строго отличать эти 16 кодовых слов $H(7,4)$ от **9 непустых типов орбит** подмножеств осей под действием конечной группы коллинеаций Фано $\mathrm{GL}(3,2)$ ([T-256](/docs/reference/status-registry), [Математическое ядро](/docs/reference/mathematical-kernel)) — ни одна из классификаций не является $G_2$-орбитами пороговых диагоналей.

**Мода `[О]`.** Требует два состояния $\Gamma(t)$, $\Gamma(t')$ и заданную группировку генератора. Формируется инкремент $\dot\Gamma \approx (\Gamma(t')-\Gamma(t))/(t'-t)$ и проецируется на выбранную [трёхчастную группировку динамики](/docs/core/operators/lindblad-operators#триадная-декомпозиция) — гамильтонову (сохраняющую), диссипативную (релаксирующую к $I/7$) и регенеративную (восстанавливающую к $\varphi(\Gamma)$). Эта трёхчастная группировка является выбранным модельным соглашением `[О]`, а не исчерпывающей теоремой классификации ГКСЛ. Возвращает три доли, суммирующиеся в единицу; «мода» — доминирующая доля.

**Смысл `[О]`.** `Meaning = P * D_diff_7D * Phi * R_phi` — выбранный составной скалярный показатель (согласно [Смыслу](/docs/consciousness/ethics-meaning/meaning#пиковый-потенциал), существует бесконечно много монотонных произведений и нет единственного канонического скаляра смысла). Возвращается и как скаляр, и как четыре его фактора, чтобы UI мог показать наименьший компонент.

**Свобода `[О]` (условно `T-89 [Т]`).** При **явно заданном $C^2$-потенциале $V$** на гладкой области 48-мерного вещественного пространства состояний и критической точке $\Gamma_*$ определяется [гессианный показатель](/docs/consciousness/ethics-meaning/freedom#количественная-мера):

$$\mathrm{Freedom}_V(\Gamma_*) := 1 + \dim\ker\operatorname{Hess}_{\Gamma_*} V \in [1, 49].$$

Численно ядро строит $\operatorname{Hess}_{\Gamma_*} V$, вычисляет его собственные значения и оценивает `Freedom = count(abs(hessian_evals) < tol) + 1`, возвращая число и плоские собственные векторы. По [T-89](/docs/consciousness/ethics-meaning/freedom#количественная-мера) (`[Т]` при условии Морса–Ботта) дефект совпадает с касательной размерностью гладкого критического многообразия; без регулярности Морса–Ботта члены высших порядков могут устранять плоские пути несмотря на нулевые квадратичные моды. Если потенциал $V$ не задан, `Freedom` возвращается как `null`. Показатель не монотонен по CPTP и не является самостоятельной мерой личной агентности без независимой модели репертуара политик.

## §3. Проброс доверия {#доверие}

Всякий скалярный инвариант несёт неопределённость, выведенную из `cov` дельта-методом: для инварианта $f(\Gamma)$, `var(f) = grad_f.T @ cov @ grad_f`, с `grad_f`, вычисленным аналитически для функций в замкнутой форме ($P, R, R_\varphi, \Phi, D_{\mathrm{diff}}^{7D}, \mathrm{Meaning}$) и автодиффом/конечными разностями для `Freedom` (при заданном потенциале $V$). Ядро возвращает всякий инвариант как тройку `(value, std, anchor)`. **У входов якоря III нет `cov`**, поэтому их инварианты возвращают `std = null` и отрисовываются как «ориентировочные, не измеренные» — ось честности, проведённая на численном слое.

## §4. Гардрейлы оптической конструкции {#гардрейлы}

Прежде чем всякий отсчёт выпущен, ядро прогоняет три проверки-гардрейла ([Математическое ядро](/docs/reference/mathematical-kernel), [Идентифицируемость реконструкции](/docs/applied/research/reconstruction-identifiability)) и прикрепляет вердикты:

1. **Тип карты (`T-256 [Т]+[И]`).** Какой из 9 непустых типов орбит коллинеаций Фано и какие секторы состояния это чтение реально разрешает? Опросная оценка разрешает населённости и величины, но фазо-слепа; ядро метит, какие секторы достоверны для *этой* оценки, так что код ниже по течению никогда не читает фазозависимое значение Gap с фазо-слепого якоря.
2. **Лицензия якоря (`T-257 [Г]`).** Если какой-либо внешний сигнал питал оценку, опирается ли он на идентифицированную физическую модель связи (режим света/сна, физиологическая телеметрия) или это немоделированное эфемеридное/натальное притязание? В рамках гипотезы канала связи ([T-257](/docs/applied/research/gap-diagnostics), [Реестр статусов](/docs/reference/status-registry)) немоделированные планетарные/натальные входы отвергаются при приёме как архитектурная политика, а не тихо используются.
3. **Гейт жизнеспособности `[О]`.** Реально ли субъект в жизнеспособном режиме ($P>2/7$ и т.д.)? Ниже гейта показатели окна сознания помечаются неприменимыми, а не сообщаются как малые числа — нежизнеспособное состояние маркируется вне окна.

Эти вердикты не совещательны; доменный модуль, игнорирующий их, не компилируется против API (§5), потому что тип отсчёта параметризован исходом гардрейла.

## §5. Внутренний API {#api}

Ядро экспонирует одну точку входа и типизированный отсчёт:

```
readout = kernel.evaluate(estimate: GammaEstimate,
                          prev: GammaEstimate | null,
                          potential: PotentialSpec | null = null) -> Readout
```

Поля `Readout`: `invariants` (одиннадцать троек `(value, std, anchor)`; `mode` присутствует только если дан `prev`, `freedom` — только если задан `potential`), `mandalagram` (render-модель), `archetype` (id кодового слова $H(7,4)$ + отступ), `guardrails` (три вердикта §4), `quality` (флаг проекции входа из §1). Всякое поле, что может быть неопределённым, несёт свою неопределённость; всякое поле несёт свой якорь. **Нет** вызова, возвращающего голое число без его происхождения — API делает нечестный вывод непредставимым.

**Субстрат-агностичность.** `evaluate` никогда не инспектирует, *откуда* пришла `gamma`, кроме тега `anchor`. Тот же вызов обслуживает человеческий самоаудит, ЭЭГ-пайплайн и адаптер ИИ-телеметрии — платформенное свойство [00 §2](/docs/applied/console/overview#почему-коммерция), обеспечиваемое слепотой ядра к субстрату.

## §6. Тестирование и численная дисциплина {#тесты}

Ядро поставляется с оракульной сюитой (та же дисциплина, что использует корпус):
- **Аналитические тождества** проверяются на случайных матрицах плотности до $\sim 10^{-12}$, включая $R_\varphi = 1-(1-R)^3$ для семейства линейного якорного смешивания $\varphi_{\mathrm{lin}}$ (`T-249 [Т]`) и $\Phi \leq 7P - 1$ (`T-129 [Т]`).
- **Краевые состояния** попадают в точные канонические значения: в $I/7$ имеем $P = 1/7$, $R = 1$, $\Phi = 0$, $D_{\mathrm{diff}}^{7D} = 13/7$; в $|E\rangle\langle E|$ — $P = 1$, $R = 1/7$, $\Phi = 0$, $D_{\mathrm{diff}}^{7D} = 7$; в однородном чистом состоянии $|u\rangle\langle u|$ — $P = 1$, $R = 1/7$, $\Phi = 6$.
- **Тесты унитарной инвариантности (строго ограниченные):** при случайных $U \in U(7)$ (в частности $G_2 \subset SO(7) \subset U(7)$) оракул проверяет инвариантность **только истинных унитарных/спектральных инвариантов** — $P(\Gamma)$, $R(\Gamma) = 1/(7P)$, спектра (собственных значений) $\Gamma$ и $R_\varphi(\Gamma)$ для $\varphi_{\mathrm{lin}}$.
- **Тесты базисной зависимости и ковариантности:** явные негативные тесты подтверждают, что базисно-зависимые величины ($\Phi$, $\mathrm{Coh}_E$, $D_{\mathrm{diff}}^{7D}$, карта Gap, кодовое слово Хэмминга $H(7,4)$) **не** инвариантны относительно общих унитарных или $G_2$-вращений, но ковариантно преобразуются при перестановках осей (и сохраняют код $H(7,4)$ при коллинеациях Фано $\mathrm{GL}(3,2)$).
- **Тесты монотонности:** монотонность составного показателя Смысла по каждому из четырёх его факторов.

Сборка, провалившая любой оракул, не выпускается — авторитет отсчёта держится на том, что ядро вычисляет точные определения корпуса, не протаскивая ложных инвариантностей.

**Куда это ведёт.** [03 · Якоря и оценка](/docs/applied/console/anchors) специфицирует, как реальный `GammaEstimate` производится из каждого из трёх типов свидетельства, с полным инструментом самоаудита и математикой измерительного моста.
