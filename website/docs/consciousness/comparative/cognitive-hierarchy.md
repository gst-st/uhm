# Cognitive Hierarchy: From Sensation to Language

Discrimination, response to reward, category transfer, planning and symbolic communication ask different experimental questions. Calling them stages adds a claim about their order and dependence. Each claim needs a test in which lack of sensory access, motivation or a usable response cannot explain the outcome.

<a id="операциональные-критерии"></a>

## Evidence specific to each task

Measure discrimination on novel trials, category transfer across new examples, and planning after an outcome changes while the initial cues stay fixed. To test communication, manipulate what the recipient can know and record whether the sender changes its message. In each case specify the simpler cue-following or memorization policy and a condition on which its prediction differs.

<a id="таксономическое-соответствие"></a>

## From a task to a claim about a subject

Learning to approach a reward does not determine whether an organism feels pleasure. A controller with a fixed reward input can learn the same mapping. A capability score is tied to its stimulus, readout and generalization test. Age, species, architecture and a chosen matrix dimension do not assign that score.
