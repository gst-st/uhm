# Pre-linguistic Consciousness

Which abilities can be tested without asking a participant to describe an experience in words? Looking, reaching and requesting help provide distinct records. Their interpretation depends on the task and on the participant’s available response channels.

## Help-seeking before an answer

Goupil and colleagues asked infants to indicate the location of a hidden toy. In one condition the infant could request help nonverbally. Help-seeking varied with the availability of information. The record consists of a choice or request and whether the indicated location was correct. A model of monitoring uncertainty can be compared with one following an external cue, prior reward or the adult’s behaviour. This tests an ability to use information about task difficulty. The result by itself does not quantify the infant’s subjective experience. [Task and results](https://doi.org/10.1073/pnas.1515129113)

## Available response channels

Signed languages are languages. Absence of speech is compatible with fluent communication and cannot be used as a measure of language ability. Match a response to the participant’s sensory and motor access and validate it independently. A missing response can reflect an inaccessible cue, an unavailable action or a failure of the proposed capacity. Clinical assessment of a patient and experimental performance by an infant or animal require different protocols. ## What would test a language-dependent mechanism?

Compare matched tasks with and without informative linguistic cues. Specify the prediction for transfer to new stimuli, and separate language demands from motor and memory demands. A formal model whose decision rule lacks a language variable only shows that such a model can be defined. It supplies no experimental age of onset or universal threshold for awareness.
