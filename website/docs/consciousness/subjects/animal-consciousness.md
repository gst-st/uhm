# Animal Consciousness

An animal can provide a record through a choice, a request for information, an opt-out response or a physiological signal. Interpretation depends on what the individual can perceive, what actions are available and how training changes those actions. A species name by itself fixes no purity, matrix dimension or level of experience.

## Comparing tasks across species

A task that requires a spoken answer cannot measure the same ability in a nonverbal animal. Match the task operationally: comparable sensory access, attainable responses, reward contingencies and opportunity to learn. Report individual trial records, including omissions. A group mean can hide distinct strategies. A declaration about animal consciousness and an empirical estimate for a particular task have different evidential roles.

## A test of memory monitoring

Hampton offered two rhesus monkeys a delayed memory test, with an option to decline on selected trials. One met the study’s criteria in every condition, the other in all but one. The comparison uses chosen and compulsory tests, and manipulations of memory availability. An alternative policy that follows elapsed time or an observable difficulty cue makes its own predictions. Test these against held-out conditions before generalizing a result to a species. No fitted matrix or named capability level replaces those records. [Hampton, 2001](https://doi.org/10.1073/pnas.071600998)

## What changes with the unit of observation?

A response to a stimulus, transmission of information and a group-level decision can each be tested with a different intervention. Define the observed system before interpreting its record. For a colony, a common environmental cue can correlate individual actions without communication. For a proposed model of experience, specify a further observation that discriminates it from the behaviourally matched alternative.
