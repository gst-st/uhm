# Операциональные основания УГМ

Физический смысл состоянию дают приготовления, допустимые вмешательства и полные записи их исходов. При соединении приборов существенно, какие операции и эталоны действительно доступны. Совпадение групп симметрий, числа координат или результатов на изолированных системах не устанавливает равенство двух физических теорий. Для этого нужен перенос композиций и независимая проверка измеряемых следствий.

Классические стохастические схемы произвольной конечной ёмкости удовлетворяют тем же правилам соединения. | [Процессы](network/OperationalProcess.lean), [вероятностная контрмодель](network/RandomProcess.lean) |

## Связь с основаниями

В Diakrisis различаются действие и его представление. Для применения к физике нужно задать, как представляются композиции и исходы. В Math Foundations операционная эквивалентность проверяет также будущие действия. MSFS различает доказуемость относительно формальной системы и наличие интерпретации её предпосылок. Здесь для каждого существенного шага указаны модель, сохраняемые наблюдения и то, что требуется от физического устройства. Численная УГМ с комплексной матрицей плотности служит отдельной проверяемой реализацией.

## Воспроизведение

Общие сетевые доказательства используют Lean 4.35 и Std. Нативные контракты Verum проверяются непосредственно по исходникам и отрицательным мутациям; охват указан в [инструкции и описи доказательств](network/README.md). Из собранного каталога math-foundations/lean4-mf-kernel выполните `lake env lean -DwarningAsError=true /absolute/path/to/AddressFusion.lean`: импортируется сам контракт DimensionPinch. Для остальных независимых точных проверок:

~~~sh
python3 -B verify_preparations.py
python3 -B verify_context.py
python3 -B check_action_access.py /path/to/math-foundations/lean4-mf-kernel
python3 -B verify_edge.py
python3 -B verify_feedback.py
lean -DwarningAsError=true FeedbackWitness.lean
~~~

Для verify_feedback.py необходим SymPy. Код, модельные данные и лабораторные наблюдения имеют разный статус: ни вычисление, ни проверка формального вывода не заменяют измерения.
