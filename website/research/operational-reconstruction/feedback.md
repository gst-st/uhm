# Ресурсная цена канонической обратной связи

## Утверждение

Пусть \(d\ge3\) — конечная размерность, \(\Theta\) — заранее известный чистый проектор, \(\tau=I/d\), а источник по запросу независимо готовит \(\rho_y=(1-y)\tau+y\Theta\) с одним и тем же неизвестным \(0\le y\le1\). Это луч из §14.8 Аутогении. На нём любой выбранный там унитальный канал, сохраняющий \(\Theta\), фиксирует всю входную матрицу. Для фиксированного питания \(\mu\) требуемое выходное состояние равно \(\rho_{g(y)}\), где

\[
t=d-1,\qquad D(y)=1+t y^2,\qquad
g(y)=\mu+(1-\mu)t y^3/D(y).
\]

Допускается любой фиксированный квантовый инструмент с исходами «успех» и «отказ», вспомогательными системами, классической случайностью и адаптивными измерениями. Их начальные состояния и правила независимы от \(y\). Считаем максимальное число запрошенных приготовлений за **одну попытку**. Успех должен иметь положительную вероятность на всём луче. Требование точности относится ко всей нормированной выходной матрице при успехе.

Тогда для \(0\le\mu<1\) минимум числа приготовлений за попытку равен
\[
m_*=\begin{cases}
3,& \mu\ge(2d-3)/((d-1)(d+3)),\\
4,& \mu<(2d-3)/((d-1)(d+3)).
\end{cases}
\]
При \(\mu=1\) хватает подготовки \(\Theta\) без входа. Если требуется безусловный точный шаг с конечным верхним пределом числа входов, при \(\mu<1\) реализации нет. Известность направления \(\Theta\), доступ к повторной подготовке и наблюдаемый исход попытки существенны.

## Почему возникает граница

Положим \(\eta=(I-\Theta)/(d-1)\). Тогда \(\rho_y=p\Theta+(1-p)\eta\), где \(p=(1+t y)/d\). Два слагаемых имеют ортогональные носители. Целевая вероятность результата \(\Theta\) равна \(q=(1+t g(y))/d=A/D\).

Для любого инструмента на \(m\) входах обозначим через \(a(p)\) вероятность успеха и последующего ответа \(\Theta\), а через \(s(p)\) вероятность успеха. Разложение тензорного произведения и линейность правила Борна дают
\[
a=\sum_{j=0}^m a_j {m\choose j}p^j(1-p)^{m-j},\qquad
s=\sum_{j=0}^m s_j {m\choose j}p^j(1-p)^{m-j},\qquad 0\le a_j\le s_j\le 1 .
\]
Коэффициенты получаются усреднением по упорядоченным входным словам с \(j\) буквами \(\Theta\). Досрочное завершение допускает дополнение до \(m\) игнорируемыми приготовлениями. В обратную сторону, любой набор таких коэффициентов реализуется измерением \(\{\Theta,I-\Theta\}\) на входах. По счётчику \(j\) готовим \(\Theta\) с вероятностью \(a_j\), готовим \(\eta\) с вероятностью \(s_j-a_j\) и регистрируем отказ с вероятностью \(1-s_j\). Тем самым равенство \(aD=sA\) обеспечивает нужную матрицу при успехе.

При \(\mu<1\) многочлен
\(A=[(1+t\mu)D+(1-\mu)t^2y^3]/d\)
имеет степень три и взаимно прост с \(D\), поскольку \(D(0)=1\) и остаток числителя по модулю \(D\) пропорционален \(y^3\bmod D\). Эти свойства сохраняются при обратимой аффинной замене \(y\leftrightarrow p\). Равенство на отрезке влечёт полиномиальное тождество. Следовательно, \(a=hA,\ s=hD\). При конечном \(m\) и \(s=1\) это невозможно. При \(m\le2\) ненулевого \(h\) также нет. При \(m=3\) множитель \(h\) — положительная константа.

Коэффициенты \(D\) в базисе Бернштейна степени три, в порядке \(j=0,1,2,3\), равны
\[
\left(\frac d{d-1},\frac d{3(d-1)},\frac d3,d\right).
\]
Коэффициент \(A_2=[(d-1)(d+3)\mu-(2d-3)]/(3d)\) меняет знак ровно при указанном пороге. Для остальных \(A_j\) и всех \(D_j-A_j\) достаточно проверить неотрицательность при \(\mu=0,1\), поскольку зависимость аффинна. При \(\mu=1\) имеем \(A=D\). При \(\mu=0\) коэффициенты \(A\) равны
\[
\left(\frac1d,\frac{4d-3}{3d(d-1)},\frac{3-2d}{3d},\frac{d^2-d+1}d\right).
\]
Те же подстановки дают \(D-A\ge0\) покоэффициентно для \(d\ge3\). Если \(A_2\ge0\), выбираем \(h=1/d\). Тогда \(s=D/d\in[1/d,1]\) на луче. Это **оптимальная поточечная вероятность успеха среди точных трёхвходовых инструментов**: \(s(1)\le1\) при \(y=1\) ограничивает единственный свободный множитель сверху величиной \(1/d\).

Для четырёх входов положим \(H(p)=(1-p)+(d-1)p/2\). В базисе Бернштейна степени четыре достаточно получить неотрицательные коэффициенты для \(HA\) и \(H(D-A)\). Если \(c_j\) — кубические коэффициенты, то новые равны
\[
c'_j=(4-j)c_j/4+j(d-1)c_{j-1}/8,\qquad c_{-1}=c_4=0 .
\]
При \(\mu=0\) единственный исходный отрицательный \(A_2\) входит в две строки. Новые \(A'_2=1/(4d)\), \(A'_3=(3d-1)/(8d)\) положительны. Остальные строки положительны по исходным коэффициентам. При \(\mu=1\) утверждение следует из \(A=D\). Интерполяция покрывает весь диапазон питания. Деление всех коэффициентов на \(d(d-1)/2\) гарантирует \(s'_j\le1\), поскольку \(D_j\le d\) и оба коэффициента \(H\) не больше \((d-1)/2\). Поэтому четвёртого приготовления всегда достаточно. Оптимальность вероятности успеха для четырёх приготовлений здесь не исследовалась.

## Проверяемый пример

При \(d=7,\ \mu=1/2\) нижняя и верхняя оценки сходятся на трёх входах. Каждая строка таблицы содержит веса с общим знаменателем 1764.

| Число попаданий в \(\Theta\) | Готовить \(\Theta\) | Готовить \(\eta\) | Отказ |
|---:|---:|---:|---:|
| 0 | 165 | 129 | 1470 |
| 1 | 74 | 24 | 1666 |
| 2 | 228 | 360 | 1176 |
| 3 | 1656 | 108 | 0 |

Для проверки возьмём равновероятную смесь препаратов \(\rho_0,\rho_1\) на одном входе. Аффинный канал обязан усреднять результаты на концах. Для целевой координаты \((g(0)+g(1))/2=5/7\), тогда как \(g(1/2)=13/20\). Разрыв равен \(9/140\). В следовом расстоянии это даёт нижнюю границу \(27/980\) на максимальную ошибку любого безусловного одновходового канала хотя бы на одном из этих трёх препаратов (неравенство треугольника и \(D_{\rm tr}(\Theta,\tau)=6/7\)). Для двух входов даже при отборе шесть рациональных точек \(y=j/5,\ j=0,\ldots,5\) дают невырожденную систему для шести коэффициентов \(a,s\). Определитель при масштабировании строк как в скрипте равен \(-135025380000000000\).

У трёхвходового протокола вероятность принятия \((1+6y^2)/7\). При независимых повторах среднее потребление входов на принятый выход равно \(21/(1+6y^2)\). Чтобы проверить аппаратную реализацию, для каждого заранее выбранного \(y\) нужно регистрировать и число попыток, и число успешных ответов обоих типов. Флаг успеха должен быть доступен наблюдателю. Итерация расходует независимо подготовленные входы следующего уровня. Одна принятая система сама по себе не предоставляет таких копий.

## Воспроизводимость и границы новизны

[verify_feedback.py](verify_feedback.py) символически сверяет коэффициенты как функции \(d,\mu\), их неотрицательность на концах по коэффициентам многочленов от \(d-3\), точный определитель и выходы прибора. [FeedbackWitness.lean](FeedbackWitness.lean) независимо проверяет допустимость трёх исходов и два точных полиномиальных сертификата для численного примера. Общая теорема об оптимальности доказана выше на бумаге. Полного переноса этого доказательства о классе квантовых инструментов в Lean нет.

У этой конструкции есть предшественники. Рациональные функции от неизвестной вероятности реализуются фабриками Бернулли. Связь постселекции с рациональной степенью также известна для моделей запросов. Здесь выведены конкретный порог по \(\mu\), таблица и оптимальная трёхвходовая вероятность для луча Аутогении. Приоритет открытия в мировой литературе не установлен. [Morina et al.](https://arxiv.org/abs/1912.09229) · [Mahadev & de Wolf](https://arxiv.org/abs/1401.0912)
